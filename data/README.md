# 원랜디 S2 2.323[C] 도감 데이터

악몽 난이도 + 이세계모드 전용 Unity 모바일 프로젝트의 데이터 저장소입니다.

## 수집 원칙
- 2.323 버전 도감·패치 기록을 우선 확인합니다.
- 각 항목에 출처 URL, 버전, 검증 상태를 남깁니다.
- 미확인 수치나 조합식을 추정해서 입력하지 않습니다.
- 도감의 계산기 옵션과 실제 게임 동작을 혼동하지 않습니다.
- 원본 W3X 분석은 핵심 규칙을 도감으로 확인할 수 없는 경우에만 수행합니다.

## 파일
- `sources.json`: 참고할 도감 및 검증 상태
- `schema.json`: 유닛·조합·스킬·상점·위습·도박·라운드 데이터를 기록할 구조
- `units.json`: 검증 완료된 유닛 항목만 기록 (현재 비어 있음)
- `recipes.json`: 검증 완료된 조합식만 기록 (현재 비어 있음)

**주의:** 데이터 파일이 비어 있다는 것은 원작에 유닛이나 조합이 없다는 뜻이 아니라, 아직 항목별 출처 대조를 완료하지 않았다는 뜻입니다.
