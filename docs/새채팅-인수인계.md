## 이어받을 다섯 가지

1. **기준:** `cuteu2474-a11y/ordr-unity-mobile`의 main. 이번 작업은 `3a2d6afb`에서 시작해 병행 반영된 영웅 성장 커밋 `65c02135` 위에 통합·검사했습니다. 작업 시작 때 실제 최신 HEAD를 확인합니다.
2. **이번 결과:** TW-01/h0BR 비전투 상자를 포함한 288항목 집계 재생성, 중복/누락 거부와 읽기 전용 `--verify` 추가, 위습 회귀를 공통 거래 조건에 맞게 수정. 게임 수치·전투 코드는 불변입니다.
3. **검사:** Windows/Python 3.12에서 340건 중 337건 통과·3건 건너뜀. 현황/생성 유닛 표 일치 확인. 상세 환경·제외 범위는 현재 상태 문서에 있습니다.
4. **남은 제약:** 이번 Unity·Linux 패키징·실기 결과는 미확인. 실제 C# 지원 내보내기는 새로 생성하지 않았습니다. 기존 APK는 `53d3e240`의 `0.1.364`이며 최신 게임 코드 14개 커밋은 미포함입니다.
5. **다음 행동:** 검사 요청이면 Linux 패키징·Unity EditMode 및 실제 C# 지원 내보내기를 확인합니다. 기능 작업이면 원본 XP 지급 사건·시라호시 특성 발동·연구의 실제 전투 영향 중 미연결 부분을 조사합니다. 58개 폼의 레벨/성장 계산은 이미 연결됐으므로 다시 만들지 않습니다. [영웅 성장 근거](../data/original-2323C-hero-level-growth-evidence.json)와 개발 작업 문서를 확인합니다.

## 작업할 때

같은 카탈로그 불일치를 다시 조사하지 않으려면 `python3 tools/build_character_runtime_coverage.py --verify`를 사용합니다. C# 지원이 바뀌었으면 실제 지원 내보내기와 실행 범위 JSON을 먼저 갱신해야 합니다.

사용자가 요청한 범위에서 진행하고 Python/Unity/APK 실제 실행과 Actions 조회는 명시적 요청이 있을 때만 합니다. 문서 수정만으로 APK를 재제작하지 않습니다. main 반영 뒤 결과를 기다리지 않고 변경과 미검증 범위를 보고합니다.

날짜별 작업 보고를 이 파일에 추가하지 않습니다. 변경 이력은 Git 커밋, 원본 근거는 `data/`, 현재 상태와 다음 작업은 위 문서에서 찾을 수 있습니다.
