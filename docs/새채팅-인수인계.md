# 새 채팅 개발 인수인계

- 저장소 `cuteu2474-a11y/ordr-unity-mobile`, `main`. ORDR 2.323[C] 악몽·이세계 Unity 모바일.
- 크립 기본 전장: 스토리→크립 탭 3단계/HP·한 기 파견·이동·수동 복귀, 메인·스토리·공유/크립 전장 공격·오라 격리.
- 신규 조건부 파견: `IOriginal323CreepConditionalDispatchAuthority`가 실제 유닛 ID·카탈로그 ID·크립 생존 인스턴스·단계·원본 능력 rawcode와 근거를 제시해야 후보 승인.
- `TryDispatchToCreep`는 direct 우선, 원본 능력 시전이 필요할 때 `TryBeginPreparation` 1회만 실행하고 신청 중복 금지; `AdvancePendingCreepPreparations`는 원본 완료를 읽은 후 공격 위치·소유자·대상 재검사, 그때만 배치.
- CTp/CTq 다음 크립 실물 생성에도 같은 조건부 준비를 자동 연결. 첫 출현 시 기존 시전 때문에 불가하면 후속 전투 스텝에서 자격 재검사, 이미 자동 실행된 기술 실패는 매 프레임 재시전 금지. 실패·소멸·타깃 교체는 임의 워프·환급 금지. 원본 시전 중 판매·조합·분해·복귀 잠금, 사망 시 준비 예약 정리.
- 원본의 **실물 객체 ID 교체형 변신**(아오키지 B0L 등)은 동일 인스턴스 자동 준비로 위장하지 않음. 능력치/소유권/특성포인트 원본 교체 포트와 영수증이 추가로 필요.
- 이전 크립 원본 사건: CTs 최초 출현→CTp/CTq 실제 사망 후 다음 생성→CTr 종료. 기본 크립 초기 객체 수치만으로 악몽 적 자동 출현 금지.
- 크립 보상: 1단계 골드1000·목재1, 2단계 공유 BFi 한 번으로 물리 h060+목재2 또는 목재7, 3단계 골드5000·목재1·fZ 1스택; 실물 h060 원본 위치 없으면 해당 난수 결과 보류.
- 기본 앱에는 원본 최초 출현 사건·악몽 최종 크립 방어/체력·유닛별 사냥 허용 자격 및 실제 이동/폼 시전 공급자·h060 위치가 없어서 크립 사냥은 아직 **실전 비활성**.
- 소스 회귀 검사 `Original323CreepPracticeWorldTests` 7건 추가, 실제 Unity/NUnit/Android 실행은 안 함. Actions 실행 결과는 사용자 요청 전 조회하지 않음.
- 크립 출전·정산·준비 중 상태를 담을 저장 스키마가 없어 안전하게 저장을 거절하며 이어하기 UI 비활성.
- 파견 중 조합·판매·분해는 원자 거래로 구현되었으나 원본 캐스팅 중 소비는 보류. 기타 스토리·전투·캐릭 구현 내용은 START_HERE 참조.
