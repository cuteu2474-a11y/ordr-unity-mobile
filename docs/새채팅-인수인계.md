## 기준 상태와 작업 경계

- **코드 기준:** `main`의 포네그리프 연결 커밋 `e2b5fce931ab65ec9c6f949cca368b219230017b`. 새 작업 전 HEAD를 다시 확인합니다. 이 인수인계 문서 정리는 **문서만 변경**하며 게임 규칙과 실행 코드를 수정하지 않습니다.
- **포네그리프(F04):** [원본 규칙](공유미션-포네그리프-시스템.md)은 공유 8종·해독 시간·금지 능력·해석자·보물 공개까지 대조됐습니다. [해독 세션](../Assets/Scripts/Combat/Original323PoneglyphSession.cs)과 컨트롤러/기록지침에 **보유 유닛 선택·정적 능력 필터·150/50초 논리 시계·중단/재시도·관측 보물 좌표 목록**을 연결했습니다. 그러나 **8종의 실제 게임 완료 사건과 보상, 해석자 3종 명령 이벤트, 동적 능력 추가/삭제 공급자, BFj 보물 좌표/전장 표식, 저장/복구**는 아직 연결되지 않았습니다. 기본 APK에서 8종을 임의 완료로 처리하지 않습니다.
- **그 밖의 코드:** 강화소 1/2 거래 18종과 JASS 공격 콜백 일부, 스토리 전장/크립·연구/상점/아이템 등은 각 시스템 문서의 코드·실기 단계를 구분해야 합니다. [현재 상태](START_HERE.md)에 있는 숫자를 완료율이나 APK 실행 증거로 해석하지 않습니다.
- **실제 검사:** 마지막으로 성공이 기록된 APK는 `0.1.364 / 53d3e240`입니다. 포네그리프 연결 푸시로 [Actions 실행 #42172448645](https://github.com/cuteu2474-a11y/ordr-unity-mobile/actions/runs/42172448645)이 시작된 것은 확인했으나 **결과는 확인하지 않았습니다**. 이후 코드의 Unity/Android 실기 및 65R 완주는 미확인입니다.

## 바로 이어서 할 일

1. **F04 실사건·보상:** `IOriginal323PoneglyphEventWitness`를 실제 스토리·객체 파괴·해왕류 격파·탐색 수집 원장에 연결합니다. 8개 개별 달성 조건·9R/30R 기한·이중 지급/원본 보상을 확인한 뒤 해금까지 확인합니다.
2. **F04 해석자·보물:** 원본 `Byh/B4Z/B6Y`의 **성공한 명령**만 전역 50초 보정에 연결합니다. 원본 BFj 보물 좌표가 있는 경우에만 BeL 위치 표식을 구현하고 수집·위습 보상과 분리합니다.
3. **F04 생명주기:** 변신/판매/파견/소멸/특수 자동 스킬의 해독 중단·잠금을 공통 경로에서 정리하고 저장/복구를 연결합니다. 코드 연결과 Android 동작 검증은 별도 판정합니다.
4. **F03 및 기타 과제:** 스토리→크립 사냥의 실제 개체 파견/복귀와 토벌 독립 진입, 시설·캐릭터 작업은 [개발 작업표](PLAYABLE_ROADMAP.md)의 고유 ID·완료 기준에서 이어 갑니다.
