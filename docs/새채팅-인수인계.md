# 새 채팅 인수인계 — 원랜디 Unity 모바일 리메이크
갱신일: 2026-10-21
저장소: https://github.com/cuteu2474-a11y/ordr-unity-mobile
작업 브랜치: main만 (새 브랜치/워크플로/CI 반복 금지)

## 목표와 고정 요구
- 원랜디 ORDR S2 2.323[C] **악몽 난이도, 이세계모드**를 Unity로 독립 제작. 기존 OpenRealm iPad 포팅이나 GrandLineDefense와 별개.
- 원작 사거리, 공속, 스킬 쿨타임/피해 공식, 타깃, 비용, 조합, 상점/도박/위습, 스토리 규칙을 **임의로 바꾸지 않음**. 게임 기능과 규칙이 그래픽/이펙트보다 우선.
- 모바일 정책: 일반 공격 자동; 확률 발동 스킬 자동; 유닛 배치 자동; 보스 타깃 자동; 수동 Q/W/R 자동; 스토리 파견 수동; 재료 조합 조작 보조; 상점·도박·위습 수동. 모바일 편의성과 원본 규칙을 분리.
- **모든 기능을 구현한 뒤 테스트**: 신규 NUnit 테스트·Unity 컴파일·기기 테스트·APK 빌드 보류. 기존 파일 유지. 한국어 커밋/업데이트.

## 현재 코드/데이터 (GitHub에서 재확인할 것)
- `data/units.json`: 도감 기준 캐릭터 271종(원본 W3X 전체 종수 검증과 별개).
- `data/character-skill-profiles.json`: 도감 상세 프로필 200종, 스킬 554항목. 대부분 `partial`, 평타 스탯/원작 rawcode/피해공식 미완료.
- `Assets/Scripts/Combat`: 데이터 기반 공격·스킬·상태효과 및 자원 소비 기초. 미확인 피해 공식은 자동 적용하지 않음.
- `Assets/Scripts/Mobile/MobileInteractionPolicy.cs`, `MobileManualInteraction.cs`, `Assets/Scripts/Unity/OrdrMobileTouchPanel.cs`: 지정한 모바일 조작 정책과 큰 터치 UI. **실제 원본 자동배치/보스선택/QWR 및 상점·도박·위습·스토리 실행 서비스는 아직 미완료**.
- `data/verified-mobile-fusion-recipes.json`: 도감 기준 7개 조합식. `AssistedFusionService.cs`: 자동 재료 선택·부족량·조합 확정 UI. 실제 조합 재료 소비·유닛 생성 미구현.
- 원본 W3X `war3map.j`의 `CWR`에서 **조합 등록 266건(TEST 1건 포함)** 추출; `data/original-jass-fusion-ordered.xz.b64`는 BGI 원본 호출 순서 보존본, `tools/unpack_ordered_jass_fusions.py`로 `data/original-jass-fusion-registry.json` 복원 가능. `tools/extract_jass_fusions.py`는 war3map.j 직접 추출 도구.
- `data/original-unit-rawcode-label-links.json`: 원본 JASS `BjB/Bi8/Bi9`로 이름·조합 능력 근거가 확보된 **81종** 대응표(초월 30, 히든 22, 불멸 12, 영원 11, 왜곡 6). **객체 rawcode/스탯 최종 검증 아님**.
- `Assets/Scripts/Mobile/OriginalJassFusionCatalog.cs`, `OriginalJassFusionPlanner.cs`, `OriginalJassKnownConditions.cs`, `OriginalJassFusionPort.cs`: 원본 UNIT/GOLD/WOOD와 UBAN/KING/RMAX 등 조건별 차단, 최종 재검사, 원자적 제작 **인터페이스**. 실제 제작은 비활성.
- `data/original-stat-evidence.json`: 패치노트 기반 기초 공격 스탯 일부(5종·7개 근거).

## 다음 작업 — 순서
1. **원본 재료 유닛 rawcode↔프로젝트 캐릭터 ID 매핑 확대**: 하위 등급·조합 재료가 현재 81종 매핑에서 누락. 실제 W3X 오브젝트/war3map.j의 유닛 이름과 등급을 대조하여 근거를 보존. 번호만 같다는 이유로 억지 매핑 금지.
2. **CWR/BGI 조건 전체 확인**: UNIT, GOLD, WOOD, ITEM, IFCT, SKPT, CHCT, RMAX, PICK, RDUN, SPEC, GREN, UPUN, UBAN, KING. 원본 `CHu/CHx`의 시전 대상/재료/재화·후속 효과까지 분석해 원작과 동일하게 처리.
3. **원자적 실제 조합 거래 구현**: 플레이어 '조합 확정' 탭 → 소유 유닛/자원/상태 최종 확인 → 정확한 비용 소비·유닛 생성/배치 → 실패 시 전체 롤백. `IOriginalJassFusionCastPolicy`, `IOriginalJassFusionAtomicCommit` 등 실제 서비스 연결.
4. 이후 자동 배치 원본 규칙, 상점·도박·위습 및 스토리, 전투 원본 수치/피해공식/나머지 스킬 완성. 모두 완성되기 전 테스트·APK 금지.
