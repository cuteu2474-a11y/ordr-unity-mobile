# 새 채팅 개발 인수인계

- 저장소 `cuteu2474-a11y/ordr-unity-mobile` / main. 작업 전 최신 SHA와 동시 변경 확인.
- 최신 구현: 캐릭터 수동 기능 공통 카드·대상 목록·소비 확인·독립 도시락·분해 진행 표시. 전장 아래 스킬/아이템 → 오른쪽 패널, 기존 전투/지갑 서비스 재사용. 코드·diff 정적 검토만, Unity/Android 실행 미검증.
- 최신 승인 UI 변경: 아군 7종 공유 시트 캐릭터 아트 우선 사용 롤백→로컬/캐시/원본 온라인 사진, 1개 배속 버튼(1→2→4→1), 전장 밖 잔상 방지 불투명 재도색·OnGUI 깊이 고정·전체 UI 패널 시트 배경 제거, 사진 프레임 내부 렌더, 조합 비선택 이름 가운데/등급 괄호/보유 N/M, 선택위습 이름 버튼만, 좌측 장식 마크 제거, 강화소 이름·가격·레벨 한 줄, 스토리 획득보상/건물별보상 UI 삭제(실제 지급 불변·그린블러드 스토리 액션 유지). 정적 구현만, Unity/Android 실행 미검증.
- 기존 [부가 목표 구현 명세](부가목표-구현명세.md)는 공유 전투 5종·개인 토벌 7종의 후속 설계이며 별도 코드 구현 승인이 아닙니다.
- 실제 출현/사망 공급자·최종 악몽 능력치·대장 버프 자료·공유 출전 복원은 미완료. 고정 증거/임의 수치로 활성화 금지.
- 초반 화력 3단계: 전체 전투 인스턴스 읽기 전용 `CaptureCombatPressure()` 분류와 하찌+흔함 5기 1~4R 추적 테스트 코드를 추가(미실행). 다음은 실제 공격/스킬 피해와 HP 변화 확인, 자동 기술 예약/대상 재선정·공식 보류 원인 분석. 기준 PLAYABLE_ROADMAP.
- APK는 기존 단발성 빌드 마커가 바뀐 main push의 1회 Unity 통합 검사 후 진행. 중복 Actions 실행/취소 금지; 새 검사 결과는 요청 시 별도 확인.
- 스토리 화면은 건물/크립 탭·목표·실제 HP·파견을 유지하고 보상 역사 목록만 제외. 초월위습은 위습, 그린블러드는 스토리의 직접 선택에 둠. 원본 보상 지급은 그대로.
- [스토리/크립 파견 계약](토벌-크립-파견-시스템.md): 복귀 없는 소비·한 번에 목적지 변경·다음 크립 연속 공격/최종 수동 복귀·이동기/변신 일괄 처리. 코드 적용과 구분.
- 공유 목표의 현재 자동 복귀/거래 잠금/전장 변경 제한은 위 계약과 구별. 별도 승인 없이 공유 목표 정책 변경 금지.
- [크립 구현 준비 조사](크립-파견-구현준비-조사.md)의 288항목 자격은 미확정. 원작 추가 확인은 현재 보류.
- 스킬·보물·전투 최신 상태는 START_HERE, 남은 구현은 PLAYABLE_ROADMAP 참조. 정식 이어하기 UI 비활성 유지.
- 기존 거래·전투·난수 엔진 재사용. 임의 원본 수치·새 보유 소환 유닛·베리 추가 금지.
