# 새 채팅 개발 인수인계

- 저장소 `cuteu2474-a11y/ordr-unity-mobile` / main. 작업 전 최신 SHA와 동시 변경 확인.
- 최신 요청: 스토리 탭 UI 다듬기. `OrdrMobileTouchPanel`의 건물/크립 하위 탭·실제 HP 막대·파견 우선 배치 반영.
- 파견 목록 기본 펼침, 개체별 기존 파견/복귀 명령 유지. 중복 선택 유닛 줄 제거, 일괄 복귀는 목록 아래.
- 후속 UI 확정: 초월위습은 위습, 그린블러드는 스토리. 기존 코드 표시와 구분하며 파견/UI 계약을 우선 적용.
- 크립 탭은 실제 월드 상태/HP 조회만. 파견 미지원 안내 유지; 정식 출현·사냥 자격·보상·저장 연결은 F03 후속.
- UI 코드 정적 검토만 수행. Unity·Android 화면/터치 실행 검증 및 APK 빌드 없음. CI 결과는 별도 요청 시 확인.
- 다음 UI 검증: 작은 가로 화면의 목록 끝 접근·필터·페이지·탭 전환·스크롤 오발동·복귀 확인·일시정지 상태.
- 최신 스킬/전투 상태는 START_HERE와 PLAYABLE_ROADMAP 참조. 기존 모델 연결을 원작 동등성으로 승격하지 않음.
- [스킬 후보98 작업표](스킬-후속-조사-작업표.md)는 등록 조건/효과 대조, 실제 실행 경로 판정 대기.
- 모리아 기여·나미 여진 등 진행 상태의 저장 차단과 복원 계약은 [상세설계11절](남은-작업-구현원리-상세설계.md) 참조. 정식 이어하기 미활성.
- 기존 거래/전투/가상 공격 엔진 재사용. 임의 원본 수치·새 보유 소환 유닛·범위 밖 기능 추가 금지.

- 최신 문서 승인: [파견/UI 계약](토벌-크립-파견-시스템.md#확정된-모바일-파견표시-계약-2026-11-16). 복귀 없는 소비·직접 목적지 이동·가능 개체만 표시·같은 상태 묶음·크립 연속 공격/최종 수동 복귀. 이동기/변신도 파견 한 번으로 처리하는 A안 확정(원본 자격·비용·쿨타임 유지); 코드 미변경.
