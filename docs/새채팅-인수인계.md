# 새 채팅 개발 인수인계

- 저장소 `cuteu2474-a11y/ordr-unity-mobile` / `main`. ORDR S2 2.323[C] 악몽·이세계 Unity 모바일.
- 스토리→크립 파견 UI/실물 전장 격리·수동 복귀, 기존 파견 중 조합·판매·분해 원자 거래 기반을 유지합니다.
- 크립 원본 사건은 CTs 최초 출현→CTp/CTq 실제 적 처치·다음 물리 등장→CTr 종료. 기본 데이터는 원본 객체 기본값으로 최종 악몽 HP/방어를 대체하지 않습니다.
- 크립 공유 지갑 보상은 CTp 골드1000/목재1, CTq 공유 BFi 1회: 실제 h060+목재2 또는 목재7, CTr 골드5000/목재1/발굴1 스택. h060 위치 증빙 없으면 같은 난수 보류.
- 조건부 크립 파견은 원본 스킬 미리보기→중복 방지 원본 시전 1회→완료 확인→실물 공격 위치 재검사→한 개체 이동. 시전 중 조합/판매/분해/복귀 차단, 자동 재시전 과금 방지.
- **신규 21종 이동기 코드:** `Original323CreepVerifiedMobilityAuthority.cs`의 `Original323CreepBlinkAbilityCatalog`가 유닛 ID/능력 rawcode/최대거리/쿨타임 원본 표를 고정 연결.
- `IOriginal323CreepVerifiedBlinkRuntime`(원본 사용·쿨타임·자원·완료)과 `IOriginal323CreepVerifiedAttackPosition`(즉시 공격 위치 vs 원본 이동 후 타격 가능 착지)이 모두 있어야 한 번의 파견 요청으로 원본 능력을 실행합니다.
- 착지 거리 > 원본 W3A 범위 거부, 착지 후보를 무시한 무료 원거리 파견 거부, 소유 인스턴스 미일치·중복 탭·원본 관측 오류 잠금 정리. 원본 완료로 인정한 착지 증빙은 한 번 파견 후 바로 폐기돼 무료 재파견에 쓰이지 않습니다. 컨트롤러 진입 `ConfigureVerifiedCreepBlinkAbilities`.
- 기본 APK는 이 원본 공급자·최종 크립 HP/방어·첫 CTs 출현 및 h060 생성 위치가 없어서 크립 사냥 실전 비활성입니다. 이동 후보21·공중45 등을 승인 명단으로 바꾸지 마세요.
- 아오키지 TR-16 B0L 실물 교체·특성포인트/레벨 승계, 카이도 I-11 폼 실제 진입은 별도 원본 근거/포트가 필요합니다.
- `Original323CreepPracticeWorldTests`의 6개 회귀 소스를 추가했고 Unity/NUnit/Android 실행 검증은 하지 않았습니다. Actions 결과는 별도 사용자 요청 때만 확인합니다.
- 출전·크립 원본 사건·난수·시전 상태 저장 스키마 부재로 이어하기 UI 비활성. 저장 재개를 임의 허용하지 않습니다.
- 현재 상태는 `START_HERE`, 다음 일감은 `PLAYABLE_ROADMAP`, 코드 위치는 `CODE_MAP`, 확정 규칙은 `토벌-크립-파견-시스템`을 참조합니다.
