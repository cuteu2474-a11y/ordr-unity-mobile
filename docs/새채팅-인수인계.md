# 새 채팅 개발 인수인계

- 저장소 `cuteu2474-a11y/ordr-unity-mobile` `main`; ORDR S2 2.323[C] 악몽·이세계 Unity Android 리메이크.
- 초반 몬스터 누적·2R 피해·4R 패배의 추가 조사·실측은 사용자 요청 전 보류, 원본 수치 임의 보정 금지.
- S01/S02 최신: `Original323StoryManualDispatch`가 소유 유닛 ID·원본 솔로 스토리 좌표를 확인하고 완료된 파견 집합만 비공개 복구. 원본 이동/복귀 명령 재호출 없음.
- 포네그리프 해독 ID를 `Poneglyph.ActiveUnitId`와 일치 확인하여 일시정지 소유권 복원. 해독 시작/50·150초 시계 재시작 금지.
- 공유 목표 `Original323SharedObjectiveWorldState`에 원본 출현·격파/후속 버프 영수증·실물 상태/계획, `SharedDeployments`에 유닛별 목적지·복귀 좌표 저장.
- `OrdrCoreCheckpoint.Validate`와 `ValidateExternalLaneState`가 실물 적/로스터/스토리·크립·해독/공유 상호 배타성과 원본 이력/미션 장부 교차 검증.
- `OrdrCombatRestoreGraphBuilder.Prepare`는 저장된 외부 전장 소유권을 전투와 결합; `OrdrAuxiliaryRestoreGraphBuilder.Prepare`는 목격·난수 포트가 있을 때 원본 공유 목표 세계 복원. 복원 중 보상/난수/실물 등장 재실행 없음.
- 이전 구현: 크립 출전/복귀권·시전 재시도 억제, 나미 여진·모리아 참여·마리아 CDh 반복, 불릿 육식 체·원본 장비 영수증 복원.
- 전투 체크포인트 v4, 엄격한 바이너리 payload **v5**. 이전 부분 초안 업그레이드/Continue UI 금지.
- 미지원: 미완료 원본 이동기/폼, 크립 원본 출현 보상, 익명 예약·위성·복합 폼, 상거래/원본 난수 서비스의 전체 원자 재결합 및 씬 교체.
- 테스트 코드는 추가만 했으며 Python/NUnit/Unity/Android/APK 실행 전 미검증. 현재 빌드/실기 정상이라고 단정 금지.
- 다음은 나머지 예약 효과·통합 상거래/지갑/난수/출전 소유권과 전체 씬 실패 원자성 보완. `AGENTS.md`·기능 대장·상태·작업표 준수.
