# 새 채팅 개발 인수인계

- 저장소 `cuteu2474-a11y/ordr-unity-mobile`, `main`; ORDR S2 2.323[C] 악몽·이세계 Unity Android.
- 사용자 지시: 초반 적 누적/2R 피해/4R 패배 추가 실측은 보류, 기능 구현 우선, 원본 수치 임의 변경 금지.
- 최신 S03: 원본 Bnm/Bnp/Bnr 시전별 e0KD 보조 주문의 원래 공격자·목표·전장·발사시각·충돌·선정/마법면역·완료 ID를 안전 복원하는 전투 장부 추가.
- 원본 공격 이벤트 시퀀스는 유닛별 마지막 순번까지 복원하여 BFi 추첨 사건이 1부터 재시작되지 않게 함.
- 진행 중 주문 복원은 같은 세션/시각의 원본 네이티브 시전 목격자가 모든 ID와 진행 이력을 검증해야 가능.
- 원본 주문·공격·난수·피해·정산을 재실행하지 않으며, 완료한 주문 ID는 재사용할 수 없음.
- 기존 S03: CJB/CJC 원본 구매/정산 기록, 원본 BFi 확률 사건, 모바일 보물/위습 권리, 파견·연구·65R 비공개 그래프.
- 전투 체크포인트 v4, 엄격 바이너리 payload **v10**. 구형 부분 초안 마이그레이션 없음.
- 미구현: 원본 네이티브 목격 공급자의 실제 앱 연결, 보물 미정산 권리/별도 전투 RNG/익명 예약/위성·폼, 씬 원자 교체 및 플레이 검증.
- 정식 Continue UI 비활성. 새 테스트 소스만 추가; Python/NUnit/Unity/Android/APK 컴파일/실행 미검증.
- 다음은 예약 기술 전체와 누락된 실물 효과·능력 소유권 복원을 묶어서 연결하고, 사용자 요청 전에는 실행 테스트를 하지 않음.
