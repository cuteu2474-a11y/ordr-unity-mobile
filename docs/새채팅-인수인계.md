## 인수인계 기준

- **코드 대조 기준:** 원본 스킬 17종 콜백 모델은 `295a09c3`까지 확인했습니다. 이후 문서 변경과 별개로 작업 전 실제 main HEAD를 다시 읽고 다른 사람의 커밋을 덮어쓰지 마세요.
- **최근 코드 경계:** 강화소 1/2의 18종 구매·평타/공속·공격력 비례 효과를 **독립 모델**에 연결했고, JASS **기존 14개 일부 효과 + 추가 17개 객체 기반 피해·상태 모델**을 연결했습니다(10개 네이티브 첫 피해·공속, 7개 다단계 일부). 소환수·투사체·면역·상태 취소 등 후속은 보류입니다. 연구소 4종은 원본 비용/오라를 실측했지만 게임 내 연구 구매는 미연결입니다. [연구·강화 명세](연구소-강화소-구현명세.md).
- **실제 검사:** 마지막으로 문서에 성공이 기록된 APK는 `0.1.364 / 53d3e240`입니다. 이후 코드의 Unity/Android 통합 검사와 휴대폰 65R 완주는 미확인입니다. 최신 Actions 결과는 요청받지 않아 조회하지 않았습니다.
- **시작 지급 일치:** 원본 `CUo/CUn`대로 **랜덤위습 5개·골드 60·진화체 1기**를 현재 코드가 지급하도록 설정돼 있습니다. 기존 테스트의 기대값도 5개이며 최신 실행 검증은 아직 하지 않았습니다.
- **원작 결과:** 현재 다수 기술은 원본 데이터를 반영한 개발용 모델이며 전체 유닛/아이템/시설/저장 기능이 완성된 것은 아닙니다. 확인되지 않은 수치나 획득 경로를 창작하지 마세요.
