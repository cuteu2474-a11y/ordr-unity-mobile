## 이어받을 상태

- 저장소는 `cuteu2474-a11y/ordr-unity-mobile`, 브랜치는 main입니다.
- 마지막 실제 검사 대상 게임 코드는 `78c86ac1`입니다. 이후 영웅 성장 코드가 추가됐으며 실행 검증 전입니다. 2026-11-05의 선행 Python 검사 3건 실패로 Unity·APK 단계가 건너뛰어졌습니다.
- 배포 가능한 기존 개발 APK는 `53d3e240`의 `0.1.364`입니다. 최신 게임 코드의 13개 커밋이 포함되지 않았습니다.
- 최신 실패의 첫 검토 대상은 카탈로그 287/288 집계, 저장된 현황 JSON, 위습 검사의 구형 문자열 기대입니다. 상세 기준은 개발 작업 문서에 있습니다.
- 영웅 경험치는 원본 58개 H 폼의 레벨 24 상한과 성장치로 계산해 개발용 공격력·공속·마나 재생에 연결했습니다. 시라호시 16/20/24 단계는 원본 4포인트 특성 발동 증거가 연결되기 전에는 적용하지 않습니다. [영웅 성장 근거](../data/original-2323C-hero-level-growth-evidence.json).
- 전체 게임은 개발용 전투 모델이며, 원작 전체 동등성과 휴대폰 65R 실기 검증을 완료하지 않았습니다.

## 작업할 때

기존 공유 전투·지갑·로스터·영수증·롤백을 재사용합니다. 출처가 있는 원본 수치와 모바일 확정 정책을 유지하고, 인터페이스나 테스트용 입력만 있는 경로를 실제 기능으로 표시하지 않습니다.

사용자가 요청한 범위에서 진행하고 Python/Unity/APK 실제 실행과 Actions 조회는 명시적 요청이 있을 때만 합니다. 문서 수정만으로 APK를 재제작하지 않습니다. main 반영 뒤 결과를 기다리지 않고 변경과 미검증 범위를 보고합니다.

날짜별 작업 보고를 이 파일에 추가하지 않습니다. 변경 이력은 Git 커밋, 원본 근거는 `data/`, 현재 상태와 다음 작업은 위 문서에서 찾을 수 있습니다.
