- 기준: `data/character-runtime-coverage.json`에 등록된 **288개 항목**(기본 카탈로그 277 + 확장 11). 전투 유닛, 변신형, 재료·보상 객체를 구분합니다.
- 상세 기술·패시브: `data/character-skill-profiles.json`의 **200개 부분 프로필 / 스킬 554개 / 패시브 295개**. 아래의 이름·일부 수치·효과 표기는 **도감 기반 일부 기록**으로, 원본의 모든 함수/실전 결과를 증명하지 않습니다.
- 프로필이 비어 있는 유닛은 **원본 기술 조사와 구현이 남은 대상**입니다. '기술이 없다'거나 '완료'로 처리하지 않습니다.
- `전투 실기 인증: 없음`은 이 자료에서 전체 원작 동등성을 승인한 개체가 0개라는 뜻이지, 실행 코드가 전혀 없다는 뜻이 아닙니다. 실제 코드 상태는 [유닛별 실행 현황](캐릭터별-구현목록.md), 잔여 작업은 [개발 작업](PLAYABLE_ROADMAP.md)을 참조하세요.
- 스킬 설명의 수치·유형은 **검색을 돕는 요약**입니다. 복합 타격·정확한 대상/확률/효과는 [원본 프로필 JSON](../data/character-skill-profiles.json), [일부 JASS 기술 조사](../data/original-2323C-next-20-skill-inventory.json)와 게임 코드에서 추적합니다. 이 표에서 생략된 필드를 0으로 간주하지 않습니다.
