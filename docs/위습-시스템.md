# 위습 시스템

> **현재 게임 설명서:** 원랜디 S2 2.323[C] **악몽·이세계모드**의 위습 획득·사용·보상을 한곳에 정리했습니다. 기준은 2026-11-05 `main` 코드입니다. **코드에 연결된 기능과 최신 APK·실기에서 확인된 기능은 다릅니다.** [현재 상태](START_HERE.md)와 [남은 작업](PLAYABLE_ROADMAP.md)을 함께 보세요.

## 1. 위습은 무엇인가요?

위습은 **유닛을 소환하거나 특정 보상·자원을 얻을 때 사용하는 재화**입니다. 모바일에서는 위습 개수를 공유 지갑에서 관리하고, 실제 보상 유닛은 보유 유닛 목록에 생성합니다. 위습마다 사용 방식이 다릅니다.

| 종류 | 원본 코드 | 사용 방식 | 무엇을 얻나요? |
|---|---|---|---|
| **랜덤위습** | `e0IX` | **위습 메뉴에서 직접 사용** | 흔함 유닛 / 골드·목재 추첨 / 도움소 마나 충전 중 선택 |
| **선택위습** | `e018` | **조합 메뉴에서 직접 사용** | 원본 자격을 충족하는 선택 대상 유닛 |
| **안흔함위습** | `e017` | **획득 시 자동 처리** | 안흔함 보상 풀 13종 중 1기 |
| **특별위습** | `e016` | **획득 시 자동 처리** | 특별함 보상 풀 33종 중 1기 |
| **희귀위습** | `e019` | **획득 시 자동 처리** | 희귀함 또는 특별함 보상 풀에서 1기 |
| **전설위습** | `e015` | **획득 시 자동 처리** | 전설 보상 풀 60종 중 1기 |
| **스토리 초월위습** | `e01A` | **스토리 보상 획득 뒤 직접 선택** | 꾸러미 보상 / 쿠마 / 레일리+해적선 중 하나 |

마지막 **스토리 초월위습**은 위의 여섯 종류와 별도로 관리하는 *스토리 보상 선택권*입니다. 일반적인 전설위습과 같은 자원이 아닙니다.

## 2. 게임에서는 어디서 사용하나요?

- **위습 메뉴 → 랜덤위습:** 세 가지 기본 기능을 펼쳐서 사용합니다. 버튼 한 번이 실행 한 번이며, 추가 확인 화면은 없습니다.
- **조합 메뉴 → 선택위습 사용:** 선택 가능한 유닛과 원본 요구 조건을 살펴보고 **바로 사용**합니다. 선택위습을 위습 메뉴에 중복 배치하지 않습니다. 위쪽 재화 표시줄에서는 개수를 확인합니다.
- **위습 메뉴 → 안흔함·특별·희귀·전설위습:** 보유 수와 자동 지급 상태를 확인합니다. 정상 조건에서는 별도의 수동 소환 버튼 없이 보상이 처리됩니다. 문제가 나면 원인과 재시도 가능한 상태를 표시합니다.
- **위습/스토리 메뉴 → 스토리 초월위습:** 지급받은 수량이 있을 때만 보상 선택지가 나타납니다. **메뉴를 여는 행위만으로 지급하거나 소비하지 않습니다.**
- **위습 메뉴 하단:** 최근 위습 사용 기록과 관련 재화 기능을 확인할 수 있습니다.

## 3. 랜덤위습으로 할 수 있는 세 가지

각 행동은 **랜덤위습 1개를 소비**합니다.

| 행동 | 보상·조건 |
|---|---|
| **① 흔함 유닛 소환** | 흔함 유닛 1기를 실제 보유 유닛으로 생성합니다. 원본 소환 풀에는 흔함 9종과 아주 낮은 확률의 해적선(`h060`, 24/10,000)이 포함됩니다. **한 번 누르면 즉시 소환**합니다. |
| **② 골드·목재 추첨** | 진행 중인 **1라운드 이상**에서 사용. **67% 목재 1개**, **33% 현재 라운드 × 75골드**를 받습니다. |
| **③ 도움소 마나 충전** | 살아 있는 실제 도움소(`h08A`)가 연결되어 있어야 합니다. 마나를 `min(100, 20 + ⌊라운드 × 1.5⌋)`만큼 충전하되 최대 마나를 넘지 않습니다. **이미 마나가 가득해도 사용하면 위습은 소비**됩니다. |

랜덤위습은 **자동으로 흔함 유닛을 뽑지 않습니다.** 플레이어가 세 행동 중 하나를 직접 선택합니다.

## 4. 자동 위습 보상과 확률

| 위습 | 보상 분기 | 분기 안에서 선택하는 방식 |
|---|---|---|
| 안흔함위습 | 안흔함 13종 | 각 1가중치(동일 비중) |
| 특별위습 | 특별함 33종 | 각 1가중치 |
| 희귀위습 | **99% 희귀함 42종 / 1% 특별함 8종** | 먼저 99:1 분기를 추첨하고, 선택된 풀에서 각 1가중치 |
| 전설위습 | 전설 60종 | 각 1가중치 |

이 숫자는 **원본 JASS에서 추출한 보상 풀**을 현재 코드가 따르는 방식입니다. 유닛별 조합 재료가 아니라 위습으로 **직접 지급되는 결과**입니다.

**희귀위습의 `A0YE` 주의:** 99% 희귀함 보상에는 `A0YE`라는 추가 능력 식별자가 따라옵니다. 현재 코드는 이를 지급된 유닛에 **미구현 정보로 보류 기록**하지만, 해당 능력의 실제 게임 효과를 발동시키지는 않습니다. 따라서 원본과 동일한 희귀위습 효과가 완성됐다고 볼 수 없습니다.

또한 풀의 가중치·분기는 반영했지만, 워크래프트 3의 **실제 난수 시드와 호출 순서까지 동일하게 재현한 것은 아닙니다.**

## 5. 스토리 초월위습 보상

원본 스토리 10단계 격파에 따른 초월위습 지급 경로와 확인된 원본 보상 사건을 모바일에 연결했습니다. 보상 선택권 **1개당 아래에서 하나**만 선택합니다.

| 선택지 | 현재 모바일 처리 |
|---|---|
| **꾸러미 상자 - 초월** | 중간 상자 유닛을 따로 만들지 않고, **골드 15,000~30,000 + 목재 14~20**을 각각 추첨해 즉시 받거나 **고유 아이템 10종 중 미획득 1종 + 목재 4개**를 선택합니다. |
| **바솔로뮤 쿠마** | 쿠마 유닛 1기를 지급합니다. |
| **실버즈 레일리 + 해적선** | 레일리 1기와 해적선 1기를 함께 지급합니다. |

고유 아이템은 **한 종류를 중복 획득할 수 없으며**, 해당 아이템이 이후 조합 재료로 사용되더라도 이미 한 번 받은 이력은 유지합니다. 보상 지급과 선택권 소비는 하나의 거래로 처리합니다.

## 6. 행운의 토큰과 위습 획득

엘리자베스 관련 원본 기능으로 얻는 **행운의 토큰 실물 3개**를 교환하면 **80% 특별위습 / 20% 희귀위습** 가운데 하나를 얻습니다. 토큰은 별도의 숫자 재화로 바꾸지 않고, 보유한 **실제 토큰 유닛 세 개**를 소비합니다. 보상 위습은 위 4절의 자동 보상 규칙으로 이어집니다.

위습을 얻는 다른 사건들은 해당 **스토리·상점·미션·유닛 효과**에서 각각 원본 지급 조건을 충족해야 합니다. 단순히 위습 버튼이나 메뉴를 열었다는 이유로 획득하지 않습니다.

## 7. 실패하면 어떻게 되나요?

1. 위습 종류·잔액·사용 가능 조건을 확인합니다.
2. 자동 지급은 보상 추첨 결과를 **보류 기록**한 뒤 실제 유닛 생성을 시도합니다.
3. 거래가 성공하면 위습 소비와 유닛 지급을 함께 확정합니다.
4. 생성·검증에 실패하면 지갑과 유닛 생성을 되돌립니다. **재시도 시 기존 추첨 결과를 유지**해 보상 재추첨을 막습니다.
5. 수동 행동은 한 번의 터치가 한 번의 실행입니다. 실행 도중 결과가 불명확한 예외가 발생하면 **임의로 자동 재실행하지 않습니다.**

보유 수·보류된 이유·최근 사용 기록은 모바일 화면에서 확인할 수 있습니다. 다만 **게임 전체를 종료하고 재실행했을 때의 전투·유닛·난수 상태까지 완전 복원하는 저장 기능은 미완성**입니다.

## 8. 현재 남아 있는 확인 사항

- **`A0YE` 실제 효과**: 희귀위습 99% 분기의 보너스 능력은 아직 보류 기록에 머물러 있습니다.
- **원본 RNG·타이밍 동등성**: 확률과 보상 풀은 연결됐지만, 원본 네이티브 난수열까지 일치하는지는 확인되지 않았습니다.
- **초기 랜덤위습 수량 정책**: 현재 시작 프로필 코드는 **5개**를 지급합니다. 과거에 논의된 **1개 시작**과 차이가 있으므로, 실제 적용할 정책을 다시 맞춰야 합니다. 이 문서 작성만으로 게임 코드를 변경하지는 않습니다.
- **실제 APK 검증**: 최신 `main`에 연결된 버튼·자동 지급·스토리 보상이 **지금 다운로드되는 이전 APK에서도 동일하게 작동한다는 뜻은 아닙니다.** 전 기능의 최신 통합 검사와 휴대폰 플레이 검증은 별도입니다.
