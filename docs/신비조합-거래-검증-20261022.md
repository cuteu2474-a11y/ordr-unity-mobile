# 신비 조합 실행 경로 및 테스트 (2026-10-22)

> **자료의 위치:** 본문은 해당 기능의 원본 근거와 작성 당시 구현 기록입니다. 현재 실행 범위는 [START_HERE](START_HERE.md), 다음 작업은 [PLAYABLE_ROADMAP](PLAYABLE_ROADMAP.md), 운영 정책은 [AGENTS](../AGENTS.md)를 우선합니다. 본문의 과거 APK/테스트 보류·사거리·다음 작업을 현재 지시로 복사하지 않습니다.

> **기록 해석 기준:** 이 문서는 단계별 조사·구현 기록입니다. 본문의 미완료·미실행·다음 작업과 정책은 해당 작성 시점 기준이며, 현재 운영·전체 현황은 [최신 인수인계](새채팅-인수인계.md)의 ‘현재 작업 기준’을 우선합니다. 특히 과거 테스트 보류, 사거리 유지, 프로젝트/원본 수치 미확보 설명을 현재 상태로 적용하지 않습니다. 원본 규칙의 근거와 미검증 한계는 계속 구분합니다.

대상: **원랜디 S2 2.323[C] 악몽 난이도 + 이세계모드 고정**.

## 이번 구현

- `OtherworldMysticFusionPreviewPort`가 검증된 거래 실행 서비스가 연결된 경우에만 신비 조합 확정 요청을 전달한다. 기본 상태에서는 미검증 조합의 확정·소모를 차단한다.
- Unity `OrdrCharacterCombatController.ConfigureOtherworldMysticFusionPreview`로 읽기 전용 조합 화면을 연결할 수 있다. 원본 세계 거래 구현을 확보한 뒤에만 `ConfigureVerifiedOtherworldMysticFusionWorld`로 실제 확정 경로를 연결한다.
- Unity Editor의 자동 데이터 동기화 목록에 이세계 신비 조합 JSON을 추가했다. 컨트롤러는 악몽 + 이세계모드의 기본 조합으로 신비 13종을 읽는다.
- `CombinedOriginalFusionPort`를 통해 기존 일반 조합 미리보기와 신비 조합 미리보기를 한 조합 탭에 함께 표시하고, 확정은 원래 등록한 서비스에만 전달한다. 단일 재료 인스턴스를 두 번 소모하거나 서로 다른 조합식 ID를 혼동하지 않도록 검증한다.
- `OtherworldMysticFusionAtomicCoordinator`는 확정 순간 **잠긴 실제 소유 유닛 목록**을 다시 읽고 고정 재료, 별개 랜덤 재료, 중복/유실 인스턴스, 스토리 파견, 골드/목재를 검사한다.
- 원본 검증 어댑터의 `TryVerifyOriginalConditions`가 해적선·행운의토큰 및 원본 원시 객체 ID, 능력 시전 제약과 부수 효과까지 검사하여 승인해야만 `TryApplyOriginalFusion`과 `Commit`을 실행한다. 거래 중 오류가 나면 `Dispose`에서 **재료/재화/결과물 모두 롤백**해야 하는 계약이다.
- Unity EditMode 모의 세계 테스트에서 3기 재료 + 10000골드/7목재를 사용해 고죠 사토루를 **원자적으로 조합 실행**하는 성공 사례와, 재사용·유실·재료 부족·파견·재화 부족·원본 조건 거절·적용 후 실패 롤백을 검증한다.

## 현재 실행 가능 범위 및 남은 연결

위 성공 사례는 **테스트 전용 모의 월드**에 원본 조건 승인을 주입한 사례다. 이를 원작 플레이에서 성공한 것으로 간주해서는 안 된다. 공개 도감 13종 조합식은 조회와 재료 추천에 사용할 수 있지만 원본 `.w3x`의 신비 유닛 rawcode, 특수 아이템 소유/소비 및 JASS 순서의 실게임 실행 연결이 아직 미확인이다.

따라서 아직 실제 게임에는 `IOriginalOtherworldMysticTransactionalWorld`의 검증된 구현을 등록하지 않았으며 **실제 캐릭터 조합·아이템 소모는 비활성** 상태다. 도감 조건만으로 성공으로 처리하거나 임의 비용을 차감하지 않는다.
