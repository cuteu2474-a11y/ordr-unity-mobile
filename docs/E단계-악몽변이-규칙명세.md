# E단계: 악몽 변이 모드 규칙 명세 (1차)

작성 기준: 2026-10-21 / 원랜디 S2 2.323[C] / 인터넷 도감 우선

## 1. 고정 개발 범위
- 난이도: 악몽만 지원
- 모드: 변이 모드만 지원
- 실행: 오프라인 싱글플레이
- 다른 난이도 및 일반 모드 선택 UI는 만들지 않음
- 변이 모드의 내부 선택·무작위 요소는 자료 확보 전까지 임의 구현하지 않음

## 2. 도감으로 확인한 권장 조합 목표
출처: https://ordr.kr/guides/gorosei (2.323, 2026-10-05 갱신)

| 오로성 | 권장 방깎 | 권장 이감 |
| --- | ---: | ---: |
| 없음 | 211 | 102% |
| 나스쥬로 | 211 | 117% |
| 워큐리 | 221 | 102% |
| 새턴 | 211 | 102% |

**주의:** 위 값은 도감 조합 계산기에서 사용하는 권장 목표이며, 실제 게임의 강제 승리·패배 조건이 아니다.

## 3. 확인된 오로성 효과
출처: https://ordr.kr/guides/gorosei
- 나스쥬로: 적 이동속도 15% 증가, 아군 공격속도 15% 감소, 라인 몬스터 체력 1,500만 증가
- 워큐리: 적 방어력 +15, 마법방어력 +15%, 보스 체력 1,500만 증가
- 새턴: 아군 공격력 30% 감소, 폭발형 피해 10% 감소, 적 체력재생 35만 증가

**적용 주의:** 효과의 계산 순서·대상 예외·중첩 방식은 검증 전이다. 도감의 오로성 '선택' UI는 계산기 기능일 수 있으며 게임 내 선택 방식으로 간주하지 않는다.

## 4. 게임 플레이 시스템별 분석
| 시스템 | 도감 확인 내용 | 미확인 핵심 |

| 변이 모드 | 전용 모드로 개발 범위 확정 | 변이 종류·추첨·발동·지속·해제 |
| 항법 | 항법별 노드 및 보상 변경 패치 존재 | 선택 시점·전체 노드·분기 |
| 라운드 | 라인 몬스터와 보스 존재 | 전체 웨이브·간격·출현표·승패 |
| 스토리 | 별도 진행 및 기여도 보상 패치 존재 | 시작·진행·보상 세부 |
| 오로성 | 위 효과 및 권장 조합 수치 | 부여 시점·확률·중복 여부 |
| 전투 | 물리/마법·방깎·이감·스턴·버프 존재 | 계산식·효과 우선순위 |
| 경제 | 목재 도박·환전소·위습 등 존재 | 비용·확률·제한·보상표 |
| 특성강화 | 일부 유닛의 스킬 변경 | 조건·대상·개별 수치 |
| 클리어 | 악몽 진행 목표 존재 | 최종 판정과 제한 |

- 오로성 저주를 실제 유닛·적 능력치에 적용하는 코드는 아직 구현하지 않음
