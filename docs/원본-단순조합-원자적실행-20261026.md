# 원본 UNIT/GOLD/WOOD 조합 실행 코어 (2026-10-26)

> **자료의 위치:** 본문은 해당 기능의 원본 근거와 작성 당시 구현 기록입니다. 현재 실행 범위는 [START_HERE](START_HERE.md), 다음 작업은 [PLAYABLE_ROADMAP](PLAYABLE_ROADMAP.md), 운영 정책은 [AGENTS](../AGENTS.md)를 우선합니다. 본문의 과거 APK/테스트 보류·사거리·다음 작업을 현재 지시로 복사하지 않습니다.

## 새로 구현된 실행 계층

원본 W3X `CWR`에 등록된 265개 비-TEST 조합을 자동으로 분류하여,
조건이 오직 `UNIT`, `GOLD`, `WOOD`로 구성된 레시피만
`OriginalJassSimpleOrderedSessionFactory`가 받아들이도록 작성했습니다.

현재 고정 데이터에서 이 조건을 충족하는 조합은 정확히 **5건**입니다.

| 원본 능력 | 결과 이름 | 주요 미연결 부분 |
| --- | --- | --- |
| A113 | 샬롯 브륄레 - 전설 | 실버즈 레일리 - 희귀 원본 재료의 카탈로그 정체성 |
| YY07 | 모비딕호 - 히든 | 원본 해적선 객체 |
| YY09 | 발라티에 - 히든 | 원본 해적선 객체 |
| YY12 | 사우전드 써니호 - 히든 | 원본 해적선 객체 |
| ET01 | 네펠타리 비비 - 영원 | 원본 객체 승인·실제 독점 거래 월드·결과 시전/생성 규칙 |

**ET01의 원본 UNIT 재료 6종과 WOOD 5개**를 실제 레지스트리에서 대조했습니다.
이 수치는 가상 밸런싱이나 임의 비용이 아닙니다.

## 거래 실행 알고리즘

- `OriginalJassFusionPort` → `OriginalJassFusionAtomicCoordinator` →
  `OriginalJassFusionOrderedWorldAdapter` → `OriginalJassSimpleOrderedSessionFactory`
  연결을 구현했습니다.
- CWR의 **실제 명령 순서**, 개별 재료의 인스턴스 ID/원본 rawcode,
  주문 결과 rawcode, 시전 대상, 골드·목재를 독점 잠금 범위에서 확인합니다.
- 소모 명령은 먼저 **메모리상 거래 명세로만 적립**합니다. 이 단계에서
  유닛·지갑에 실제 변경을 만들지 않습니다.
- 최종 `IOriginalJassSimpleFusionLockedTransaction.TryStageOriginalFusion`을 통해
  실제 월드가 원본 CHu/CHx에 맞는 재료 제거·골드/목재 차감·결과 생성·배치/후처리를
  **롤백 가능한 독점 트랜잭션 내부**에서 수행해야 합니다.
- 월드 커밋 **전**에 소모한 원본 인스턴스가 정확히 삭제됐는지,
  생성된 결과가 고유 인스턴스/정확한 rawcode/카탈로그 ID인지,
  골드·목재가 원본 금액만큼 차감됐는지 다시 관측합니다.
- 실패 또는 잘못된 결과는 Commit을 호출하지 않고 Dispose/롤백합니다.
  성공 후에도 같은 재료로 다시 제작할 수 없습니다.
- 각 조합식의 `CanCommitRecipe`를 통해 단순 레시피 하나를 연결해도
  나머지 미구현 특수 조건 조합의 **제작 버튼이 활성화되지 않도록** 했습니다.
- `OrdrCharacterCombatController.ConfigureOriginalJassSimpleCraftingWorld`
  진입점에서 검증된 `IVerifiedUnitRawcodeMap`, 실제 경제 공급자,
  월드 독점 세션, 원본 시전 대상 규칙을 연결할 수 있습니다.

## 검증 시나리오 (Unity EditMode 소스 추가, CI 미확인)

`OriginalJassSimpleFusionTransactionTests`:
1. **ET01 원본 레시피**: 시험 전용 원본 객체/전투 상태로 6재료·목재 5 차감과
   결과 비비 영원 1기 생성 및 중복 확정 차단.
2. 원본 등록식 5개만 단순 조합으로 인식. UPUN 등 추가 조건이 있는 조합 실행 차단.
3. 일부 소모 이후 원본 후속효과 실패 시 지갑·유닛 **전체 롤백**.
4. 잘못된 원본 객체와 잘못된 생성 결과를 거절하고 소모를 유지하지 않음.

테스트가 사용하는 `TestMap`과 `TestWorld`는 **TEST_ONLY**이며
실제 원본 유닛 rawcode의 생산 승인 또는 Unity 실전 월드 구현이 아닙니다.

## 실제 플레이까지 남은 필수 연결

현재 프로젝트에는 전투 월드에서 **유닛 실제 삭제와 재생성, 원본 객체 ID,
실제 지갑 차감, CHu/CHx 후속효과 및 그 전체 롤백**을 독점 상태로 제공하는
`IOriginalJassSimpleFusionTransactionalWorld` 구현체가 아직 없습니다.
또한 `OriginalVerifiedUnitObjectMap`이 요구하는 개별 원본 객체 승인 파일도
없습니다. **따라서 생산 환경에서 완전히 제작 가능한 조합은 아직 0건**입니다.

이 변경은 그 사실을 숨기지 않으며 읽기 전용 265종 카탈로그를 계속 유지합니다.
원본 맵, 임의 피해 수치, APK/iOS 빌드는 변경하지 않습니다.
