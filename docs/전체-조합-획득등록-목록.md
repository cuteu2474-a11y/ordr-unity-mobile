## 먼저 구분해야 할 점

- 원본 JASS `CWR` 등록 **266건**은 **241건의 재료 제작 경로**, **희귀위습 특수 8건**, **랜덤위습 해적선 1건**, **이세계 도박 결과 14건**, **안내용 1건**, **개발용 TEST 1건**으로 분류됩니다. **266개를 모두 제작 버튼으로 만들면 안 됩니다.**
- 제작 경로 241건은 **코드상 제작 허가 범위**입니다. 실물 재료 획득, 거래, 생성 후 후속 기술, Android 실기 확인까지 끝났다는 뜻이 아닙니다.
- 아래 **필요 실물**은 `UNIT` 조건입니다. **표시용 안내**는 `UPUN`으로, 원본의 안내 조건이지 유닛을 추가로 소모하라는 뜻이 아닙니다.
- **재화·추가 조건**의 `ITEM / PICK / CHCT / IFCT / SKPT / UBAN / KING / RMAX / RDUN / SPEC / GREN`은 원본 표기를 그대로 유지합니다. 단순히 UI에 표시하는 것과 실제 차감·횟수·해금·결과 판정은 구분합니다.
- **원본 순번**은 JSON의 등록 순서입니다. 한 결과 유닛을 만드는 **서로 다른 등록식도 각각 보존**합니다. 결과 이름만 보고 레시피를 합치면 안 됩니다.
- 빈 칸(—)은 **해당 CWR 등록에 조건이 없다는 뜻**이지, 원본 획득/시전 후속 효과가 없다는 뜻은 아닙니다. 미수집 후속 규칙은 계속 구현 대상입니다.
- 안내/개발용 경로를 포함해 **등록식의 조건 1,570개**를 누락하지 않고 실었습니다. 원본 데이터의 조건 순서는 [JSON](../data/original-jass-fusion-registry.json)에서 확인합니다.

1. 결과 `rawcode`와 유닛 실제 소환/소유·전투 스탯 연결.
