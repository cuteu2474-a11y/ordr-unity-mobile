## 현재 구현에서 확인한 처리 순서

1. 실제 몬스터 생존 여부와 원본 타격 대상 식별자를 확인한다.
2. 타격 시점의 몬스터 마법 저항력 레벨과 관측 레벨이 일치하는지 확인한다.
3. 원본에서 검증한 1~41레벨 피해 수령 배율을 확인한다.
4. 마법 저항 감소, 마법 피해 증폭, 전체 피해 증폭, 폭발 피해 증폭, 원본 마법 저항 레벨 증가 효과가 남아 있으면 독립적인 원본 증빙을 요구한다.
5. 원본에서 관측한 **마법 저항 적용 전 피해**에, 실제 적용이 확인된 경우에만 몬스터 마법 저항 배율을 한 번 적용한다. 다른 증폭 효과를 임의로 다시 곱하지 않는다.
6. 검증된 체력 변환 정책의 결과와 원본 실제 체력 감소량을 비교한다. 일치하지 않으면 해당 타격을 승인하지 않는다.

## 추가로 검증해야 할 사항

- 원본 `war3map.j`에서 마법 저항 감소·마법 피해 증폭·전체 피해 증폭의 실제 호출 관계와 시간 순서를 확인해야 한다. **현재 확인한 C# 파일만으로 중첩 공식을 확정할 수 없다.**
- 원본 엔진의 최종 체력 단위 변환 방식과 원본 투사체 대상 선정 결과를 별도 증빙으로 확보해야 한다.
- 효과 만료·갱신이 주문 시전과 명중 사이에 발생하는 사례를 원본 이벤트 기록으로 검증해야 한다.
- 검증되지 않은 효과를 합산하거나 곱하는 임의 계산은 금지한다.

## 개발 원칙

이 문서는 코드 분석에서 확인한 경계 조건을 정리한 것입니다. 원본 피해 중첩 수식이 검증됐거나 실제 게임 플레이가 완성됐다는 의미가 아닙니다. 원본 맵과 APK는 변경하지 않습니다.
