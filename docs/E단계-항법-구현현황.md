## 코드 변경

- `NavigationProgression`: 검증된 항법 노드 목록을 외부에서 주입받아 경로 선택·선행조건·획득 상태를 관리한다.
- 원작 항법 노드, 비용, 보상, 개방 라운드는 아직 등록하지 않았다.
- 테스트용 가상 노드는 테스트 코드 안에서만 사용한다.
- 경로 선택을 단 한 번만 허용하는 것은 현재 **엔진 인터페이스의 임시 제약**으로, 실제 원작에서 재선택 가능한지 확인되면 수정해야 한다.

## 미확인 항목

1. 이세계모드의 정확한 시작·선택·발동 조건
2. 항법 노드의 전체 목록, 경로, 선행조건, 비용과 보상
3. 노드 해금 시점 및 항법 경로 변경 가능 여부
4. 오로성 저주의 부여 시점과 이세계모드의 관계

## 검증 현황

- GitHub 파일 등록 및 재조회: 가능
- Unity/C# 컴파일·NUnit 테스트 실행: 아직 미검증
- 실제 원작 플레이와 일치 여부: 미검증

도감에서 확인할 수 없는 게임 필수 수치는 임의로 만들지 않는다. 필요할 때만 W3X의 해당 부분을 확인한다.
