# 원본 CWR 단순조합 공유 지갑 연결

- 실제 CharacterCombatRuntime의 보유 인스턴스와 같은 SharedEconomySession을 읽는 브리지 구현.
- EconomyWallet.TryExchange로 원본 CWR의 금/목재를 차감한 후 네이티브 유닛 거래 완료 시에만 확정.
- 유닛 거래 실패 및 예외 시 RestoreState로 잔액 및 1회 보상 기록 복원.
- 소스 검증된 원본 객체 식별자, 시전 대상, 독점 및 복원 가능한 원본 유닛 교체 월드를 요구하며 미연결 시 조합 실행 거부.
- 비비 영원(ET01) 원본 재료 6종, 목재 5 조건을 시험용 월드로 검사.
- 260개 특수 조건 조합은 실행 차단 유지.
- 원본 W3X, 확률 및 수치 변경 없음. APK 제작 없음.

현재 실제 게임의 스킬 시간표와 캐릭터 제거까지 복구하는 네이티브 유닛 거래는 미구현입니다. Unity CI 성공 여부도 아직 미확인입니다.
