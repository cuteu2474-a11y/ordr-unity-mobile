# D단계: 조합·상점·도박·위습 구현 현황

기준: ORDR S2 2.323[C], 악몽 이세계모드 / 2026-10-21

## 2.323 도감에서 확인
- 조합식은 유닛 여러 종류와 추가 재화·아이템을 함께 요구할 수 있다.
- 하위 유닛은 여러 상위 조합에 중복으로 필요할 수 있다.
- 2.323 패치에서 환전소 노드의 위습 1개 당첨 미지급 버그가 수정됐다.
- 도감의 유닛 수량 입력/조합 추천 UI는 원작 게임의 실제 조합 실행 방식과 구별한다.

출처:
- https://ordr.kr/guides/beginner
- https://ordr.kr/guides/team-building
- https://ordr.kr/patch-notes

## 이번에 작성한 C# 로직
- `ResourceBundle`: 중복 재료 수량 합산 및 양수 검증
- `EconomyWallet`: 자원·유닛 수량을 한 거래로 원자적으로 차감/지급
- `CatalogTransaction`: 조합, 상점 구매, 위습 교환에 공통으로 사용할 거래 명세
- `GamblingTable`: 원작 확률 미확인 상태에서 도박 실행 차단
- NUnit 테스트 4개: 조합 소비, 부족한 재료 거래 실패, 오버플로 롤백, 미검증 도박 차단

## 미구현 및 검증 필요
- 도감 전체 조합식의 실제 데이터 등록
- 원작에서 조합 재료로 쓰는 유닛의 배치/소유 조건과 실제 제거 처리
- 상점 품목, 가격, 쿨타임 및 구매 제한
- 위습 종류, 소환 및 교환 기능, 환전소 노드
- 도박 종류별 원작 확률, 비용, 보상 및 횟수 제한
- 게임 내 실제 유닛/재화 상태와 거래 엔진 연동
- Unity 장면, 터치 UI, Android APK

**주의:** 테스트 데이터의 `test-*` 값은 엔진 테스트용이며 원작 데이터가 아니다. Unity 컴파일과 NUnit 테스트는 아직 실행되지 않았다.
