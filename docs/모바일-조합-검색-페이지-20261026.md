# 모바일 조합창 검색·필터·페이지 이동 (2026-10-26)

## 구현

- 기존 전체 원본 조합 미리보기를 화면에서 한 번에 렌더링하지 않고 8건씩 표시합니다.
- 캐릭터 이름, 재료 이름, 부족한 재료, 조합식 ID를 검색합니다.
- **재료 확보만** 필터를 제공하되, 이는 유닛 재료 확보 여부일 뿐 원작 추가 조건·재화·실제 제작 승인과 다릅니다.
- 페이지 이동으로 모든 조합식을 확인할 수 있으며, 기존 조합 확정 서비스의 원본 재검증과 원자적 거래 계약을 유지합니다.
- 읽기 전용 JASS 등록식도 기존 앞 18개 제한을 해제하고 10건씩 검색·탐색합니다.
- 선택위습 Merge, 조합 확정, 원본 피해·경제 수식은 변경하지 않았습니다.

## 검증 범위

`MobileFusionBrowserTests`에서 265건 페이지 구간, 한국어 이름·재료·부족 항목 검색,
원본 ID 대소문자 검색, 재료 확보 필터, 빈 검색 결과, 잘못된 페이지 크기를 테스트합니다.
테스트에 등장하는 가상 레시피는 UI 동작 검증용이며 원본 조합법이 아닙니다.
실제 원작 조합 소비 포트가 없는 경우 제작은 계속 비활성입니다.

## 남은 일

신비함·원본 JASS의 추가 비용·특수 조건을 원본과 독립 대조한 다음 제작 실행 포트를 연결해야 합니다.
APK/iOS 테스트 빌드는 아직 만들지 않습니다.
