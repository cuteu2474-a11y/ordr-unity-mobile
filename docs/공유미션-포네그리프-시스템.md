# 공유 도전과제 8종 · 포네그리프 해독

> **원본 확인 명세 / 모바일 실행 검증 전.** ORDR S2 2.323[C]의 추출 `war3map.j`를 직접 대조했습니다. 이 문서는 **8개 공유 도전과제 → 해금 → 해독 시도 → 보물 위치 공개**의 실제 원본 규칙을 설명합니다. 개인미션 18종·개인 토벌 7종과는 별도입니다. 모바일에서는 **베리 지급·저장·UI를 구현하지 않지만 보물 공개는 유지**합니다.

## 플레이어가 알아야 할 핵심

- 공유 도전과제 **8개를 전부 완료**하면 숨겨진 **포네그리프 해독**이 해금됩니다. 단순히 정규 라운드를 넘기는 것으로 해금하지 않습니다.
- 해독 가능한 유닛이 원본 해독 지역에 들어가면 **1기만 해독에 착수**합니다. 도중에 유닛이 죽으면 실패하며, 성공하기 전에는 다시 시도할 수 있습니다.
- 기본 해독 시간은 **150초**, `포네그리프 해석자` 조건(`aJ`)이 활성화되면 **50초**입니다. 해독 중 대상 유닛은 정지합니다.
- **해독에 성공하면 현재 존재하는 보물의 위치 표식을 모두 공개**합니다(`BeL`). **보물을 자동으로 획득하거나 새로 생성하지 않습니다.**
- 원작의 **베리 1개** 지급 분기는 모바일에서 제외합니다. 보물 공개 기능은 베리와 독립적으로 실행해야 합니다.

## 1. 해금에 필요한 공유 도전과제 8개

아래의 **조건은 원본 퀘스트 설명과 실제 이벤트 함수**를 대조한 결과입니다. 나열 순서는 클리어 강제 순서가 아닙니다. 모든 참가자가 공유하는 보상은 싱글플레이에서 자신에게 **한 번** 지급합니다.

| 원본 도전과제 | 성공 조건·시점 | 원본 실제 보상(참가자별) | 함수 |
|---|---|---|---|
| **룸바 해적단 영혼 해방** | **1시 지역**의 영혼 관련 파괴물 `Ck` 파괴 | 골드 **3,000** · 목재 **1** · 아이템 발굴 **1회** | `CNa → CNZ → CNY` |
| **정의의 문 파괴** | **3시 지역** 정의의 문 `Ci` 파괴 | 흔함선택위습 **2** · 골드 **20,000** · 아이템 발굴 **1회**. 이후 해군대장 3종 중 **1기 무작위 등장** | `CNJ → CNI → CNH` |
| **샨도라의 황금 종** | **7시 지역** 황금종 파괴물 `Cj` 파괴 | 랜덤위습 **1** · 골드 **3,000** · 아이템 발굴 **1회**. 별도 **5%** 추첨에서 고유 아이템 `AI01`을 **미획득 상태일 때만** 지급 | `CM7 → CM6 → CM5` |
| **해왕류 퇴치** | **9시 지역** 해왕류 실제 격파 | 흔함선택위습 **1** · 골드 **3,000** · 아이템 발굴 **1회** · 보유 영웅에게 경험치 **325** | `CNW → CNV → CNU/CNT` |
| **신속한 철거** | **9라운드 시작 전** 스토리 **[2] 알라바스타** 파괴 | 랜덤위습 **1** | `CNN → CNM → CNL` |
| **파괴왕** | **30라운드 시작 전** 스토리 **[11] 드레스로자** 파괴 | 목재 **2** · 아이템 발굴 **1회** | `CNF → CNE → CND` |
| **해군대장 저지** | 정의의 문 파괴 후 등장한 해군대장 격파 | 특성포인트 **1** · 목재 **1** · 보유 영웅 경험치 **600**, 등장한 대장의 종류에 따른 신속함/강렬함/냉철함 버프 | `CM3 → CM2 → CM1/CM0` |
| **트레져 헌터** | `탐색`으로 발견한 보물 수 `YI ≥ 2×n9+6` (**솔로 16개**) | 목재 **2** | `CNf → CNe → CNd` |

**구분할 사항**
- 황금종의 **5% `AI01` 추가 추첨**은 보상 메시지 본문과 별도로 `CM5` 안에 있습니다. 이미 같은 아이템을 획득했다면 `BhZ` 검사로 **중복 지급하지 않습니다**. 이 5%는 기존 스토리의 개별 고유 아이템 드롭과 **별개 사건**입니다.
- **정의의 문 파괴**와 뒤이어 나오는 **해군대장 저지**는 다른 두 미션이며 보상도 따로 줍니다.
- 크립 처치·패스트유니크는 원본 퀘스트 패널에 등록되지만 **개인 도전**이므로 위 **공유 8개 카운터 `ni`에 더하지 않습니다**.
- `CNE`는 `X3 >= 30`, `CNM`은 `X3 >= 9`일 때 완료를 거절합니다. 기한을 넘긴 뒤 해당 건물을 파괴해도 도전과제를 달성한 것으로 처리하면 안 됩니다.
- 원본 완료 콜백은 각 도전과제의 `완료` 플래그를 내리고 공유 카운터 `ni`를 **1씩 증가**시킵니다. 여덟 번째 완료 시 `CMy`가 해독을 활성화합니다. 임의로 8개 보상을 한 사건에 지급하지 않습니다.

## 2. 포네그리프 해독 절차

| 단계 | 원본에서 확인한 동작 | 모바일에서 유지할 상태 |
|---|---|---|
| **해금** | `ni`가 **8개**에 도달하면 `CMy`가 `nY=true`로 전환 | 공유 8종 완료와 해독 가능 여부를 별도로 저장 |
| **대상 진입** | 원본 해독 구역 `Cd`에 유닛이 들어오면 `CMx`가 자격 확인. 일부 기술을 가진 유닛은 거절 | 보유 **실제 유닛 인스턴스**가 자격을 만족할 때만 진입/해독 가능 |
| **중복 제한** | `nZ=true`인 동안 다른 유닛의 시도를 거부 | 동시에 **1기**만 해독, 중복 탭·파견 중복 불가 |
| **해독 시간** | 기본 **150초**, 해석자 보정 `aJ=true`면 **50초**; `PauseUnit(true)` | 게임 논리 시간·시전 유닛·남은 시간·일시정지 유지 |
| **실패** | 진행 유닛이 사망하면 `CMv → CMu(false)`로 종료. 대기 중 조건을 잃거나 시간이 만료할 때도 실제 생존 확인 | 실패에 **베리/공개 보상 없음**. 생존 상태·재시도 권리를 잘못 소모하지 않음 |
| **성공** | `CMw`: 유닛 정지 해제 → `BeL()` → `CMu(true)` | 원본 보물 좌표의 시각 표식 공개, **해독 권리 종료**와 보물 수집 분리 |

**원본의 자격 필터:** `CMx`는 `A080`, `A0B9`, `A0BB`, `A0BA`, `A09G`, `A17T`, `A0B8`, `A800` 중 하나를 가진 유닛을 거절하고 `Aloc` 보유 유닛도 제외합니다. 이것은 **원본 능력 ID 조건**이며, 어떤 모바일 등급 전체를 임의로 금지하는 규칙이 아닙니다. 대상별 실제 능력 매핑은 구현 시 확인해야 합니다.

**해석자 보정의 발동 증거:** `aJ=true`는 로빈(`Byh`), 베가펑크(`B4Z`), 오뎅(`B6Y`)의 원본 획득 후속 함수에서 확인됩니다. 보정이 켜진 상태에서는 **그 시도만 50초**를 사용합니다. 현재 보정 상태의 전파·리셋·모바일 영구화는 별도 코드 검증이 필요합니다.

**보물 위치 공개의 경계:** `BeL`은 현재 원본 보물 배열 `X9/YC`를 순회해 **위치가 있고 아직 표식이 없는 보물**에 효과를 설치합니다. `X7=0`이면 오류 안내 후 위치를 표시하지 않습니다. `BeI`의 탐색/획득을 호출하지 않으므로 **발견 수 `YI`, 보물 잔여 수, 위습 보상은 자동으로 변하지 않습니다**. 향후 재배치된 보물까지 영구 자동 공개된다고 가정하지 않습니다.

## 3. 모바일 화면·저장 구현 기준

- **왼쪽 미션:** 공유 8개 목표의 이름·완료 여부·기한·보상을 보여 줍니다. 개인미션 18종과 진행 장부를 섞지 않습니다. 수동 소환이 아니라 **실제 스토리/보물 탐색/격파 사건**으로 달성합니다.
- **왼쪽 기록지침:** 포네그리프의 **잠김/해독 가능/진행 중/성공**과 해독 대상·남은 시간, 해독 성공 후 **보물 위치 보기** 상태를 연결합니다. 원본의 지역 진입은 모바일에서 **선택한 실제 자격 유닛의 해독 지시**로 대응할 수 있으나, 현재 화면에서 구현되었다는 뜻은 아닙니다.
- **공통 사건/저장:** 8개 개별 완료 영수증, `ni`, 해금 `nY`, 해석자 `aJ`, 해독 진행 유닛·타이머·결과, 보물 공개 표식 상태를 저장합니다. 대상 판매/조합/사망/파견 이동과 휴대폰 일시정지가 겹쳐도 중복 완료하지 않아야 합니다.
- **베리 제외:** 원본 `CMw`의 `Sx` 지급 코드는 **참고 근거만** 남기고 모바일 지갑·UI·영수증에는 넣지 않습니다. `BeL` 보물 공개 효과만 별개로 유지합니다.
