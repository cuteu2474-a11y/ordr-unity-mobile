# 공유 도전과제 8종 · 포네그리프 해독

> **원본 규칙 확인 문서.** ORDR S2 2.323[C]의 `war3map.j`와 유닛 객체를 대조했습니다. 개인미션·토벌과 별개인 **공유 도전과제 8종 → 포네그리프 해독 → 보물 위치 공개**를 다룹니다. 모바일에서는 **베리만 제외**합니다. 실제 코드·검사 상태는 [현재 상태](START_HERE.md), 남은 일은 [개발 작업 F04](PLAYABLE_ROADMAP.md)를 참고하세요.

## 플레이어가 알아야 할 핵심

- 공유 도전과제 **8개를 전부 완료**하면 숨겨진 **포네그리프 해독**이 해금됩니다. 단순히 정규 라운드를 넘기는 것으로 해금하지 않습니다.
- 해독 가능한 유닛이 원본 해독 지역에 들어가면 **1기만 해독에 착수**합니다. 도중에 유닛이 죽으면 실패하며, 성공하기 전에는 다시 시도할 수 있습니다.
- 기본 해독 시간은 **150초**, `포네그리프 해석자` 조건(`aJ`)이 활성화되면 **50초**입니다. 해독 중 대상 유닛은 정지합니다.
- **해독에 성공하면 현재 존재하는 보물의 위치 표식을 모두 공개**합니다(`BeL`). **보물을 자동으로 획득하거나 새로 생성하지 않습니다.**
- 원작의 **베리 1개** 지급 분기는 모바일에서 제외합니다. 보물 공개 기능은 베리와 독립적으로 실행해야 합니다.

## 1. 해금에 필요한 공유 도전과제 8개

아래의 **조건은 원본 퀘스트 설명과 실제 이벤트 함수**를 대조한 결과입니다. 나열 순서는 클리어 강제 순서가 아닙니다. 모든 참가자가 공유하는 보상은 싱글플레이에서 자신에게 **한 번** 지급합니다.

| 원본 도전과제 | 성공 조건·시점 | 원본 실제 보상(참가자별) | 함수 |
|---|---|---|---|
| **룸바 해적단 영혼 해방** | **1시 지역**의 영혼 관련 파괴물 `Ck` 파괴 | 골드 **3,000** · 목재 **1** · 아이템 발굴 **1회** | `CNa → CNZ → CNY` |
| **정의의 문 파괴** | **3시 지역** 정의의 문 `Ci` 파괴 | 흔함선택위습 **2** · 골드 **20,000** · 아이템 발굴 **1회**. 이후 해군대장 3종 중 **1기 무작위 등장** | `CNJ → CNI → CNH` |
| **샨도라의 황금 종** | **7시 지역** 황금종 파괴물 `Cj` 파괴 | 랜덤위습 **1** · 골드 **3,000** · 아이템 발굴 **1회**. 별도 **5%** 추첨에서 고유 아이템 `AI01`을 **미획득 상태일 때만** 지급 | `CM7 → CM6 → CM5` |
| **해왕류 퇴치** | **9시 지역** 해왕류 실제 격파 | 흔함선택위습 **1** · 골드 **3,000** · 아이템 발굴 **1회** · 보유 영웅에게 경험치 **325** | `CNW → CNV → CNU/CNT` |
| **신속한 철거** | **9라운드 시작 전** 스토리 **[2] 알라바스타** 파괴 | 랜덤위습 **1** | `CNN → CNM → CNL` |
| **파괴왕** | **30라운드 시작 전** 스토리 **[11] 드레스로자** 파괴 | 목재 **2** · 아이템 발굴 **1회** | `CNF → CNE → CND` |
| **해군대장 저지** | 정의의 문 파괴 후 등장한 해군대장 격파 | 특성포인트 **1** · 목재 **1** · 보유 영웅 경험치 **600**, 등장한 대장의 종류에 따른 신속함/강렬함/냉철함 버프 | `CM3 → CM2 → CM1/CM0` |
| **트레져 헌터** | `탐색`으로 발견한 보물 수 `YI ≥ 2×n9+6` (**솔로 16개**) | 목재 **2** | `CNf → CNe → CNd` |

**모바일 원본 후속 사건 연결(2026-11-07, 코드 단계·실행 미검증):**

- 공유 목표의 동일한 원본 등장 ID가 중복 전달되면 **원본 능력치·좌표가 완전히 동일한 경우에만** 기존 적을 반환합니다. 정의의 문 뒤 대장 등장 차감이 일시 실패했다면 해당 이벤트 재전달에서 재시도하며, 재소환·중복 차감은 금지합니다. 완료된 적의 동일 사망 이벤트도 중복 지급 없이 접수합니다.
- 5종 공유 목표의 실제 등장/격파 근거는 별개입니다. 기본 APK에 최종 악몽 체력·방어·좌표·원본 사건 공급자가 없어 5종 전투는 여전히 활성화되지 않았습니다.
- 룸바·정의의 문·황금종·해왕류·파괴왕의 `아이템 발굴 1회`는 독립적인 미사용 장부 대신 원본 `Bhd`가 충전하는 **공통 일반 발굴 스택 `fZ`**으로 같은 미션 영수증에서 지급합니다. 상한 **10회**를 넘으면 충전만 생략하며 다른 골드·위습·목재 보상은 지급합니다. 기존 `BhS/BhT` 발굴 엔진이 실제 스택을 소모하고 일반/유니크 아이템을 추첨합니다.
- 해군대장별 버프도 **해당 대장의 원본 버프가 실제 적용된 사건**을 확인해야 미처리 1건을 차감합니다. 대장 격파 사건보다 버프 적용 사건이 먼저 도착할 수 있으므로 증거를 보관했다가 격파/보상 완료 후 정산합니다. 모바일에서 공격력·공속·쿨타임을 임의로 올리는 처리로 대체하지 않습니다.
- 별도의 버프 사건 공급자는 `IOriginal323SharedMissionFollowUpWitness`로 게임 시작 전 한 번 등록하며, **실제로 적용된** 원본 대장 버프 이벤트 ID와 대상 대장의 rawcode를 증빙합니다. 기본 APK에 대장 버프 공급자·실제 버프 적용 로직이 없고, 고유 아이템의 개별 사용 효과/외형 및 실기 검증도 남아 있습니다.

**구분할 사항**
- 황금종의 **5% `AI01` 추가 추첨**은 보상 메시지 본문과 별도로 `CM5` 안에 있습니다. 이미 같은 아이템을 획득했다면 `BhZ` 검사로 **중복 지급하지 않습니다**. 이 5%는 기존 스토리의 개별 고유 아이템 드롭과 **별개 사건**입니다.
- **정의의 문 파괴**와 뒤이어 나오는 **해군대장 저지**는 다른 두 미션이며 보상도 따로 줍니다.
- 크립 처치·패스트유니크는 원본 퀘스트 패널에 등록되지만 **개인 도전**이므로 위 **공유 8개 카운터 `ni`에 더하지 않습니다**.
- `CNE`는 `X3 >= 30`, `CNM`은 `X3 >= 9`일 때 완료를 거절합니다. 기한을 넘긴 뒤 해당 건물을 파괴해도 도전과제를 달성한 것으로 처리하면 안 됩니다.
- 원본 완료 콜백은 각 도전과제의 `완료` 플래그를 내리고 공유 카운터 `ni`를 **1씩 증가**시킵니다. 여덟 번째 완료 시 `CMy`가 해독을 활성화합니다. 임의로 8개 보상을 한 사건에 지급하지 않습니다.

## 2. 포네그리프 해독 절차

| 단계 | 원본에서 확인한 동작 | 모바일에서 유지할 상태 |
|---|---|---|
| **해금** | `ni`가 **8개**에 도달하면 `CMy`가 `nY=true`로 전환 | 공유 8종 완료와 해독 가능 여부를 별도로 저장 |
| **대상 진입** | 해독 구역 `Cd` 진입 시 `CMx`가 능력 ID·진행 상태를 검사. **소유자/진영을 허용 대상으로 한정하는 검사는 없음** | 모바일에서는 플레이어가 **실제로 보유·조작 가능한 유닛**을 선택해 지시. 이 조작상 안전장치는 원본의 소유자 검사라고 주장하지 않음 |
| **중복 제한** | `nZ=true`인 동안 다른 유닛의 시도를 거부 | 동시에 **1기**만 해독, 중복 탭·파견 중복 불가 |
| **해독 시간** | 기본 **150초**, 전역 해석자 플래그 `aJ=true`면 **50초**; `PauseUnit(true)` | **시도 시작 순간** 전역 보정을 읽어 타이머 150/50초를 확정. 도중 보정 활성화로 기존 타이머를 재설정하지 않음 |
| **실패** | 해독 유닛 사망 시 `CMv → CMu(false)` 즉시 종료. 타이머 종료 시 `Bcu(na)`가 거짓이면 `CMw → CMu(false)` | 실패에 **공개 보상 없음**. 재시도 권리를 유지하고, 생존 유닛이 어떤 종료 경로에서든 정지 상태로 남지 않도록 정리 |
| **성공** | `CMw`: 유닛 정지 해제 → `BeL()` → `CMu(true)` | 원본 보물 좌표의 시각 표식 공개, **해독 권리 종료**와 보물 수집 분리 |

**원본의 자격 필터:** `CMx`는 `A080`, `A0B9`, `A0BB`, `A0BA`, `A09G`, `A17T`, `A0B8`, `A800` 중 하나라도 **현재 유닛 인스턴스에 붙어 있으면** 거절하며, `Aloc` 보유 유닛도 제외합니다. 아래는 원본 맵의 **유닛 기본 능력·게임 내 표시 이름까지 전수 대조한 결과**입니다. 모바일 등급만으로 판정하면 누락됩니다.

**왜 등급만 검사하면 안 되나요?**

- 대부분의 제외 능력은 **판매 버튼**이지만 `A800`은 랜덤전용 표시입니다. 단순히 `판매 가능`이나 `희귀 이하`만 거르면 랜덤전용 14종이 빠집니다.
- `A080`에 **전설 등급 망가진 장난감 `h07H`**도 포함됩니다. 반대로 모든 전설이 해독 불가라는 뜻은 아닙니다. **현재 실물의 실제 능력 목록**을 검사해야 합니다.
- **게임 도중 추가되는 예외:** 원본 `CJH`는 압살롬 도박 **실패 55% 분기**에서 좀비 `h00H`를 만든 뒤 `UnitAddAbility(..., A09G)`를 호출합니다(JASS 49275~49285행). `h00H`의 기본 능력표에는 `A09G`가 없으므로 **유닛 종류 ID만 보고 허용하면 오판**합니다. 모바일은 생성·조합·변신 후에도 **인스턴스별 능력 부여 상태**를 반영해야 합니다.
- **별도 제외 조건 `Aloc`:** 원본 `Units/UnitAbilities.slk`의 1,493개 기본 유닛 객체 중 **999종**에 이미 `Aloc`가 있으며, 위 114종과 기본 데이터상 겹치지 않습니다. 원본 JASS에서 일시적으로 `Aloc`를 추가하는 경로도 확인됩니다(27838·27844행). 따라서 기본 능력표 기준으로 위 두 필터를 통과하는 **380종은 단순 코드상 후보**일 뿐, 그 모두가 실제 조작·진입 가능한 해독 유닛이라는 보장은 없습니다.
- **판정 시점:** `CMx`는 유닛 종류 ID나 도감 등급을 조회하지 않고 `GetUnitAbilityLevel(진입 유닛, ID)>0`를 각각 검사합니다. **개별 실물의 현재 상태**가 결정적입니다. 해독 가능 여부를 표기할 때는 유닛 생성 직후 한 번 판정한 값을 영구 캐시하지 않습니다.

**원본 데이터 출처:** 동일한 W3X 안의 `Units/UnitAbilities.slk`(기본 능력), `Units/CampaignAbilityStrings.txt`(판매 기술의 실제 이름·설명), `Units/CampaignUnitStrings.txt`(유닛 표시명)를 서로 결합하고 `CMx`의 8개 능력 검사와 맞췄습니다. 별도 소문·등급 추정이 아닙니다. **원본 정적 객체 대조 완료 ≠ 모바일 실행 완료**입니다.

**해석자 보정의 발동 증거 — 전역·세션 내 지속 상태로 확인:** `aJ`는 원본 JASS에서 **전역 boolean으로 `false` 초기화**됩니다(398행). 로빈 `Byh`, 베가펑크 `B4Z`, 오뎅 `B6Y`의 **성공한 조합/전환 명령** 후에만 `true`가 되며(24351·32169·34647행), 추출 JASS 전체에서 이를 `false`로 되돌리는 대입은 없습니다. 세 함수는 `Bcx`가 등록한 플레이어 **채팅 명령**의 콜백이며, `BI2`를 통한 조합 성공 검사가 앞섭니다. 따라서 **해독을 시도하는 유닛이 로빈·베가펑크·오뎅일 필요도 없고**, 보정 유닛을 현재 보유하거나 해독 지역에 동행시킬 필요도 없습니다. 멀티 원본에서는 한 플레이어가 활성화해도 **게임 전체**가 50초 보정을 사용합니다. 모바일 싱글에서는 이 효과를 **해당 판의 공통 달성 상태**로 저장하며, 다음 판까지의 계정 영구 특전으로 만들지 않습니다. 해당 명령을 실제로 성공시킨 경우에만 플래그를 세웁니다.

**보물 위치 공개의 경계:** `BeL`은 현재 원본 보물 배열 `X9/YC`를 순회해 **위치가 있고 아직 표식이 없는 보물**에 효과를 설치합니다. `X7=0`이면 오류 안내 후 위치를 표시하지 않습니다. `BeI`의 탐색/획득을 호출하지 않으므로 **발견 수 `YI`, 보물 잔여 수, 위습 보상은 자동으로 변하지 않습니다**. 향후 재배치된 보물까지 영구 자동 공개된다고 가정하지 않습니다.

## 3. 이벤트·중단·재시도에서 놓치기 쉬운 원본 조건

1. **해금은 공유 미션 사건에 반응합니다.** 각 미션 완료 콜백은 자신의 1회 완료 플래그를 내리고 `ni`를 정확히 1 증가시킵니다. 증가 **전 `ni >= 7`**이면 `CMy`를 호출해 해독을 개방합니다. 다른 화면을 열거나 라운드가 지나야 해금되는 대기 상태가 아닙니다. 모바일에서도 **8번째 완료 사건 직후** 해독을 열고 한 미션의 중복 보상/카운트 증가를 막습니다.
2. **해독은 지역 진입 사건 한 번으로 시작합니다.** `BDQ(Cd, CMx)`는 직사각형 구역 진입 트리거이고, `CMx`의 `GetOwningPlayer`는 실패 안내를 보낼 대상을 얻을 뿐 **소유권 허용 여부를 검사하는 조건은 아닙니다**. 모바일의 직접 지시 UI는 `대상 실물 보유`를 확인하도록 설계합니다. 이를 원작의 소유자 제한으로 소급 해석하지 않습니다.
3. **보정은 시작할 때 한 번 판정합니다.** `CMx`는 `aJ`를 읽고 즉시 **50초 또는 150초 단일 타이머**를 만듭니다. 해독 중 다른 조합으로 해석자 효과를 얻어도 시작한 타이머를 소급 단축하는 코드는 없습니다.
4. **실패와 성공의 해금 플래그 처리가 다릅니다.** `CMu(false)`는 유닛/타이머/죽음 감시를 정리하고 `nY`는 유지해 **다시 시도**할 수 있게 합니다. `CMu(true)`만 `nY=false`로 바꿔 재시도를 끝냅니다. 한 번 실패했다고 공유 8개를 다시 완료하게 하거나 성공 뒤 같은 보상을 반복하면 안 됩니다.
5. **원본 중단 처리의 구멍은 모바일에서 재발 방지합니다.** 원본 `CMw`의 성공 분기에는 `PauseUnit(na,false)`가 있지만 `CMu(false)`에는 그 호출이 없습니다. 일반적인 사망 실패는 이미 죽은 유닛을 정리하는 흐름이나, 모바일에서는 **시간 종료/앱 복원/유닛 소멸·변신·판매 등 모든 종료 경로**에서 해당 실물의 이동·조작 잠금을 해제하거나 안전하게 폐기해야 합니다. 원본의 이 구현 누락을 새로운 실패 보상 규칙으로 해석하지 않습니다.

### 모바일 동작 예시

- **7개 공유 미션 완료 → 마지막 1개 완료:** 즉시 해독이 열립니다. 보상은 마지막 미션의 원본 보상 **1건**만 지급합니다.
- **해석자 효과 획득 전 해독 시작 → 진행 중 오뎅 성공:** 기존 시도는 **150초 그대로**, 다음 재시도부터 **50초**입니다.
- **로빈 조합 성공 → 다른 일반 유닛으로 해독:** 일반 유닛이 자격 필터를 통과하면 **50초**입니다. 로빈이 해독 구역에 있을 필요는 없습니다.
- **해독 중 유닛 사망 → 새 유닛으로 재시도:** 진행상태·잠금을 해제하고 **한 번 해금된 권리로 재시도**합니다. 보물은 성공 전까지 표시하지 않습니다.
- **해독 성공 → 이미 발견한 보물:** 발견/획득 영수증은 그대로 두고, **현재 남아 있는 보물의 위치 표식만** 처리합니다. 이전에 가져간 보물을 되살리지 않습니다.

## 4. 모바일 화면·저장 구현 기준

- **왼쪽 미션:** 공유 8개 목표의 이름·완료 여부·기한·보상을 보여 줍니다. 개인미션 18종과 진행 장부를 섞지 않습니다. 수동 소환이 아니라 **실제 스토리/보물 탐색/격파 사건**으로 달성합니다.
- **왼쪽 기록지침:** 실제 보유 유닛을 직접 선택해 해독 지시를 내립니다. **잠김/해독 가능/진행 중/완료**, 대상·남은 시간·현재 보물 위치를 한 화면에서 확인합니다. 원본의 **지역 진입** 조작만 모바일의 **선택 후 지시**로 바꿉니다.
- **공통 사건/저장:** 8개 개별 완료 영수증, `ni`, 해금 `nY`, **판 전체 공통 해석자 플래그 `aJ`**, 해독 진행 유닛 ID·시작 시 확정한 150/50초 타이머·결과, 보물 공개 표식 상태를 저장합니다. 대상 판매/조합/변신/사망/파견 이동과 휴대폰 일시정지가 겹쳐도 중복 완료하거나 실제 유닛을 정지 상태에 방치하지 않아야 합니다. **계정 누적 해석자 획득 기록과 이번 판에 활성화된 보정은 구분**합니다.
