총 합성 오라 정의는 149건으로 증가한다.

## 실제 플레이 전투 경로

1. 해당 캐릭터가 전투 로스터에 존재하고, 원본 능력 객체가 실제 해당 캐릭터 소유일 때만 오라 정의가 나타난다.
2. `IOriginal323SpecialAuraTargetRules`가 **실시간 원본 능력 레벨, 실제 버프 대상, 진영, 면역, 틱/잔류시점**을 검증한 대상에게만 `AttackPowerBuff` 상태를 준다.
3. `Original323SpecialAura.AllowsAllyRole`가 W3A `self`와 `notself` 비트를 실제 런타임 단계에서 강제 적용한다. 외부 검증 정책이 실수해도 니카의 자신 전용 효과나 오뎅의 자신 제외 효과를 다른 대상으로 이동시키지 못한다.
4. `IOriginal323NativeAuraRankWitness`가 필요한 **다중 레벨 능력**(예: 스코퍼 가반 A0IN 1·2레벨)은 현재 원본 레벨 증거가 없으면 아무 버프도 적용하지 않는다. 1레벨과 2레벨의 25%·50%가 동시에 누적되지 않도록 오라 공통 엔진에서 차단한다.
5. 원본 네이티브 평타는 현재 공격자의 오라를 `BasicDamageRequest.AttackerEffects`로 전달하고, `IOriginal323NativeAttackBuffRules`가 검증한 **공격력 중첩·적용 단계·원본 계산**이 없으면 피해를 적용하지 않는다. 7%/25%를 막연히 **최종 HP에 곱하지 않는다**.
6. 해당 원본 실전 시점의 타깃·오라 증거가 없으면 버프가 자동 적용되지 않는다.

## 일부 능력을 의도적으로 제외

`Cac1=10000/20000` 같은 별개 모드의 필드, `Cac1=0`, 음수 적 디버프,
게임 전역/소유자 보정형 대상, `aare=0`, 일부 상속/오버레이 미해결 정의는
근거 없이 10,000% 공격력 증가나 아군 오라로 해석하지 않는다.
예: 초월함 로빈의 `A0AY`, 영원함 버기의 `A0NL`, 불멸 카이도의 `A0Q1`.
이들은 별개 원본 JASS/능력 규칙을 조사해야 한다.
