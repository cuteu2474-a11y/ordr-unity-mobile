# 특별함·희귀함 스킬: 원본 관측 타격을 실제 전투에 적용

기준: ORDR S2 2.323[C], 악몽·이세계 모드, 2026-10-26.

## 이 변경에서 실제로 실행하는 기능

`CharacterCombatRuntime.SpecialRareObservedSkills.cs`는 **특별함·희귀함 75종의 동일한 전투 경로**에서 원본 관측 이벤트를 받을 수 있는 기능을 추가한다. 캐릭터의 웹 상세 스킬 프로필이 없어도 원본 W3X에서 확인된 소유 유닛과 능력 ID로 연결한다.

1. `OriginalMapBaseStatCatalog`의 **소유 캐릭터 도감 ID ↔ 원본 4글자 유닛 ID ↔ 실제 원본 능력 ID**를 먼저 대조한다.
2. `IOriginal323SpecialRareImpactWitness`가 **현재 전투 시각에 실제 발생한** 네이티브 주문 사건을 확인해야 한다. 단순 스킬 툴팁, 공격력 수치, 맵 객체의 능력 보유 여부로 스킬을 자동 시전하거나 10% 같은 발동률을 추정하지 않는다.
3. 원본 몬스터 대상 마스크·충돌·면역·저항·버프·최종 정수 HP 감소량을 외부 독립 검증기가 **각 타격별** 공급한다. 기절은 실제로 검증된 초·면역 근거가 있는 경우에만 적용한다.
4. 실행 전에 원본 맵 SHA, 현재 시전 캐릭터 신원, 스킬 보유 여부, 게임 시간, 전장 구분, 타깃 생존, 중복 타깃, 최종 HP 및 합계 오버플로를 **배치 전체** 검사한다.
5. 승인되면 실제 `CombatResolution.TryApplySkillDamage`에서 체력을 감소시키고 처치·기여·UI 이벤트에 일원화한다. 기절도 동일한 게임 `CombatStatusEngine`을 사용한다.
6. `SourceEventId` 기준으로 같은 원본 공격 사건이 다시 전달될 때 **2중 데미지**를 방지한다. 이벤트가 거절되면 근거가 확보된 별도 정상 사건은 그대로 실행할 수 있다.
7. 이미 별도 원본 주문 엔진에 연결된 **에넬 갈래 번개 A086**, **람각 A0VS**는 중복 처리 금지. 창고 이동/모으기/판매/조합/무적 객체 능력도 전투 스킬로 오인하지 않는다.

게임 연결 진입점:
- `OrdrCharacterCombatController.ConfigureVerifiedOriginalSpecialRareNativeImpacts(witness)`를 원본 데이터 로드 후·전투 월드 구성 전에 호출.
- 원본 효과 발생 시 `Combat.TryApplyObservedOriginal323SpecialRareImpact(sourceEventId)` 호출.
- 이 경로는 **평타 공격 공식이 아직 미검증인 캐릭터**도 원본 타격이 확정적으로 관측됐을 때 별개 피해를 정확히 반영할 수 있다.

## 소스 확인에 사용한 캐릭터

| 캐릭터 | 실제 W3X 객체 ID | 객체에 등록된 능력 ID | 구현 검증 범위 |
| --- | --- | --- | --- |
| 에넬 (특별함) | h00Q | A084 | 2개 대상의 별도 관측 최종 HP 적용, 중복 이벤트 차단 |
| 도플라밍고 (희귀함) | h01L | A057 | 원본 관측 피해와 검증된 기절 상태·만료 반영 |

위 능력 ID는 `original-2323C-map-base-stats.json`에 존재하는 **소유 관계**다. A084/A057의 실제 효과·피해·확률·발동·기절을 원본 대조하여 승인했다는 의미가 아니다.

`Original323SpecialRareObservedSkillTests.cs`는 **TEST_ONLY** 피해량 41, 53, 37, 기절 0.4초 등을 사용해 Unity 전투 엔진의 상태·타깃·피해·시계가 제대로 연결되는지 검사한다. **실제 게임 수치로 사용되지 않는다.**

## 실전 활성화에 필요한 원본 검증

특별함 33종·희귀함 42종의 원본 스킬 *실제 네이티브 효과*를 전수 확보한 상태는 아니다. 현재의 구체적인 `IOriginal323SpecialRareImpactWitness` 실전 구현이 없기 때문에 기본 씬에서는 새 스킬의 실전 피해가 자동 활성화되지 않는다. 원본 W3X의 JASS, W3A/SLK 및 전투 중 적 타입·마법 면역·방어 계산·발동 시각을 대조해야 한다.

효과 적용 전 검사로 일반적인 미검증 일괄 데미지를 막지만, 전투 엔진 내부 후크가 사전검사와 효과 적용 사이에 예외를 발생시키는 극단 상황의 **전투 전체 스냅샷 롤백 보장**은 별도 과제다. 이를 해결 전 완전한 원자성이라고 주장하지 않는다.

원본 공격력·공격속도·쿨타임·확률·조합 수치 변경 없음. GitHub `main`에만 반영, APK 미제작.
