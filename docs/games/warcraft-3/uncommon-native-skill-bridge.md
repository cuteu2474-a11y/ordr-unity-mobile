1. `Original323UncommonAbilityCatalog`가 원본 14종의 W3X rawcode 및 능력 순서를 검증한다.
2. `OrdrCharacterCombatController`가 카탈로그를 월드에 자동 연결하며 유닛 탭에서 고유 스킬 증거를 표시한다.
