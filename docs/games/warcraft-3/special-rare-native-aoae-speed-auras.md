# 원본 AOae 이동속도 감소·아군 공격속도 오라 전수 연결

대상: **원랜디 S2 2.323[C] / 악몽·이세계**  
원본 맵 SHA-256: `0794996c9bc73eaa3020f20ebc45fb37cfa64a6e98ffe8aa0dfa3b356e77bc5c`

## 게임에서 늘어난 기능

기존 `Original323ArmorAuraCatalog`의 AHad 방어 감소 61단계와 기존 특별함 오라 6종을 보존하면서,
같은 W3X 자료(`data/original-2323C-all-unit-aura-audit.json`)의 AOae 계열을 실제 전투
`CombatStatusEngine`의 **이동속도 감소 및 아군 공격속도 증가 상태**에 추가했다.

- `Original323NativeSpeedAuraCatalog`: **59종 유닛에서 원본 AOae 오라 69개**를 추출.
  - 적 이동속도 감소 정의 51개, 아군 공격속도 증가 정의 18개.
  - W3X `DataA` 음수값의 절댓값(적 이동 감소), `DataB` 양수값(아군 공격 속도 증가)을 각각 **표시용 퍼센트 상태량**으로 유지. 공격 주기, 실제 경로 이동 속도, 최종 타격 간격에 추측 공식을 적용하지 않음.
  - AOae 원본 오라 반경·원본 버프 ID·원본 대상 마스크·오라 레벨이 모두 보존됨.
- `Original323CompositeAuraCatalog`: 이미 구현된 AHad 방어 감소와 AOae 두 종류의 오라를 한 번에 읽는다.
  원본 특별함 스모커/크로커다일/키드의 기존 등록식 3개는 새 AOae 자료에도 존재하므로 **중복 적용하지 않음**.
- `Original323SpecialAura.TargetsAllies`: 아군 공격속도 오라를 적에게 거는 디버프와 명확하게 분리.
- `OrdrCharacterCombatController`: 기존 W3X 오라 자료 로드 시 합성된 오라를 전투 월드에 연결. 새로운 저장 파일이나 도감 수치 삽입은 없음.

### 필수 안전 조건과 남은 작업

`AOae` 소유 객체 정보는 효과 정의일 뿐 **게임에서 실제로 어느 시점에 버프가 걸리는지까지 증명하지 못한다**.
기존과 동일하게 `IOriginal323SpecialAuraTargetRules`가 현재 원본 능력 레벨·타깃 유형·버프 존재·면역/진영·반경·잔류 시점을 독립 확인하지 못하면 해당 오라 상태를 **일절 적용하지 않는다**.
W3A 상속 필드 미확정, 자료에 없는 마스크, 자체 강화(self-only), DataA와 DataB 혼합 등은 이번 범위에서 제외한다.

현재 완성된 것은 **전투 상태에 원본 효과의 타입·크기·범위·유닛 수명주기를 넣는 경로**다.
원본 전투 중 몬스터 이동시간 계산과 워크래프트 공격 간격은 별도의 실제 네이티브 속도 공식 검증이 필요하다.
실전 대상/버프 증거 공급자가 없으면 기본 게임은 해당 상태를 자동으로 적용하지 않는다.

`Original323NativeSpeedAuraCatalogTests`에는 원본 목록 69개 검산, 기존 AHad·특별함 오라 병합,
희귀함 아오키지 적 이동/범위 변경, 희귀함 브룩 아군 공격속도/범위 변경,
실전 증거 부재 차단, 잘못된 원본 지문 거절을 포함했다.
신규 테스트 코드의 검증 공급자는 **TEST_ONLY**, Unity CI 실행/통과는 별도 확인이 필요하다.

원본 공격력·확률·쿨타임·조합 비용 변경 없음. 신규 그래픽·APK 빌드 없음.
