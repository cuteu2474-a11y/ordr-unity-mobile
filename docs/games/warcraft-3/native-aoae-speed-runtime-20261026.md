# 원본 AOae 공속·이속 효과의 전투 실행 연결 — 2026-10-26

적용 기준: ORDR S2 2.323[C], 악몽·이세계, Unity 독립 모바일 리메이크. **원본 맵·수치 변경 없음.**

## 이번 실제 기능 구현

지난 단계에서 원본 W3X의 AOae 객체 정의 **69건**(이동속도 감소 51, 공격속도 증가 18)을 캐릭터 오라 상태에 연결했다. 이번에는 상태 등록만 하고 끝내지 않고 실제 전투 진행 경로에 다음 실행 기능을 추가했다.

### 1. 실제 기본 공격 재사용 간격 변경

`CombatAttackPipeline`의 `TryBasicAttack`이 성공한 기본 공격 후 다음 공격의 시각을 예약할 때 기존처럼 무조건 기본 스펙의 `IntervalSeconds`를 쓰지 않는다.

- 공격자에게 실시간 `AttackSpeedBuff`가 없으면 원본 검증 기본 공격 간격을 그대로 사용한다.
- 공격자에게 AOae 공속 버프가 있으면 **독립적으로 원본 공속 계산을 검증한** `IOriginal323VerifiedNativeAttackCadence`에 현재 공격자 인스턴스, 원본 공격 스펙, 적용된 현재 상태효과들, 게임 시각을 보낸다.
- 네이티브 규칙에서 양수 유한값의 최종 다음 타격 간격과 근거를 제공하면 실제 `CombatScheduler`의 공격 예약에 반영한다.
- 공속 중첩·상한·잔여 공격 구간·워크래프트 내부 반올림 규칙이 미확정이면 거절한다. **공격 선언 이벤트, 기본 피해, 스킬 발동 확률 RNG, 공격 쿨타임을 소비하지 않는다.**
- 오라가 사라지면 일반 원본 기본 간격으로 다음 공격을 예약한다.
- 원본 공속 공식이 아직 없으면 HUD의 `InspectBasicAttack`에서 **원본 네이티브 공격 간격 미확인**으로 표시하고 전투 스케줄러의 해당 평타 시도만 보류한다. 기타 검증된 주기 스킬/모바일 조작은 별도로 동작한다.
- 원본 `AttackPowerBuff` 및 기본 공격력 산식은 변경하지 않았다.

**중요:** 이 코드에서 `DataB 0.1`을 근거 없이 `기본 간격 / 1.1`로 변환하지 않는다. 원본 공속 중첩 방식은 아직 추가 검증이 필요하다.

### 2. 실제 몬스터 이동 경로의 감속 적용

`CharacterCombatRuntime.TryAdvanceEnemyAlongVerifiedOriginalRoute`는 **감속 전 경로상 다음 좌표**를 받을 때 활용할 수 있는 명시적 이동 API다.

- 기절 중인 적은 기존과 동일하게 이동 불가.
- 이속 감소 상태가 없으면 원래 경로 좌표를 적용.
- 이속 감소 상태가 있으면 `IOriginal323VerifiedNativeEnemyMovementStep`으로 원본 오라·면역·이동속도/중첩·이동 시각을 독립 검증한 이동 좌표를 얻는다.
- 계산 결과 승인 또는 증거가 없으면 원본 경로에서 **임의로 전진하지 않는다.** 검증 공급자가 계산 중 게임 시계, 적 위치 또는 상태를 몰래 바꿔도 차단한다.
- 기존 `TryMoveEnemy`는 이미 원본 이동을 계산해서 전달하는 좌표를 위한 메서드로 유지한다. 두 경로를 섞어 **원본에서 이미 감속한 적을 다시 감속시키지 않는다.**
- 원본 확인된 넉백/강제이동 전용 `ForceMoveEnemy`는 별도 유지.

### 3. 게임 구성 연결

`OrdrCharacterCombatController.ConfigureVerifiedOriginal323NativeSpeedExecution(attackTiming, enemyMovement)`에서 게임 월드 생성 전에 각 소스 검증 모듈을 주입할 수 있다.

기본 게임에는 원본 워크래프트 **현재 공속 중첩/캡/공격 구간 및 실제 웨이브 이동 검증 공급자**가 아직 연결돼 있지 않다. 그러므로 이 변경을 ‘모든 몬스터가 원작 이동속도로 자동 이동한다’고 해석하면 안 된다. 실제 웨이브 이동기에서 새 `TryAdvanceEnemyAlongVerifiedOriginalRoute` 호출이 필요하다.

## 추가된 회귀 시험

- `Original323VerifiedNativeAttackCadenceTests.cs`: 승인된 공속의 실제 다음 공격 예약, 미승인 사전 차단, 증거 부족·비정상 간격, 버프 종료 뒤 기본 간격 복귀.
- `Original323VerifiedNativeEnemyMovementTests.cs`: 아오키지 오라를 가진 적의 실제 좌표 변화, 미확정 속도 공식 차단, 버프 제거, 기절, 사전검증 중 불법 상태 변화.
- `Original323NativeSpeedRuntimeIntegrationTests.cs`: **희귀함 브룩 음악가** 오라가 아군 흔함 루피의 실제 기본 공격 예약 시각에 전달되는 전투 전체 경로, 미검증 공속 차단 및 버프 사라짐 처리.

해당 테스트에서 공속 간격 0.5초, 적 이동 반거리, 평타 피해 10 등은 **TEST_ONLY 가상 검증값**이다. 실제 게임 밸런스/원본 피해 수치로 적용하지 않았다. Unity CI 통과 및 실제 iOS/Android 단말 실행은 별도 미확인이다. APK 제작 없음.

## 다음 핵심 과제

원본 W3X/JASS 및 실제 워크래프트 시뮬레이션에서 다음을 수집해 독립 네이티브 규칙 공급자를 구현해야 한다.

1. AOae 공속의 원본 내부 중첩·최대/최소 제한·버프 획득 시 공격 예약 재계산과 공격 시점 반올림.
2. 현재 몬스터의 기본 이동속도, 이동 경로, 감속 중첩, 충돌·이동 이벤트 처리.
3. 실제 웨이브 이동기에서 승인된 이동 API를 호출하여 메인/스토리/보스 경로와 검증.
4. 오라 외 특별함·희귀함 **개별 공격 스킬**의 원본 발동·대상·완전 효과를 캐릭터별 확정.

현재의 정밀한 확인·차단 경계는 재현성을 지키기 위한 것이며, 아직 원작 파리티가 확보됐다는 뜻은 아니다.
