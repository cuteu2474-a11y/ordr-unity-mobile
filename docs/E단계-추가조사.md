# E단계 추가 조사: 이세계모드와 항법

> **자료의 위치:** 본문은 해당 기능의 원본 근거와 작성 당시 구현 기록입니다. 현재 실행 범위는 [START_HERE](START_HERE.md), 다음 작업은 [PLAYABLE_ROADMAP](PLAYABLE_ROADMAP.md), 운영 정책은 [AGENTS](../AGENTS.md)를 우선합니다. 본문의 과거 APK/테스트 보류·사거리·다음 작업을 현재 지시로 복사하지 않습니다.

> **기록 해석 기준:** 이 문서는 단계별 조사·구현 기록입니다. 본문의 미완료·미실행·다음 작업과 정책은 해당 작성 시점 기준이며, 현재 운영·전체 현황은 [최신 인수인계](새채팅-인수인계.md)의 ‘현재 작업 기준’을 우선합니다. 특히 과거 테스트 보류, 사거리 유지, 프로젝트/원본 수치 미확보 설명을 현재 상태로 적용하지 않습니다. 원본 규칙의 근거와 미검증 한계는 계속 구분합니다.

기준: 2026-10-21 / ORDR S2 2.323[C] / 악몽 이세계모드 전용

## 검증된 자료

- https://ordr.kr/guides/nightmare — 악몽 방깎 211, 이감 102는 **조합 권장 목표**이지 클리어 조건이 아니다.
- https://ordr.kr/guides/gorosei — 나스쥬로·워큐리·새턴의 악몽 효과와 권장 목표 변경
- https://ordr.kr/guides/armor-reduction — 오라형 방깎과 발동형 방깎은 별도 집계한다.
- https://ordr.kr/rankings/slow — 오라형 이감과 발동형 이감은 별도 집계한다.
- https://ordr.kr/ — 조합 계산기에는 '이세계모드' 항목이 있지만 **실제 게임의 이세계모드와 같은 것이라고 확인되지 않았다**.

## 오로성 악몽 효과 (도감 수치)

| 저주 | 효과 |
| --- | --- |
| 나스쥬로 | 적 이동속도 +15%, 아군 공속 -15%, 라인 몬스터 체력 +15,000,000 |
| 워큐리 | 적 방어력 +15, 마법방어력 +15%, 보스 체력 +15,000,000 |
| 새턴 | 아군 공격력 -30%, 폭발형 피해 -10%, 적 체력재생 초당 +350,000 |

위 수치는 `ElderCurseCatalog`에 **원자료**로 저장했다. 게임에 실제로 적용하는 코드는 아니다.

## 아직 확인되지 않은 핵심 사항

1. 이세계모드의 정식 명칭, 활성화 조건 및 난이도 악몽과의 관계
2. 이세계모드의 추첨 시점·후보·선택 여부·지속 시간·중복 규칙
3. 항법의 선택 타이밍, 노드별 효과·비용·보상 및 이세계모드와의 연관성
4. 오로성 저주의 게임 내 선택/부여 시점과 중첩 방식
5. 실제 라운드별 몬스터·보스 출현 및 종료 조건

## 구현 제한

- 위 사항이 확인되기 전에는 이세계모드를 임의 추첨하거나 가짜 항법 노드를 만들지 않는다.
- 도감 계산기의 사용자 선택 UI를 게임의 오로성 선택 규칙으로 오해하지 않는다.
- W3X 내부 분석은 해당 규칙이 도감에서 확인되지 않을 때만 최소 범위로 수행한다.
