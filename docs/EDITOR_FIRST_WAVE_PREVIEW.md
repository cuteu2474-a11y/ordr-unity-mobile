# Unity Editor에서 3라운드 바로 체험하기

> **개발용 가상 전투입니다. 정식 원랜디 S2 2.323[C] 악몽·이세계가 아니며 APK/IPA도 아닙니다.**

## 빠른 실행

1. PC에서 GitHub 저장소 **전체**를 내려받아 Unity Hub에서 프로젝트 루트를 Unity **6000.3.26f1**로 엽니다.
2. 상단 메뉴 **ORDR → 첫 라운드 직접 체험 (Unity Editor 전용)** 을 클릭하고 가상 데이터 안내를 승인합니다.
3. 기존 `MainGame.unity` 씬이 Play 모드로 열리며 **첫 라운드가 자동 시작되고, 루피(C-01)가 1개 자동 소환**됩니다. 시작 버튼을 여러 번 누를 필요는 없습니다.
4. 화면에서 자동 공격, 몬스터 출현/이동/피해/사망, 공유 골드 지급을 확인합니다. 왼쪽 **위습** 메뉴에서 남은 **랜덤위습 4개**를 자유롭게 사용하거나 다른 탭을 둘러볼 수 있습니다. 상단의 **1x / 2x / 4x** 버튼으로 배속을 선택하면, 4배에서는 35초 연습 라운드가 약 9초의 실제 시간에 진행됩니다. 일시정지는 배속과 무관하게 작동합니다.
5. 출현한 몬스터는 **Editor 전용 가상 경로(두 구간, 총 512×192 좌표 변화), 가상 이동속도 초당 40 월드 단위**로 움직입니다. 실제 전투 논리 시간만 이동에 반영되므로 일시정지 중에는 움직이지 않으며, 기절 시 기존 경로 드라이버의 정지 판정을 따릅니다. 경로 종점은 **처치/이탈/골드 지급으로 취급하지 않습니다.** 약 35초의 **연습용 라운드 타이머**가 지나면 2라운드, 다시 35초 뒤 3라운드가 시작됩니다. 정식 라운드 시작 증거와 혼동하지 않도록, 이 타이머는 별도의 Editor 전용 로직으로만 실행됩니다. 몬스터가 살아 있어도 원본의 연속 출현 설계를 흉내 내는 **Editor 전용** 타이머입니다. 4라운드 이후와 게임 클리어는 포함하지 않습니다.
6. 전장을 드래그/줌하거나 일시정지할 수 있습니다. 종료하려면 Unity 상단 Play 버튼을 끄세요. 저장소의 JSON/씬 및 정식 플레이 승인 조건은 바뀌지 않습니다.

## 정식 모드와 다른 점

- **기존 구현 재사용:** 1~3라운드의 원본 JASS 몬스터 ID, 종류, 각 0.5초 출현 시각, 전투/위습/경제 런타임, 실제 HP 감소/처치/골드 계정과 UI.
- **오직 Unity Editor에서만 생성하는 가상 입력:** 체력 55/75/95, 방어 0, 원본과 다른 전장 좌표 및 2구간 이동 경로/초당 40 이동속도, 첫 타격 지연 0.35초, 임시 물리 공격 승인, 최종 피해 절사, 모든 처치에 당첨 처리하는 가상 골드 판정(금액은 기존 원본 라운드별 계산식 재사용), 첫 위습 루피 고정, 이후 별도 시드 및 가상 라운드 35초. 정식 악몽 이세계 데이터라고 주장하지 않습니다.
- **체험 종료:** 3라운드 이후 추가 라운드가 자동으로 열리지 않지만 3라운드 전투와 생존 몬스터 이동은 계속 확인할 수 있습니다. Play 모드 종료 시 Editor 전용 타이머 콜백과 배속을 해제하고 1배로 복구합니다. 정식 원본 라운드 시작 증거 검증은 변경하지 않습니다.
- **아직 체험 불가능한 부분:** 실제 원본 몬스터 최종 체력·면역, Warcraft의 글로벌 난수·피해 소수점 처리, 실제 이동/이탈, 전체 스킬, 스토리·조합·상점의 미검증 동작, 4~65라운드, Android/iOS 게임 설치.

체험 코드의 가상 데이터는 `Assets/Editor/OrdrFirstWavePreview.cs`에 한정됩니다. **보통의 Unity Play 또는 Android/iOS 빌드에서는 자동 연결되지 않습니다.** 에디터 전용 경고 라벨이 게임 화면 상단에 표시됩니다.

Unity CI 컴파일/단위 테스트가 통과하더라도 **실제 Editor 화면을 사람이 조작했다는 뜻은 아닙니다.** 메뉴가 보이지 않거나 시작되지 않으면 Unity Console의 오류를 확인해 주세요.

개발 항목의 완료/미완료 구분은 [작업목록](PLAYABLE_ROADMAP.md)을 확인하세요.
