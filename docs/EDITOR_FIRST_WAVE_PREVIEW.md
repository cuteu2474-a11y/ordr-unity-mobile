# Unity Editor에서 첫 라운드 직접 체험하기

> **개발용 연습 환경입니다. 정식 원랜디 S2 2.323[C] 악몽·이세계 전투가 아닙니다. Android APK/IPA가 아닙니다.**

## 바로 실행

1. PC에서 GitHub 저장소 전체를 내려받고 Unity Hub에서 저장소 루트를 Unity **6000.3.26f1** 프로젝트로 엽니다.
2. Unity 상단 메뉴 **ORDR → 첫 라운드 직접 체험 (Unity Editor 전용)** 을 선택합니다.
3. 가상 데이터 경고를 확인하면 기존 `MainGame.unity` 씬이 Play 모드로 시작됩니다.
4. 게임 화면의 **체험 첫 라운드 시작 (가상 능력치)** 을 누릅니다.
5. 왼쪽 **위습** 메뉴의 **흔함 소환 → 소환 확정**을 누릅니다. 첫 추첨은 조작 연습을 위해 C-01(루피)로 고정되며, 자동 평타가 시작됩니다. 이후 추첨은 별도의 편의 시드로 진행됩니다.
6. 몬스터 출현·체력 감소·사망·체험 보상 골드, 정지 버튼과 전장 카메라 이동 등을 확인할 수 있습니다. 정식 2라운드는 아직 자동 개방되지 않습니다.
7. Unity 상단 **Play 종료**로 체험을 종료합니다. 저장소의 원본 JSON, 씬 및 정식 난이도 게임 규칙은 변경되지 않습니다.

## 어디까지 원본인가

- **원본에 근거가 있는 부분:** 35마리 첫 라운드 몬스터 식별자 및 0.5초 출현 일정, 흔함 위습 소환 서비스와 원본 흔함 9종 객체 표, 객체 공격 주사위/공격 주기 로딩, 동일 공유 지갑·전투 이벤트·HUD.
- **체험에만 존재하는 가상 부분:** 몬스터 HP=55, 방어=0, 점 배치 좌표, 첫 공격 지연 0.35초, 물리 공격 분류 승인, 피해 절사, 보상 난수 항상 당첨(+2G), 첫 위습 뽑기 고정. 이 값은 **`Assets/Editor/` 내 Editor 스크립트에만** 있으며 정식 게임의 데이터가 아닙니다.
- **체험에서 미구현/차단:** 실제 악몽·이세계 최종 체력·방어·면역, 원본 Warcraft 공격 판정 및 난수 상태 동등성, 동적 몬스터 경로/이탈, 실제 스킬 전체, 정식 다음 라운드, 게임 전체 저장과 클리어, Android/iOS 설치본.

## 안전 장치

- 체험 실행은 명시적인 메뉴 클릭과 경고 확인이 필요합니다. 일반 Unity Play나 빌드는 체험 값을 자동으로 주입하지 않습니다.
- Editor 컴파일 대상에만 체험 코드가 들어갑니다. 정식 플레이어 빌드에는 해당 클래스가 포함되지 않고, 시작 조건이 충족되지 않으면 기존처럼 버튼이 잠깁니다.
- 게임 화면 제목과 시작 버튼에 **개발용 체험 / 가상 능력치** 문구가 표시됩니다.
- CI에서 코드 컴파일을 확인하는 것과 실제 PC Editor를 조작해 보는 것은 다릅니다. 실제 Editor 조작·시각 품질은 사용자의 환경에서 추가 확인이 필요합니다.

완성 조건과 미완료 사항은 [실제 플레이 작업목록](PLAYABLE_ROADMAP.md)을 참고하세요.
