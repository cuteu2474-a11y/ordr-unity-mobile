# 개인 미션 구현 현황 — S2 2.323[C] 악몽 이세계모드

## 출처로 확인한 규칙
- 2.320에서 이세계모드 전용 개인 미션 `유닛조합(신비)` 추가
- 개인 미션 리롤은 10라운드 이전에만 사용 가능
- 출처: https://ordr.kr/patch-notes/2-320

## 이번 구현
- 미션 정의: ID, 이벤트 종류, 목표, 요구 수량, 이세계모드 전용 여부, 출처 URL
- 미션 할당, 이벤트별 진행도 갱신, 완료 판정, 보상 지급 확인, 수령 후 초기화
- 10라운드 이상 리롤 금지, 이세계모드 전용 미션의 일반 모드 할당 방지
- 단위 테스트 4개 작성

## 주의
- 이벤트 유형은 엔진 확장용 추상화로, 실제 원작 개인 미션 종류가 확정된 것은 아니다.
- 테스트에서 사용한 요구 수량 2는 원작 수치가 아니다.
- 보상 자체의 지급, 비용 지불, 미션 추첨, 출현 확률 및 전체 미션 목록은 **미구현**.
- 리롤 함수는 호출자가 비용과 추첨을 검증한 이후에만 호출해야 한다. 자체적으로 비용을 차감하지 않는다.
- 게임 이벤트와의 연결, Unity 컴파일 및 NUnit 실행은 **미검증**.

## 다음 조사
전체 개인 미션 목록·요구 조건·보상·리롤 비용과 횟수는 2.323 도감 또는 원본 W3X에서 확인 후 데이터로 등록한다.
