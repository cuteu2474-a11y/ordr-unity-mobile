### 조합 판정 세부 사항

- 초월: 생성 유닛에 `A07O` 능력이 있고 영웅 타입이어야 한다.
- 불멸: `A905`, 영원: `A906`, 제한: `A907`, 왜곡: `A0QH`, 신비: `A909` 능력 존재.
- 아이템 조합: 생성 유닛 rawcode가 `h067` / `h08O` / `H0BK` 중 하나.
- 최상위 조합: 원본의 별도 `Q7` 누적 카운터를 사용하므로, 실제 조합 로직에서 최상위 자격을 검증하여 이벤트로 넘겨야 한다.

## 게임 진행 규칙

1. 초기 후보는 공통 17개; **이세계모드라면 Q017을 추가하여 18개**.
2. 한 플레이어에게 3칸을 배정하며 각 칸의 미션은 **중복되지 않는다**.
3. `X3 < 10`, 미션 미완료, 변경 미사용 상태에서 **전체 게임당 1회**, 한 칸만 리롤할 수 있다. 원본 코드의 리롤 핸들러에는 재화 차감이 없다.
4. 원본은 목표 달성 시 **자동으로 완료 및 즉시 보상 지급**한다. 별도 수동 보상 수령 단계가 없다.
5. 목재수집·리사이클은 달성 후 **라운드 종료 이벤트**를 기다린다.
6. 최종 클리어 시 개인 미션 3종 모두 완료했다면 **베리 1개 추가**.
