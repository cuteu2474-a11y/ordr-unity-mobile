# 특별함·특수함 모바일 운용 정책

> **사용자 확정 규칙과 원본 기술 근거:** 악몽·이세계모드의 특별함 6종, 특수함 베티·오타마·가이몬, 수동 분해를 정리합니다. 원본 수치/효과를 임의로 바꾸지 않되, 여기 명시한 **모바일 운용 예외**는 그대로 적용합니다. 연결·실행·APK 검증 상태는 [현재 상태](START_HERE.md)와 [개발 작업](PLAYABLE_ROADMAP.md)을 우선합니다.

참여 장부는 **실제 양수 피해를 준 적의 사망·누수·퇴장까지** 유지합니다. 시간 만료를 새로 만들지 않으며 다른 유닛이 막타를 가해도 보상을 인정합니다.

## 공통 시전 대상과 참여 판정

- **로우·베티:** 외부 AI가 아니라 현재 전투 수치로 예상 DPS를 계산합니다. 보유·생존·동일 전장·능력별 자격을 확인하고 시전마다 다시 뽑습니다. 등급이나 표시 공격력만으로 정하지 않으며 동률은 인스턴스 ID 순입니다. 적법한 대상이나 실제 시전 공급자가 없으면 자원·쿨타임을 소비하지 않습니다.
- **로우:** 7초 100% 가속·50초 재사용·중복 가속 차단을 유지합니다. **베티에는 로우의 수치를 복사하지 않습니다.** 베티의 회복 효과·마나·쿨타임은 별도 원본 증거가 필요합니다.
- **모리아:** 실제 HP를 감소시킨 **양수 피해**만 참여로 인정합니다. 0피해·디버프만 적용·누수는 제외합니다. 여러 모리아가 같은 적을 때려도 플레이어의 좀비 재료는 한 번만 지급합니다. 소환수 피해는 원본 소유자 증명이 있을 때 귀속합니다.
- **도킹5·마르코:** 기존 공격 타깃 선택 결과를 재사용하되, 도킹5는 현재 적에게, 마르코는 **적 위치를 범위 중심**으로 적용합니다. 부가 범위·스턴·마방 감소 등은 검증된 원본 효과만 사용합니다.

## 수동 분해: 갱 뱃지와 버기 마기탄

두 기술 모두 **유닛 메뉴에서 분해 시작**을 직접 누르고, 시전이 끝난 뒤 실물 유닛을 교환합니다. 자동 전투 스킬로 발동시키거나 일반 판매 권한을 새로 부여하지 않습니다.

| 실제 보유 유닛 | 원본 시전 시간 | 확정 시 원본 개체 1기 소비 → 결과 |
|---|---:|---|
| **갱 뱃지** | **5초** | 안흔함 후쿠로 + 흔함 버기 + **흔함 해군 총병(C-08 / h009)** 각 1기 |
| **버기 마기탄** | **2초** | 흔함 버기 **2기 50% / 3기 50%** (`BFi(2,3)`) |

- 시전 중에는 해당 유닛의 자동 평타·미리보기 공격을 중단합니다. **이동·판매·조합 소비·스토리 파견·게임 종료**로 취소되며, 이동 후 원래 자리로 돌아와도 재개하지 않습니다.
- 준비 시간에도 시전 시간은 진행하지만 몬스터 라운드를 미리 진행하지 않습니다. **일시정지·백그라운드·포커스 해제** 중에는 시간이 흐르지 않고, 복귀 시 경과한 현실 시간을 한꺼번에 적용하지 않습니다.
- 완료 전에는 유닛/재화를 소비하지 않습니다. 여러 결과 유닛의 생성·배치가 모두 준비된 뒤 원본 개체를 제거하고 사건을 공개합니다. 실패 시 준비된 결과를 모두 취소하고 본체·위치·선택·공격 예약을 보존합니다. 추첨된 버기 수량은 실패 재시도 시 그대로 사용합니다.
- 이 두 분해에는 **골드·목재 비용과 판매 포인트가 없습니다.** 원본 `Bn2/BoK`의 `SPELL_EFFECT`, `AbilityData.slk`, `BIY` 배치와 [분해 추출 자료](../data/original-2323C-unit-decomposition.json)를 대조했습니다. 미기록 정수 `Cost1`의 0 처리에는 원본 SLK 별칭과 [w3x2lni 읽기](https://github.com/sumneko/w3x2lni/blob/82916514a12b7edb15252d42225cd8cc8ce61cfd/script/core/slk/frontend_slk.lua)·[쓰기](https://github.com/sumneko/w3x2lni/blob/82916514a12b7edb15252d42225cd8cc8ce61cfd/script/core/slk/backend_slk.lua)를 사용했습니다. **다른 미확인 필드까지 전부 0으로 간주해서는 안 됩니다.**

## 오타마의 1회 목재 보상

- 경단먹이기는 과거 **다른 플레이어에게 유닛을 양도하는 효과를 목재 +16으로 치환**한 확정 모바일 예외입니다. 유닛 선택·희귀 이하 검사·소유권 이동을 실행하지 않으며 기존 주는 사람/받는 사람 목재 보상을 중복 지급하지 않습니다.
- 개체당 한 번만 `EconomyWallet.TryGrantOnce`로 같은 공유 지갑에 지급하고, 실패하면 사용 기회를 보존해야 합니다. 오타마 본체를 삭제하지 않습니다.
- 지급 이력·유닛 ID·공유 지갑을 포함한 **전체 게임 저장/복구**는 별도 미완료 범위입니다. 코드의 단일 거래가 Android 기기 사용 검증을 뜻하지는 않습니다.

## 가이몬 탐색: 확률은 원본 보물 사건에서 구합니다

모바일에서는 지도 이동·좌표 지정 대신 **탐색 버튼 → 랜덤 결과 표시**로 조작합니다. 다만 **탐색 성공률을 임의의 50%나 고정 천장으로 대체하면 안 됩니다.**

### 원본 JASS·객체의 조사 증거

근거: [원본 탐색 조사 데이터](../data/original-2323C-treasure-research.json). 웹 도감만으로 확정하지 않고 제공된 맵의 JASS와 원본 유닛 이름을 대조했다.

- 가이몬의 실제 원본 유닛은 `h0BG`(프로젝트 `X-08`), 이름은 ‘가이몬 - 특수’다. 과거 7종 웹 목록에는 누락되어 있다. 원본 희귀위습 `CSI`의 **1% 특수 분기**에도 등장한다.
- 보물은 고정 성공률로 지급되지 않는다. BeM이 영역 내 무작위 좌표에 배치하고, BeN이 탐색 사각 범위에 들어온 미획득 보물을 수집한다. 한 번의 탐색에 여러 보물이 들어올 수도 있다.
- 기본 보물 추가량은 4개이고, 10·20·30·40·50라운드에 추가된다. 보물지도는 3개를 추가한다. 이전 보물을 매번 초기화한다고 단정하지 않는다.
- 가이몬 효과가 있을 때 수집 범위의 반쪽 길이는 978(기본850), 나미 효과도 있으면1125다. 가이몬의 꿈은 플레이어 상태로 1회 적용된다.
- **당첨 후 보상 종류**: 50라운드 전에는 흔함 선택 위습2개 또는 안흔함 위습2개가 1:1이다. 50라운드부터는 랜덤 위습2개다. 이것은 탐색 자체의 당첨률이 50%라는 뜻이 아니다.
- 베리 추가보상은 YU가 false일 때 발견한 보물당25/1000 분기다. 가이몬의 위습 수량2배를 베리에도 적용하지 않는다.
- 가이몬 R의 CCQ는 플레이어 시작점 주변 보물을 표시하는 경로이며, BeN의 수집 플래그가 false다. 따라서 도감의 R 재사용300초를 ‘가챠1회당 무조건300초’로 대응하면 원작 수급량이 보존된다는 근거가 없다.

### 탐색 구현에서 지킬 경계

- 보물 생성·남은 보물 수·탐색 범위·정보 공개·기회 및 중복 수령 상태를 내부에서 유지합니다. 복수 보물을 발견할 수 있는 원본 결과를 항상 1개로 줄이지 않습니다.
- 위치 공개 `CCQ`는 **반경 2,000**의 보물 정보를 표시하는 경로이지 즉시 수집·위습 지급이 아닙니다. 수동 버튼은 실제 `BeN` 성격의 탐색을 수행해야 합니다.
- 가이몬의 실제 원본 획득·`CCP` 가이몬의 꿈·나미 조건·탐색 기회·희귀위습 특수 분기/`A0YE`와 연결돼야 합니다. 연결되지 않은 상태에서 가짜 당첨이나 무제한 탐색을 허용하지 않습니다.
- 원본 당첨률·보상량을 비교하려면 같은 라운드·기회·보물 누적 상태에서 **꽝/1개/복수 개수와 보상 종류별 분포**를 대조해야 합니다. 조작 편의성과 실제 자원 수급은 별개입니다.
