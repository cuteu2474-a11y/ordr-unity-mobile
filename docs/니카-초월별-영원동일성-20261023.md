# 초월 루피 두 경로와 니카 영원 동일성 — 2026-10-23

대상은 ORDR S2 2.323[C]다. 사용자 질문은 루피 초월과 스네이크맨 초월에서 만드는 영원 유닛이 서로 다른가 하는 것이다.

## 확인 결과

**초월 루피와 스네이크맨은 서로 다른 유닛이다. 영원의 니카(루피)·니카(스네이크)는 같은 니카로 가는 두 재료 경로를 구분한 도감 항목이다.** 동일한 레벨과 스탯을 계승한 상태라면 출신 경로만으로 별도 스킬 세트를 적용할 근거는 없다. 조합 직전 재료의 성장 상태가 다르면 계승 결과의 실제 스펙은 달라질 수 있다.

| 비교 | 루피 초월 경로 | 스네이크맨 초월 경로 |
| --- | --- | --- |
| 초월 카탈로그 ID / 원본 객체 | TR-08 / H099 | TR-14 / H0B2 |
| 초월 객체 기본 공격 범위값 | 30,001~30,003 | 30,001~30,003 |
| 초월 객체 기본 공격 주기 | 0.38초 | 0.48초 |

| 니카 도감 항목 | E-01 / 니카(루피) | E-02 / 니카(스네이크) |
| 추가 재료 | 전설 로우·희귀 캡틴 키드·안흔함 에이스·태양신의 흔적·목재5 | 동일 |
| 영원 스킬·오라 설명 | 아래 공통 효과 | 같은 효과 |
| 원본 CWR의 니카 결과 | ET02 → H0BK(태양의 신) | 별도 결과 등록이 아닌 같은 니카 조합 |
| 완성 시 성장값 | 사용한 초월 재료의 레벨·스탯 계승 | 사용한 초월 재료의 레벨·스탯 계승 |

초월 표의 공격력·주기는 [원본 기본 능력치](../data/original-2323C-map-base-stats.json)의 객체 기본 필드다. 업그레이드·능력치·버프·변신·공격 지연·실제 피해가 반영된 최종 DPS가 아니다.

## 공통 영원 효과 대조

[E1](https://ordr.kr/character/E1)과 [E2](https://ordr.kr/character/E2)는 조합에 쓰는 초월 유닛만 다르고 다음 효과의 수치가 일치한다.

- 주변 방어 감소35, 공격속도 버프25%, 자기 공격력 증가25%, 평타 스플래시 반경350.
- 체력115를 쓰는 4.25초 거대화와 변신 중 공격 효과.
- 마나150을 쓰는 범위750 혼합 피해 및 2.5초 기절.
- 공격 확률10% 혼합 광역 타격, 확률20%의 5배 치명타·단일2초 기절.
- 확률15% 이동속도 연계 물리 타격과 거대화 전용 확률20% 광역 타격.

기존 E-01/E-02 JSON은 같은 설명을 서로 다른 필드명으로 입력한 부분이 있다. 예를 들어 attackSpeedBuff/allyAttackSpeedBuff, basicAttackPercent/plusBasicAttackDamagePercent, self/area 위치가 다르다. 이는 별도 원본 성능의 근거가 아니며 공통 사양으로 정합화할 데이터 작업이다. 이번 문서 검토에서는 프로필·카탈로그 ID·원본 매핑 JSON을 병합하거나 전투를 활성화하지 않았다.

## 계승과 조합 조건

- [2.314 패치](https://ordr.kr/patch-notes/2-314): 니카 제작 시 재료 초월의 레벨과 스탯을 가져오도록 수정했다.
- [2.320 패치](https://ordr.kr/patch-notes/2-320): 재료 초월이 특성강화 후 상태여야 제작 가능하다. 루피 경로에서 스네이크맨 부재 메시지가 나오던 오류도 수정됐다.
- [2.321 패치](https://ordr.kr/patch-notes/2-321): 블랙맘바 상태의 스네이크맨을 사용했을 때 경험치 계승이 누락되는 오류를 수정했다.

따라서 ‘같은 니카’라는 이유로 재료 성장값을 버리거나, 두 초월 재료를 동시에 요구해서는 안 된다. 계승할 스탯의 구체 필드·복사 순서·블랙맘바 임시 보정 제거 및 숨은 기능은 별도 원본 처리 확인이 필요하다. 패치 문구만으로 모든 일시 버프까지 복사한다고 단정하지 않는다.

## 원본 결과와 기존 미연결 항목 해석

[원본 CWR 등록 자료](../data/original-jass-fusion-registry.json)에서 H0BK를 생성하는 등록은 ET02 한 건이다. UNIT 조건은 H08T·h03C·h02D·h00K, 아이템 AI01과 목재5다. H08T는 기존 [객체 교차대조](원본-조합-객체-재대조-20261023.md)에 ‘해적왕이 될 사나이 / 다섯번째 황제’로 기록된 공통 조합 입력이며, 구체적인 특성강화·변신 객체 처리까지 검증됐다는 뜻은 아니다.

기존 E-02의 객체 unmatched는 웹 도감의 두 경로를 원본 객체에 일대일로 연결하지 못했다는 상태다. ‘아직 못 찾은 두 번째 니카가 반드시 존재한다’는 근거로 쓰지 않는다. E-01/E-02 원본 기록과 기존 저장 참조는 보존하고, 공통 결과와 별도 재료 경로·계승 상태를 연결하는 후속 작업에서 스키마와 매핑을 함께 검토한다.

## 문서 및 검증 범위

이번에는 웹 도감 두 페이지·관련 패치·저장소의 원본 CWR와 객체 추출 자료를 교차 확인했다. E-01/E-02의 수치 비교와 결과 등록 확인은 조사 근거이며 실제 Unity 전투·제작·계승 검증은 아니다. U-TR-08/U-TR-14/U-E-01/U-E-02와 A-02, D-10/D-12, F-07(특수 조건)의 관련 범위에 연결한다.
