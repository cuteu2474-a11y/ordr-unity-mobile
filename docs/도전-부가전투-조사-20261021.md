# 원랜디 S2 2.323[C] 도전·부가 전투 조사 (2026-10-21)

> **기록 해석 기준:** 이 문서는 단계별 조사·구현 기록입니다. 본문의 미완료·미실행·다음 작업과 정책은 해당 작성 시점 기준이며, 현재 운영·전체 현황은 [최신 인수인계](새채팅-인수인계.md)의 ‘현재 작업 기준’을 우선합니다. 특히 과거 테스트 보류, 사거리 유지, 프로젝트/원본 수치 미확보 설명을 현재 상태로 적용하지 않습니다. 원본 규칙의 근거와 미검증 한계는 계속 구분합니다.

이 문서는 **모바일 독립 게임 기획을 위한 공개 자료 조사**다. 원본 W3X 기능 실행이나 정식판 실기 검증을 의미하지 않는다. 기록 상태는 `현 버전 근거 확인`, `과거 자료만 확인`, `조사했지만 미확인`, `기획 제안`을 구분한다.

## 1. 실제 콘텐츠 분류

- **크립 1~3단계**: 현 버전 연결 **확인**. 2.320 이세계모드 패치에서 **3단계 크립 처치**가 '이세계 유닛도박 충전 스택' 획득 조건으로 명시됨. 2.323 도감의 아냐 포저 툴팁에서도 `1~3단계 크립 공격 시 해당 스킬 미발동` 예외를 확인.
  - https://ordr.kr/patch-notes/2-320
  - https://ordr.kr/character/MY8
- **해왕류**: 부가 처치 대상으로 존재 **확인**. 2026년 9월 솔악 커뮤니티 게시글에서도 해왕류의 처치 가능 유닛이 제한된다는 플레이 사례가 존재. 이전 공략에서는 공중/수중 이동 유닛을 사용한다고 설명.
  - https://gall.dcinside.com/mgallery/board/view/?id=ordrs2&no=268
  - https://m.humoruniv.com/board/humor/read.html?number=2690889&table=game (2020, 과거 참고)
- **폐문·해군대장**: 2026년에도 어려운 부가 전투 목표로 언급됨. 오래된 공략에는 문 파괴 뒤 3대장 중 하나가 출현한다는 설명과 특성포인트 보상이 있음. 해당 정확한 분기는 S2 2.323[C]에서 아직 검증 못함.
  - https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=232128
  - https://ordsearch.net/tips/1 (오래된 공략, 2.323 전용 명세 아님)
- **피카**: 2026년 5월 플레이어가 특성포인트 획득 경로로 피카를 언급. 예전 공략에는 50라운드 이후 처치로 특성포인트 1 획득이라고 기술. 정확한 S2 2.323[C] 등장 조건·제한시간·실패 패널티는 **조사했지만 미확인**.
  - https://ordsearch.net/wagles/607 (2026-05)
  - https://ordsearch.net/tips/1 (오래된 공략)
- **황금종·등불·비석·파편 등**: 부가 목표로 플레이 언급 존재. 황금종은 2026년 6~10월 글에서도 언급; 등불·파편·비석은 오래된 공략과 구분해야 하며 각 목표의 동일성/별도 조건은 미확인.
  - https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=248902
  - https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=267171&t=cv
  - https://m.humoruniv.com/board/humor/read.html?number=2690889&table=game (과거 참고)
- **탐색·해적단·스모커**: 자원 획득 활동으로 알려져 있음. 크립형 단일 적 처치와 달리 경제·퀘스트 카테고리로 독립 모델링하는 편이 타당. 정확한 2.323 반복 횟수·라운드 제한·보상은 **조사했지만 미확인**.
  - https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=151116 (2024 가이드)

'도전'이 현재 원작에서 **모든 부가 콘텐츠를 묶는 단일 메뉴명인지**는 이번 공개 자료에서 확인하지 못함. 모바일에 '도전' 버튼을 만드는 것은 **새로운 인터페이스 제안**이지 원작 UI의 확인 결과가 아니다.

## 2. 크립 2단계 보상 — 버전 변경 주의

- 2020년 공략에는 `목재 7개 OR 목재 3개 + 해적선`으로 기술됨(과거 자료).
- 2024년 게시글에서 후자가 `목재 2개 + 해적선`이라고 정정되고, 2025년 2월 플레이어와 2026년 9월 시즌2 악몽 플레이 댓글에도 `목재 7개` 대 `해적선 + 목재 2개` 취지의 기록이 있음. **현행 보상 후보로 우선할 만한 근거**지만, 정확한 확률은 미확인.
  - https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=171170
  - https://gall.dcinside.com/mgallery/board/view/?id=ordc1&no=201545
  - https://gall.dcinside.com/mgallery/board/view/?id=ordrs2&no=125
- 2020년 가이드는 1단계 클리어 시 전체 플레이어 목재 1, 3단계 개인 목재 1 등도 기록함. **S2 2.323[C] 현행 고정 수치로 취급하지 말 것**.
  - https://m.humoruniv.com/board/humor/read.html?number=2690889&table=game

## 3. 현재 확인한 2.323 기반 핵심 연계

- 2.320 패치의 `3단계 크립 처치 → 이세계 유닛도박 충전 가능 스택`을 최신판도 반영 대상으로 유지. 2.323 패치 요약은 최적화/버그 수정 위주이나, **특정 S2 2.323[C] 맵에서 직접 시연한 것은 아님**.
  - https://ordr.kr/patch-notes/2-320
  - https://ordr.kr/patch-notes
- 크립에게 모든 유닛 스킬이 그대로 발동하지는 않음: `아냐 포저(신비)` 상세 스킬 설명에서 1~3단계 크립 대상 발동 제외 규칙 확인. 엔진의 타깃 타입은 적어도 `WAVE`, `BOSS`, `STORY`, `CREEP` 등을 구별할 필요가 있음.
  - https://ordr.kr/character/MY8

## 4. 모바일 UI 제안: 밖으로 이동하는 조작만 변환

기존 휴대폰 가로화면: 왼쪽 메뉴 · 중앙 메인 전장(상부) · 중앙 스토리 전장(하부) · 오른쪽 상세 목록.

**추천 조작안(원작 규칙 아님)**

1. 왼쪽에 `도전` 버튼 또는 `부가 콘텐츠` 항목 추가.
2. 오른쪽에 `크립 1 / 2 / 3`, `해왕류`, `폐문`, `피카`, `기타 목표` 등을 열람하게 함. 단, 실제 해금/반복/보상은 확인된 자료를 채워 넣을 때만 활성화.
3. 크립을 선택 → **보유 유닛을 직접 지정** → `출전` 버튼. 과거처럼 작은 맵을 팬/스크롤하며 외부 좌표로 이동시키는 조작은 제거.
4. 출전 중 유닛은 메인 웨이브·스토리 전투에서 동시에 공격하지 않게 하여 병력 배분의 기회비용을 유지. 크립 공격은 기존 유닛 스탯·스킬 예외(예: 일부 스킬 미발동)를 공유한다.
5. 크립 체력·시간·처치 결과는 오른쪽 상세 패널이나 독립 미니 진행 영역에 표시하되 중앙 주 전장을 침범하지 않음. 처치 조건 완료 후 검증된 원본 보상 이벤트와 3단계 도박 충전 이벤트 발생.
6. 맵 접근 제한(공중/순간이동/바다이동), 이동 소요시간, 실패 시 재출전, 동일 유닛 재사용, 보상 수령 주체 등이 실제 게임 난이도에 영향을 줄 수 있으므로 **조작 단순화와 규칙 변경을 구분해 추후 결정**. 현재는 전투/보상 수치를 임의 생성하지 않는다.

## 5. 조사 상태 및 남은 과제

| 항목 | 상태 | 한계 |
| --- | --- | --- |
| 크립 1~3단계 존재 | 현 버전 자료 확인 | 직접 실행 미검증 |
| 3단계 크립 ↔ 이세계 도박 스택 | 2.320 패치 확인 | 2.323[C] 직접 시연 미검증 |
| 2단계 7목재 vs 해적선+2목재 | 2025·2026 실플레이 보고 확인 | 정확한 확률 미확인 |
| 크립 단계별 HP·방어·공격, 해금 라운드 | 조사했지만 미확인 | 버전 검증 가능한 수치 필요 |
| 1·3단계 보상, 다인/솔플 귀속 | 과거 자료만 확인 | 현행 여부 미확인 |
| 해왕류·폐문·피카 존재/운영 | 공개 자료와 최근 커뮤니티 근거 확인 | 개별 단계 조건/수치 미확인 |
| 크립 이동 능력별 출전 제한 | 과거 자료만 확인 | 현재판 접근 조건 재검증 필요 |
| 부가 콘텐츠 반복/재시도 규칙 | 조사했지만 미확인 | 무한 재도전/쿨타임 임의 구현 금지 |
| 원작 공통 '도전' 메뉴 존재 여부 | 조사했지만 미확인 | 모바일 탭은 신규 UI 제안 |

**개발 판단:** 맵 외부 이동 조작의 불편함은 제거할 수 있다. 다만 **출전 중 메인 전투 병력 감소·단계 보상·스킬 예외·이세계 도박 스택 조건**을 재현하는 것이 핵심이다. 원본 W3X 전체를 역분석할 필요는 없으나 공개 자료에 없는 이 정보만 추가 확인해야 한다.

이 문서 작성은 **조사 및 설계** 단계이며, Unity 도전 기능 구현/테스트/API 연결은 아직 진행하지 않았다.
