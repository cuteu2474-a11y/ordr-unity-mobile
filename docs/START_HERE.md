**현재 영웅 능력치 연결(코드 반영·실행 미검증):** 원본 JASS `Bjq`·`Bxc`의 교체는 기존 영웅의 **보너스 제외 힘·민첩·지능**을 읽고, 경험치를 복사한 뒤 새 영웅에 `ModifyHeroStat(SET)`으로 덮습니다. 새 원본 `Original323HeroAttributeWorld`는 본래 레벨 성장과 이 복사값의 차이를 개체별·폼 리비전별로 보관하므로 이후 레벨업 때 새 폼의 성장치만 적용합니다. `IOriginal323CurrentNativeHeroAttributeWitness`는 원본 현재 `GetHeroStatBJ(false/true)` 각각의 3능력치와 아이템/버프 변화·만료 시 최신 리비전을 **실제 관측한 경우에만** 제공하며, 전투의 기존 STR·AGI·INT 공급 경로와 위성 ID별 경로가 이를 읽습니다. 현재 APK 자체에 네이티브 관측 자료 제공자는 없으므로 `true`의 값/18개 피해 추가가 자동으로 완성되는 것은 아닙니다. 공속·공격력·방어력 장비 장부를 영웅 STR·AGI·INT 보너스로 위장하지 않습니다. 원본 24건의 `ModifyHeroStat`는 대부분 교체 SET이며 시라호시 레벨20의 +10 ADD는 기존 성장 규칙에 이미 포함됩니다. 원본 JASS SHA `96201e80…`; 원작 실기 동일성은 미확인.

**스토리 탭 UI(코드 반영·실행 미검증):** 건물 공략/크립 사냥 하위 탭은 스크롤 위에 고정합니다. 건물 목표·실제 HP 막대 다음에 기본 펼침 파견 목록을 배치하고, 획득 보상·건물별 보상은 접어서 표시합니다. 초월위습/그린블러드 잔여 수와 지급 대기는 보상 헤더에 노출합니다. 중복 선택 유닛 행동 줄은 제거하고 각 보유 개체 행의 기존 파견/복귀 명령을 유지합니다. 크립 탭은 현재 월드의 실제 출현/격파·HP만 표시하며 파견 미지원 안내를 유지합니다. 크립 파견·정식 출현·보상은 미완료입니다.
