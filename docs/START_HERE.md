## 특히 놓치면 안 되는 사항

1. **시작 지급:** 원본 `CUo/CUn`의 **랜덤위습 5개·골드 60·진화체 1기**와 현재 `Original323SoloStartProfile` 및 기존 테스트 기대값이 일치합니다. 사용자 별도 1개 예외는 철회되었습니다. 최신 Unity·APK 실제 지급은 미검증입니다.
2. **완성 판정:** ‘도감/원본 데이터 등록 → 호출 코드 연결 → Unity/기기 실행 → 원작 결과 일치’는 서로 다른 단계입니다. [검증 기준](PARITY.md)을 따릅니다.
3. **원본 자료:** 기본/확장 개체 **277+11=288**, 수집한 기술 **554개**, 패시브 **295개**는 전수 목표·자료 집계이지 완성 건수가 아닙니다. [전체 캐릭터·기술 목록](전체-캐릭터-기술목록.md) 및 [유닛별 코드 스냅샷](캐릭터별-구현목록.md)은 집계 범위가 다릅니다.
4. **전투 모델:** 샌즈(MY-07) 뼈 성장·브룩 먹이기, MY-06/08/13·I-08·L-03/18의 새 효과 일부는 `TOOLTIP_MODEL_ONLY` 또는 원본 검증 전 모델입니다. 확률·쿨타임·자원과 중복 타격을 확인하기 전 ‘원작 구현 완료’로 표시하지 않습니다. [스킬 누락 검토표](스킬-누락-검토표.md).
