CWR 분류와 미연결 사건은 [원본 경로 감사](../data/original-2323C-cwr-last26-batch56.json)를 확인합니다. 기존 표의 154개 제작식과 AI00~02만의 아이템 목록은 이전 범위이므로 현재 총계로 사용하지 않습니다.

스토리 공성 표시는 실제 파견 인스턴스와 건물 HP만 읽습니다. 유닛 탭으로 개별 선택하며 많은 유닛은 한 줄씩 페이지를 전환합니다. 공격/스킬 이벤트로 동작·궤적을, 실제 피해 이벤트로 건물 피격을 표시하고 전투 논리 시간으로 정지합니다. 파견·피해·보상·대상 선정 규칙은 바꾸지 않았습니다.

## 돈 도박

도박소에서 항목 선택 → 비용/확률 확인 → 직접 실행 → 결과·누적 손익 확인 순서입니다. 자동 반복이나 유닛 도박 미션 진행은 추가하지 않았습니다.

| 종류 | 비용·보상 | 재고/해금 |
|---|---|---|
| 일반 | 10골드, 75% 10~50골드 / 25% 3~5골드 반환 | 3회, 11초마다 1회 |
| 고급 | 500골드, 70% 500~4500골드 / 30% 300~400골드 반환 | 실제 아론(o01V) 보스 처치로 R009 해금, 7회·9초마다 1회 |

고급 누적 **반환액** 35000 도달 시 마지막 반환을 깎지 않고 일반/고급 돈 도박을 종료합니다. R01M과 목재 구매 기회 5회를 같은 거래로 기록하며, 10000골드+기회 1회를 소비하면 목재 1개를 지급합니다. 졸업 상점의 특성 포인트/희귀 유닛 구매는 아직 미연결입니다.

비용·반환·졸업은 공유 지갑의 단일 영수증으로 확정합니다. 실패 시 재추첨하지 않고, 커밋 후 알림 예외로 중복 지급하지 않습니다. 고급 반환 총액·횟수·해금·졸업·목재 기회는 지갑 상태에 보존합니다. 최근 결과·일반 통계·상점 재고/타이머까지 포함한 전체 저장은 별도입니다.

원본 W3X/JASS SHA를 대조하여 [돈 도박 자료](../data/original-2323C-money-gambling-shop.json)를 재추출했습니다. 초기 가득 찬 재고와 논리 시간 재충전은 개발용 모델이며 원본 네이티브 초기화/난수열 동등성은 미인증입니다. 회귀 코드는 작성했지만 이번 요청에서 실행하지 않았습니다.

## 현황을 다시 확인하는 방법

검사 요청이 있으면 저장소 루트에서 다음 명령을 사용합니다.

```sh
python3 tools/build_character_runtime_coverage.py --verify
python3 tools/render_unit_status_docs.py --verify
python3 -m unittest discover -s tests -q
```

집계는 기본 카탈로그 277개 + 확장 11개 = 288항목입니다. 추가된 TW-01/h0BR은 비전투 보상 상자이며 평타·효과·원작 전투 승인을 추가하지 않았습니다. 중복 ID·누락 항목은 생성 단계에서 거부합니다. 위습 회귀는 현재 공통 거래의 보상 자격·잔액·1회 차감·실패 롤백 경로와 대조합니다.

Windows 검사에서는 기존 원본 의존 검사 1건과 POSIX 권한·`/bin/bash`가 필요한 패키징 검사 2건을 건너뛰었습니다. 후자 2건은 Linux CI에서 계속 실행됩니다. 이번 작업은 게임 수치·전투 코드·획득 권한을 바꾸지 않았습니다. 다음 작업은 [개발 작업](PLAYABLE_ROADMAP.md)을 확인합니다.

## 숫자와 근거 읽기

`캐릭터별-구현목록.md`와 `unit-runtime-status.json`은 저장된 실행 범위 스냅샷입니다. 확장 카탈로그·변신체까지 집계하는 `character-runtime-coverage.json`과 집계 범위가 다릅니다. `--verify`는 현재 입력 JSON과의 일치만 확인하므로, C# 실행 지원이 바뀌면 실제 지원 내보내기를 먼저 갱신해야 합니다. 도감 수·평타 모델 수·효과 정의 수를 완성 유닛 수로 합산하지 않습니다.

원작 전체 전투 검증을 완료한 유닛으로 승인하지 않은 상태입니다. `MODEL_ONLY`는 명시적인 개발용 모델을 뜻합니다. [검증 기준](PARITY.md) · [데이터 출처](../data/README.md).

## Unity에서 열기

Unity **6000.3.26f1**로 저장소 전체를 열고 `Assets/Scenes/MainGame.unity`를 실행합니다. 준비 화면에서 유닛과 위습을 다룬 뒤 전투를 시작합니다. 데이터는 `data/`에서 Resources로 자동 동기화됩니다. 검사·빌드 실행은 [운영 규칙](../AGENTS.md)과 [실행 안내](unity-editmode-test.md)를 따릅니다.
