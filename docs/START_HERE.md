## 2026-10-29 가이몬 R 공개 정보를 모바일 가챠 확률 공급자에 전달

- 원본 `CCQ`에 의해 실제 확인된 보물 ID만 `Original323GaimonRevealPort`에 축적하고, 아직 등장하지 않았거나 이미 수집된 상자는 탐색 정보에서 제외하는 `ActiveRevealedChests`를 추가했습니다. 플레이어가 좌표를 입력하는 UI는 만들지 않습니다.
- 모바일 탐색 버튼은 원본 공개 결과를 `IOriginal323MobileTreasureRevealedPolicy`에 전달하도록 연결했습니다. **CCQ 공개 결과가 있는데 공개 정보의 확률 편향을 처리할 능력이 없는 기존 정책은 탐색을 허용하지 않습니다.** 같은 원본 상자 월드와 일치하는 객체만 공급자에 전달하고 미래 라운드 상자·위조 위치 입력을 거부합니다.
- 기존 꽝/발견/복수 보상과 공유 지갑 정산은 그대로 사용합니다. 공개 정보를 받았다는 이유로 당첨률을 50% 등으로 고정하거나 보상을 무료 지급하지 않으며, 미검증 공급자의 기본 가챠 잠금 상태도 유지됩니다.

## 두 전투 경로를 혼동하지 않기

1. **개발용 연습:** `SourceModelBasicCombatRules`, `SourceModelUnitEffects`, `SourceModelPracticeBattle`이 객체 수치와 명시적인 참조 모델로 움직인다. 원작 HP 소수 처리·미사일 시점·보스 저항·동적 면역 전체가 검증된 것은 아니다.

## 로컬에서 열기와 검사

- 저장소 전체를 Unity 프로젝트로 연다. 버전은 [ProjectVersion.txt](../ProjectSettings/ProjectVersion.txt)의 `6000.3.26f1`이며 의존성은 [manifest.json](../Packages/manifest.json)에 있다.
- 씬: [MainGame.unity](../Assets/Scenes/MainGame.unity). `OrdrCharacterDataSync`가 `data/`에서 Resources 캐시를 생성한다. 필요하면 Editor 메뉴 **ORDR → 캐릭터 데이터 273종 · 스킬 200종 동기화**를 사용한다.
- 기본 APK용 연습과 `Assets/Editor/OrdrFirstWavePreview.cs`의 가상 체험은 서로 다르다. Editor 전용 체험의 숫자나 자동 확정 소환을 APK에 복사하지 않는다.
- 비 Unity 자료 검사: 저장소 루트에서 아래 명령을 실행한다. Unity 검사는 [실행 안내](unity-editmode-test.md)를 따른다.

```sh
python3 -m unittest discover -s tests -q
git diff --check
```

`3cc8997` 작업 때 확인한 것은 **공통 C# 142파일 로컬 컴파일, 파일 로딩용 Unity 어댑터를 사용한 실제 코드 NUnit 46사례, Python 161건**이다. 이는 Unity 엔진·Android 설치 검증과 다르다. 임시 로컬 Mono 실행기는 저장소의 표준 실행 도구가 아니므로 새 환경에서 있다고 가정하지 않는다. 현재 CI 결과를 확인하지 않은 상태에서 과거 통과 건수를 최신 통과로 보고하지 않는다.

## APK 제작 경로

기존 [unity-editmode.yml](../.github/workflows/unity-editmode.yml)의 main push가 먼저 Python/Unity 검사를 실행한다. push 커밋 메시지에 `[apk-preview]`가 있으면 그 검사에 의존하는 Android 제작 작업을 실행한다. 수동 dispatch만으로는 현재 조건상 APK 작업이 실행되지 않는다.

APK 아티팩트 이름은 `ordr-mobile-android-development-apk`, 경로는 `build/Android/**/*.apk`, 보존 기간은 14일이다. 동일 실행을 취소하거나 중복 실행하지 않는다. 최근 게임 코드 `3cc8997`의 제작 요청은 [이 실행](https://github.com/cuteu2474-a11y/ordr-unity-mobile/actions/runs/40609510016)에 있다. 2026-10-28 해당 실행에서 ARM64 APK 생성과 ZIP 무결성·v2 서명 블록 존재를 확인했다. 파일은 `ORDR-Mobile-3cc8997.apk`, 크기 11,971,189바이트, SHA-256 `5528a1a9ce9ba87b18a280f2edfcc3ea088923da3c070032fb931e6a0cc4248d`다. 설치·실제 플레이는 확인하지 않았다. 이 기록은 해당 산출물에 대한 확인이며 이후 코드의 빌드 성공을 뜻하지 않는다. 산출물의 커밋을 확인하고 사용자에게 제공한다. 문서만 수정한 main HEAD와 APK에 들어간 게임 코드의 기준 커밋은 다를 수 있다.
