# 현재 상태

> **코드 반영 기준:** 최신 main의 UI·전투·원본 데이터 경로를 구분합니다. 게임 코드 연결과 Unity/Android 실기 검증은 별개입니다.

**현재 영웅 능력치 연결(코드 반영·실행 미검증):** 원본 JASS `Bjq`·`Bxc`의 교체는 기존 영웅의 **보너스 제외 힘·민첩·지능**을 읽고, 경험치를 복사한 뒤 새 영웅에 `ModifyHeroStat(SET)`으로 덮습니다. 새 원본 `Original323HeroAttributeWorld`는 본래 레벨 성장과 이 복사값의 차이를 개체별·폼 리비전별로 보관하므로 이후 레벨업 때 새 폼의 성장치만 적용합니다. `IOriginal323CurrentNativeHeroAttributeWitness`는 원본 현재 `GetHeroStatBJ(false/true)` 각각의 3능력치와 아이템/버프 변화·만료 시 최신 리비전을 **실제 관측한 경우에만** 제공하며, 전투의 기존 STR·AGI·INT 공급 경로와 위성 ID별 경로가 이를 읽습니다. 현재 APK 자체에 네이티브 관측 자료 제공자는 없으므로 `true`의 값/18개 피해 추가가 자동으로 완성되는 것은 아닙니다. 공속·공격력·방어력 장비 장부를 영웅 STR·AGI·INT 보너스로 위장하지 않습니다. 원본 24건의 `ModifyHeroStat`는 대부분 교체 SET이며 시라호시 레벨20의 +10 ADD는 기존 성장 규칙에 이미 포함됩니다. 원본 JASS SHA `96201e80…`; 원작 실기 동일성은 미확인.

**스토리 탭 UI(코드 반영·실행 미검증):** 건물 공략/크립 사냥 탭, 현재 단계·실제 HP, 수동 파견/복귀 목록을 유지하고 **획득 보상/건물별 보상** 두 목록을 제거했습니다. 실제 지급 장부는 그대로 남고 초월위습은 위습 메뉴, 그린블러드 실제 사용권은 스토리의 독립 대상 선택으로 접근합니다. 크립 파견·정식 출현·보상은 미완료입니다.

**부가 목표 문서화:** [부가 목표 구현 명세](부가목표-구현명세.md)에 공유 전투 5종·개인 토벌 7종의 연결 절차와 복구 계약을 정리했습니다. 기존 공유 출전/정산 모델을 재사용하되 기본 APK의 실제 출현·사망·대장 버프 공급과 공유 출전 저장 복원은 미완료입니다. 이번 반영은 문서만이며 실행 검증·원작 추가 조사·APK 제작은 하지 않았습니다.

**캐릭터 수동 기능 공통 UI(코드 반영·실행 미검증):** 전장 아래 스킬/아이템 진입, 오른쪽 공통 행동 카드, 브륄레/도시락의 적격 아군 목록 및 전장 터치, 강화/해금/구매/판매의 카드 내부 확인, 도시락 독립 아이템 보기, 오타마 사용 완료·비비 최대 단계·위성 보유 표시를 연결했습니다. 분해는 기존 서비스의 진행률·취소·확정을 재사용합니다. 제작자가 사라진 도시락의 대상 선택에서 현재 선택 ID와 원래 제작자 ID를 구별합니다. 정적 호출/변경 검토와 diff 공백 점검만 수행했으며 C# 컴파일·Unity/Android 실행·APK 제작은 하지 않았습니다.

## 실행 검증

- **UI 원인 분석과 일괄 수정(코드 반영·실행 미검증):** 큰 공용 적 해적 스프라이트는 이전 수정에서 이미 제거되었습니다. 아군 7종의 가져온 5×2 유닛 시트 기본 우선권을 해제해 실제 개별 사진 경로를 복원했습니다. 프레임 밖·잔상 위험 경로인 화면 밖 미클리어 영역, 1536×1024 전체 UI 시트를 배경으로 늘리던 패널, 여러 OnGUI의 불명확한 깊이, 스토리 초상화 돌출을 일괄 조정했습니다. 오른쪽 패널을 불투명하게 전면 갱신하고 프레임 내부 크롭/중앙 정렬로 통일했습니다. 이전 APK에서의 정확한 잔상 원인은 실기/프레임 캡처 없이는 단정하지 않습니다.
- **미사용 위습 부유 알림(코드 반영·실행 미검증):** 원작에서 위습이 전장에 남아 있는 느낌을 메인 전장 상단의 빛나는 부유 마커로 표시합니다. 랜덤위습만 실제 지갑 잔액을 조회하고, 초월선택은 미사용 보상 장부를 조회합니다. **선택위습은 잔액과 관계없이 부유 표시에서 제외하고 기존 조합 메뉴에만 둡니다.** 0개에서는 보이지 않고 탭하면 위습 메뉴로 이동하며 재화를 소비하지 않습니다. 자동 지급형 위습은 제외하고 겹치는 전장 터치는 차단합니다. UI/배속/Android 실기 검사 전이며 원작 위습의 실제 경로/물리 이동 재현은 아닙니다.
