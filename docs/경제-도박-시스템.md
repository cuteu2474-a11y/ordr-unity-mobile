# 경제·도박 시스템

> **현재 코드 기준 설명:** 이 문서는 원랜디 S2 2.323[C] 악몽·이세계모드의 **재화·돈 도박·이세계 유닛 도박**을 정리합니다. [현재 상태](START_HERE.md)의 검증 수준과 [개발 작업](PLAYABLE_ROADMAP.md)의 M·I·S 작업을 함께 확인하세요. 코드 연결은 실제 APK 검증과 다릅니다.

## 1. 재화는 어디서 관리하나요?

골드·목재·위습·특성포인트·아이템 소유권·일부 성공/보류 영수증은 **한 게임의 공유 지갑과 실제 보유 유닛 목록**을 기준으로 처리합니다.

- **수동 거래:** 상점·도박·조합·위습·토큰 교환은 화면에서 선택하고 실제 서비스가 실행 조건을 다시 검사합니다.
- **성공 시:** 비용 차감, 유닛 생성/제거, 보상 지급, 사용 횟수·영수증을 가능한 범위에서 하나의 거래로 확정합니다.
- **실패 시:** 유닛과 재화의 변경을 되돌리고 보류한 추첨 결과를 유지해 재시도 과정의 재추첨·중복 지급을 막습니다.
- **저장 한계:** 영수증과 일부 잔액 상태는 관리하지만, **재고/타이머·전투·유닛을 포함한 전체 게임 저장과 이어하기는 미완성**입니다.

조합별 비용은 [조합 시스템](조합-시스템.md), 위습별 소모·획득·판매 보상은 [위습 시스템](위습-시스템.md)에 한 번만 설명합니다. **구현 완료 여부와 무관하게** 포함할 전체 아이템·시설·상점 기능은 [전체 아이템·시설 목록](전체-아이템-시설-목록.md)에 유지합니다.

## 2. 일반·고급 돈 도박

**도박소 UI(2026-11-13, 코드 반영·실행 미검증):** 돈 도박과 유닛 도박을 **한 줄짜리 항목**으로 나열하고, 이세계 도박을 유닛 도박에 합쳤습니다. 한 번 누르면 거래 1회 실행, **0.55초 이상 길게 누르고 떼면** 비용·확률·원본 제한이 해당 행 아래에 펼쳐집니다. 고급 돈 도박의 **졸업 누적 반환 35,000골드 진행 및 졸업 후 구매 기회**도 고급/졸업 행을 길게 눌러 확인합니다. 결과·재고·시도·RNG 규칙은 유지합니다.

| 구분 | 시도 비용 | 결과(원본 분기) | 재고·해금 |
|---|---|---|---|
| **일반 돈 도박** | 골드 **10** | **75%:** 10~50골드 반환 / **25%:** 3~5골드 반환 | 최대 3회, 11초마다 1회 충전 |
| **고급 돈 도박** | 골드 **500** | **70%:** 500~4,500골드 반환 / **30%:** 300~400골드 반환 | 원본 **아론 보스(`o01V`) 실제 처치**로 해금, 최대 7회·9초마다 1회 충전 |

'반환액'은 베팅 비용을 뺀 순이익이 아니라 **해당 결과로 돌려받은 골드**입니다. 현재 초기 재고와 충전 시간은 원본 능력의 정확한 시작 설정·네이티브 난수열까지 인증된 결과가 아니라 개발용 모델이 포함돼 있습니다.

**공통 보상 알림:** 확정된 도박·콤푸 환전·발굴 결과와 위습 사용/자동 재처리로 실제 새로 생성된 유닛은 모두 **메인 전장 왼쪽 상단(HUD 아래)에 약 3.2초간 표시**합니다. 유닛은 실제 로스터의 신규 인스턴스 차이로 사진·이름·수량을 보여주며, 유닛이 아닌 도박 보상은 확정 메시지를 표시합니다. 전장을 가리는 전체 팝업이나 자동 재시도/재추첨은 사용하지 않습니다. 항법 결정 규칙은 이번 UI 변경 대상에서 제외하며, Unity/Android 실행은 미검증입니다.

## 3. 돈 도박 졸업과 이후 구매

고급 돈 도박의 **누적 반환액이 35,000골드 이상**이 되면 일반·고급 돈 도박을 종료하고, 졸업 상태·원본 권리·목재 구매 기회 **기본 5회**를 한 번 기록합니다. 원본 `BhL`에서 일반 발굴 **AI13을 획득하면 `i5` 목재 재고 +2회**가 추가되며, 졸업 전 획득분도 추후 상점에 반영됩니다. 모바일은 기본 5회 소모 후 AI13 추가 2회를 별도 지갑 장부로 사용하고, **10,000골드 차감·구매권 1회 소모·목재 1개 지급을 원자 거래**로 확정합니다. AI13의 별도 라인 골드 효과는 원본 사망 관측과의 연결이 아직 남았습니다.

| 졸업 후 항목 | 비용 | 추가 조건·효과 |
|---|---|---|
| **목재 구매** | 골드 **10,000** + 구매 기회 1회 | 졸업 기본 5회, AI13 일반 아이템 획득 시 +2회(최대 7회). 기본권/추가권 각각 1회만 소모, 기회 없으면 구매 불가 |
| **특성포인트 1개** | 골드 **15,000** | 원본 졸업 도박소 `h0AL`. 재고 1회·3,600초 재충전 모델 |
| **희귀/특수 유닛 1회 소환** | 골드 **5,000** | 원본 `H0B0`, **스토리 5단계 연구 `R01N` 해금**, 구매 1회 권리·원본 재고 필요. `CJF` 분기에 따라 **희귀 99% / 특수 1%** |

마지막 추첨은 **돈 도박 졸업 상점의 별도 보상 풀(희귀 43·특수 7)**입니다. [희귀위습](위습-시스템.md)의 **희귀함 42·특별함 8** 풀과 혼동하면 안 됩니다. A0YE를 받은 개체는 아래 수동 희귀 리롤을 사용할 수 있으며, 레일리 예외와 원본 풀을 유지합니다.

재고/충전·해금·비용·소환은 같은 공유 거래 경로를 사용합니다. 조건 미충족, 재화 부족, 결과 유닛 생성 실패 시 원본 권리를 무료로 지급하거나 재추첨하지 않습니다.

## 4. 하급·중급·고급 유닛 도박

유닛 도박에는 **하급·중급·고급·이세계** 버튼을 한 줄씩 보여주며, 짧게 누르면 실제 거래 1회, 길게 누르면 원본 비용과 확률을 펼칩니다. 돈 도박을 졸업해도 계속 이용합니다. 비용은 원본 훈련 객체 h06B/h06C/h06D, 분기는 CJP/CJS/CJK를 따릅니다.

| 등급 | 비용 | 원본 결과 순서 |
|---|---|---|
| 하급 | 200골드 + 목재 1개 | 먼저 15% 실패(유닛 없음). 나머지에서 2% 해적선, 그 외 50% 흔함 9종 / 50% 안흔함 13종 |
| 중급 | 1,000골드 + 목재 2개 | 먼저 30% 실패(유닛 없음). 나머지에서 4.5% 해적선 / 95.5% 특별함 32종 |
| 고급 | 2,000골드 + 목재 4개 | 먼저 30% 실패(토큰 1개). 나머지에서 4% 레일리, 그 외 50% 특별함 32종 / 50% 희귀함 42종 |

표의 뒷분기는 **앞 분기를 통과한 경우의 조건부 확률**입니다. 특별함 도박 풀은 위습의 33종 풀과 다릅니다. 고급의 희귀 결과에는 A0YE 리롤 권한을 기록하며 레일리에는 붙이지 않습니다.

- **카지노:** 하급·중급을 잠그고, 고급 성공은 희귀 42종으로 지급합니다. 원본처럼 레일리 분기 난수는 건너뛰되 특별함 기준 0%의 분기 난수는 소비합니다.
- **리스크헷지:** 고급 실패 시 토큰을 **총 2개** 지급하고 목재 1개를 반환합니다.
- **개인미션:** 결제와 실제 보상 생성이 확정된 뒤 해당 등급의 시도/실패 사건을 한 번 기록합니다. 돈 도박·이세계 도박·리롤은 이 세 등급에 합산하지 않습니다.
- **실패 재시도:** 이미 뽑은 분기와 풀 인덱스를 유지합니다. 생성 실패·잘못된 난수·재화 부족으로 무료 보상이나 새 결과를 만들지 않습니다.

원본은 훈련 완료 콜백입니다. 모바일에서는 결과를 직접 결제·지급하는 방식으로 연결했으며, 네이티브 훈련 시간·초기 재고·원본 RNG까지 재현됐다는 뜻은 아닙니다. [원본 표·함수·객체 근거](../data/original-2323C-unit-gambling-reroll.json).

## 5. 이세계 유닛 도박

**이세계 유닛 도박은 유닛 도박 목록 안의 한 행**입니다. 행에는 실제 충전 수와 골드·목재 비용을, 길게 누른 상세에는 현재 당첨 확률·보상을 표시합니다. 일반/고급 돈 도박과 별개이며, **돈 도박을 졸업해도 같은 충전 횟수로 계속 이용**합니다.

| 항목 | 현재 연결된 규칙 |
|---|---|
| 시도 비용 | **3,500골드 + 목재 5개 + 충전 1회**, 모두 있어야 실행 |
| 기본 당첨 | **15%**, 원본 `ke[0..13]` 순서의 랜덤전용 유닛 14종 중 1기 |
| 기본 실패 | **행운의 토큰 `h06G / LT-01` 1개**를 실제 보유 목록에 생성 |
| 충전 | 초기 무료 충전 없음. **스토리 8~13단계 격파마다 1회**, **3단계 크립 `n00G` 최초 처치 1회**, **해왕류 공유 미션 `CNU` 완료 1회**(원본 사건 확인 필수) |
| 기록 | 같은 지갑에 잔여 충전·시도·당첨·실패 누적 보너스와 구매 영수증 보관. 화면에 최근 6회 결과 표시 |

**원본 해석 오류를 수정했습니다.** 스토리의 `BdL`은 특성포인트가 아니라 `kP`와 `H0AW` 재고를 늘리는 **유닛 도박 충전 함수**입니다. 8~13단계에서 특성포인트를 지급하지 않습니다. 기존 데이터/화면의 잘못된 특성 표기도 교정했습니다.

원본 해왕류 도전과제 `CNU`의 `BdL(EK,1)`을 **공유 미션 보상의 동일 영수증**에 연결했습니다. 원본 증빙을 갖춘 해왕류 격파 완료가 정산되면 1회(카지노 선택 시 2회)가 골드·위습 등과 **한 번에** 지급됩니다. 따라서 기본 총 충전 가능 횟수는 8회(스토리 6+3단계 크립 1+해왕류 1)입니다. **기본 APK의 해왕류 실제 출현·사망을 증명하는 공급자는 아직 없으므로 무조건 8회가 지급되는 상태는 아닙니다.** 원본 3단계 크립 배치는 기존 연습 월드의 명시적 생성 경로를 사용하며 자연 출현 규칙을 새로 만들지 않았습니다. 충전을 시간 경과나 라운드 도달로 대신 지급하지 않습니다.

**21라운드부터 도박소에서 카지노·리스크헷지 중 하나를 확인 후 선택**할 수 있습니다. 도움소 연금술·최대출력과 같은 1회 선택 제한을 공유하며 바꿀 수 없습니다. 보류 거래가 있거나 일시정지 중이면 선택하지 않습니다.

카지노는 선택 순간 잔여 충전을 **2×잔여 충전 + 기존 이세계 도박 시도 수**로 환산하고, 이후 스토리/크립 충전은 2회씩 줍니다. 실패 중 50%는 토큰 대신 희귀 `kd[0..41]`로 지급하며 `h05X`는 제외합니다. 희귀 리롤 기회도 1회 추가합니다.

리스크헷지는 이세계 실패마다 성공 확률을 **+15%p** 누적하고 당첨 시 초기화합니다. 희귀 리롤 기회 2회를 추가하며 리롤의 목재·토큰 비용을 면제합니다. 희귀 리롤 기회 자체는 여전히 1회 소모합니다. **환전소:** 21R 이후 도박광 3번째 항법을 선택할 수 있습니다. 원본 `CJS`는 중급 유닛 도박을 시도할 때마다(30% 실패 포함) 콤푸 `I009`를 **1개** 충전합니다. 중급 결제·결과·콤푸가 동일 거래에서 확정되며 **원본 시작 콤푸는 0개**입니다. 원본 `CKR(3)`에서는 고급 도박만 잠깁니다. 환전 `CKD~CKJ` 7종 비용·분기·실물 유닛 생성·중복 결제를 코드에 연결했으며, 콤푸 없이 구매되지 않습니다. `CKH/CKI`는 즉시 아이템 획득이 아니라 일반·유니크 발굴 **1스택 충전(각 1회만 교환)**입니다. `BhS/BhT`는 각각 12종 일반·10종 유니크 미획득 풀을 소모하는 원본 추첨이며, 일반 발굴은 양쪽 풀이 남으면 일반 90%/유니크 10%로 결정합니다. 스택은 종류별 최대 10개이고 당첨 능력은 재추첨하지 않습니다. 개별 `BhL` 아이템 사용 효과·외형·전체 저장·실기 검증은 남아 있습니다.

당첨 유닛의 `A0YZ`는 아래 **랜덤전용 리롤**에 연결했습니다. 공격 버프로 사용하지 않습니다.

소환과 비용·충전·영수증은 한 번의 거래로 확정합니다. 생성/결제 실패는 생성 유닛과 보류 능력을 되돌리고, 같은 서비스에서 다시 시도할 때 이미 뽑은 분기/인덱스를 재사용합니다. 커밋 후 화면 알림 오류는 재결제·재지급하지 않습니다. **보류 추첨·개체·전투까지 포함한 전체 저장/복원은 아직 미완료**이며 지갑 저장만으로 재접속 동등성을 보장하지 않습니다.

원본 `CJM`은 하급/중급/고급 도박 미션 판정 함수 `BCj`를 호출하지 않습니다. 이세계 도박을 해당 세 등급이나 목재 도박 미션으로 임의 합산하지 않습니다.

## 6. 희귀·랜덤전용 유닛 리롤

**유닛 메뉴에서 실제 보유 유닛 선택 → 리롤 → 확정**으로 사용합니다. 단순히 같은 등급이라는 이유로 리롤을 허용하지 않고 획득 시 기록한 A0YE/A0YZ 권한을 확인합니다. 파견·일시정지·진행 종료 상태에서는 실행하지 않습니다.

| 종류 | 일반 비용 | 리스크헷지 | 교체 후 |
|---|---|---|---|
| 희귀 A0YE / CRj | 공용 리롤 기회 1회 + 목재 2개 | 공용 기회 1회, 목재 무료 | 희귀 42종 중 다른 유닛. A0YE 유지 |
| 랜덤전용 A0YZ / CRl | 실제 행운의 토큰 1개 | 토큰 무료 | 랜덤전용 14종 중 다른 유닛. **A0YZ를 다시 붙이지 않아 해당 권한은 1회용** |

희귀 리롤은 원본 초기 LN=2에서 시작하며 카지노 +1, 리스크헷지 +2를 더합니다. 같은 유닛이 뽑히면 원본처럼 다시 추첨하므로 난수 소비를 임의로 1회로 바꾸지 않습니다.

실제 원본 유닛·토큰은 결과 생성과 결제가 준비된 뒤 함께 제거합니다. 결과는 원래 위치에 생성하고 선택을 넘깁니다. 실패 시 기존 인스턴스·재료·지갑을 유지하고 보류 결과를 재사용합니다. 원본 능력의 ANsg 상속 비용·2초 준비 시점까지 인증한 네이티브 시전 재현은 아닙니다.

## 7. 특성포인트와 고유 아이템

- **특성포인트 획득:** 개인 미션 **트리플(`Q015`) 최상위 조합 3회**의 1점과 졸업 도박소 구매를 구분합니다. 스토리 `BdL` 충전은 특성포인트로 지급하지 않습니다.
- **현재 소비 예시:** 시라호시(`H08U/H0C1`)의 `Bz6` 특성은 **4포인트**를 원자 차감하고 개체별 중복 구매를 막습니다. 다른 영웅의 모든 특성 소비를 지원한다는 뜻은 아닙니다.
- **고유 아이템:** 초월위습 꾸러미 선택으로 얻는 **10종**의 보유·중복 획득 방지 이력과 조합에서 인정하는 실제 소모를 유지합니다. 효과가 아직 확인되지 않은 아이템을 임의로 활성화하지 않습니다.
