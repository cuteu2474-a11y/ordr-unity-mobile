## 실제 연결 범위

1. 기본 Unity 컨트롤러에서 공유 `EconomyWallet`과 `UnitRoster` 및 실제 `CharacterCombatRuntime`을 묶어 소환합니다.
2. 성공 시 유닛과 위습 1개 차감, 원본 카운터 변경을 확정합니다. 유닛 소환/거래 실패 시 원래 재화와 유닛 상태로 복원하고 **같은 추첨 결과를 유지**합니다.
3. 모바일 자동배치 공급자가 존재해도 원본 `BIY` 좌표를 덮어쓰지 않습니다. 다른 유닛의 일반 자동배치 동작은 유지합니다.
4. 랜덤위습 자원 교환과 흔함 추첨에 동일한 모바일 난수 객체를 전달하여 해당 두 기능 간 호출 순서를 유지합니다.
5. 모바일 `Random`으로 원본 분포를 구성한 것이며 Warcraft의 전역 `H6/BFi` 상태, 시드, 다른 네이티브 호출까지 같다는 의미는 **아닙니다**. 이 차이는 별도 원본 세션 재현 또는 승인된 시드 추적 후 해결해야 합니다.
