# 영웅 성장·특성 — 최종 APK 구현 명세

> **완성 목표 문서:** 원본 ORDR S2 2.323[C] 악몽·이세계의 영웅 성장·특성을 **현재 구현 여부와 상관없이 전부 구현 대상**으로 보존합니다. 이 문서의 숫자는 [원본 영웅 성장 추출 자료](../data/original-2323C-hero-level-growth-evidence.json)에 근거하며, **실제 Unity 전투·Android 플레이·원작 동일성 검증이 끝났다는 뜻이 아닙니다.**

## 1. 영웅 레벨과 경험치

- 원본 최대 영웅 레벨은 **24**입니다. 원본 설정에 명시된 초기 경험치 요구 입력은 **33 → 75 → 116 → 152**입니다.
- 이후 구간의 설정 근거는 **이전 단계 요구치 × 1.03 + 단계 인덱스 × 15**, 정수 절삭입니다. 이 자료를 누적 총 XP 요구량이나 실제 레벨업 UI 수치로 단정하지 말고, 원본 `war3mapMisc.txt`의 인덱스 정의·`Bz6/Bz7` 사건과 함께 적용합니다.
- 영웅이 받는 XP는 스토리·전투·기타 원본 사건별 지급자와 대상 그룹을 연결해야 합니다. **13·14단계 스토리 영웅 XP 300**은 확인된 경로이며, 다른 XP 획득 사건이 이 문서에 없다고 해서 삭제하지 않습니다.
- 레벨 증가에 따른 **실제 개체별 STR/AGI/INT, 공격력, 공격속도, 마나 재생, 기술 해금**, 변신 전후 승계를 구현합니다. 원본 초기 능력치가 미수집인 폼에는 임의 기본값을 채우지 않습니다.

## 3. 시라호시 특성 — 단순 보유 조건이 아닌 실제 소비

대상 폼: **`H08U`·`H0C1`**.

- 플레이어가 특성포인트를 **4개 실제 소비**하여 `Bz6` 해금을 실행해야 합니다. 지갑에 4개가 *있다는 이유만으로* 자동 해금하지 않습니다.
- 해금 후 `Bz7` 영웅 레벨 이벤트를 등록하고, 해당 폼과 레벨 조건에 맞춰 다음 단계 기술을 적용합니다.
- **16레벨:** `A0L1` 2단계.
- **20레벨:** `A0RU` 2단계 + **힘·민첩·지능 각각 10의 일회성 추가**.
- **24레벨:** `A0KZ` 2단계.
- 기술의 원본 피해·지속시간·타깃, 특성포인트의 **실제 획득 경로**, 해금 전에 이미 레벨 조건을 넘긴 경우의 처리, 변신 중 사건 순서는 후속 원본 증거와 연결합니다. 미확인 처리를 임의 자동 지급으로 대체하지 않습니다.

## 4. 구현·검증 완료 조건

1. 원본 XP 획득 사건과 **정확한 영웅 폼/대상 그룹**이 연결되며, 비영웅·다른 폼에는 지급되지 않습니다.
2. 58개 폼의 **초기 스탯(원본 확인 가능한 경우) + 레벨 증가 + 연구·오라·변신**이 중복 없이 적용됩니다.
3. 특성포인트 **획득 → 실제 소비 4개 → 해금 → 16/20/24레벨 기술/보너스**가 원자 거래로 연결되며, 20레벨 +10 보상이 반복되지 않습니다.
4. 판매·조합·변신·소환·스토리 파견·게임 종료/이어하기에 **XP·레벨·소비 포인트·해금 플래그·일회 지급**이 정확히 유지됩니다.
5. 코드 등록, Unity 확인, Android 실기 확인, 원본 비교 결과를 **각각 따로** 기록합니다. 미연결 수치는 영구 기능 목록에서 제거하지 않습니다.
