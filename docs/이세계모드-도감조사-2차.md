# 악몽 이세계모드 — 도감 조사 2차

기준 버전: ORDR S2 2.323[C] / 조사일: 2026-10-21

## 확인된 사항
1. ORDR 조합 도우미는 **이세계모드**를 독립적인 선택 옵션으로 제공한다.
2. 도감 안내에는 '이세계모드와 랜덤유닛의 경우 우측 상단에 버튼을 눌러 추가'할 수 있다고 되어 있다.
3. 난이도(악몽) 선택과 이세계모드 선택은 도감 화면에서 별개다.
4. 오로성은 난이도·이세계모드 옵션과 별개로 표시된다.
5. 2.320 패치에서는 '패왕의길' 항법의 기본 효과가 보스목재 +2 / 이감 7%에서 **전설 레오 소환**으로 변경됐다고 기록된다. 레오는 이동속도 10% 감소 오라 및 보조 딜러 역할로 설명된다. 이는 2.323 도감에 포함된 이전 패치 기록이다.

## 구현 결과
- `OtherworldModeConfiguration`: 악몽 + 이세계모드 고정 식별
- `UnitCatalogEntry`: 출처 URL과 '이세계모드 전용' 분류를 명시적으로 보유하는 도감 데이터 모델
- 테스트 코드: 모드 식별, 이세계 분류, 출처 검증

## 아직 확인되지 않은 사항
- 이세계모드의 실제 게임 내 활성화 절차와 효과
- 이세계모드 전용 유닛의 정확한 목록 및 획득 규칙
- 항법의 전체 노드·비용·보상·선택 시점
- 오로성의 부여 시점과 이세계모드의 상호작용
- 라운드 및 보스·스토리의 이세계모드 차이

## 원칙
도감 화면의 버튼이나 체크박스가 실제 게임의 동일한 선택 절차를 의미하지는 않는다.
게임 진행에 필요한 정보가 도감에서 끝내 확인되지 않을 때만 W3X 내부 해당 규칙을 조사한다.

## 2.323[C] 이세계모드와 몬스터 강화 분리 판정 (2026-10-22)

**핵심:** 이세계모드는 전용 캐릭터 해금/획득 계통 외에도 **일부 개인미션·도박·항법 노드의 조건부 기능**과 연결됩니다. 그러나 **이세계모드만 켰다는 이유로 웨이브 몬스터 HP/방어력을 일괄 증폭한다는 근거는 현재 없습니다.** 악몽 난이도 보정, 후반 웨이브별 능력, 오로성 버프는 각각 별도의 메커니즘이므로 혼합하지 않습니다.

| 범위 | 확인 내용 | 근거·한계 |
|---|---|---|
| 원본 이세계 선택 코드 | `CUM`에서 `th[tn]` 조건을 검사하고 플레이어 0~3에게 `R00P` 연구, `k4=true`, `TriggerEvaluate(tu)` 호출 | 원본 JASS 추출 결과; **R00P의 효과/tu의 호출 대상별 부작용은 아직 역추적 미완료** |
| 이세계 전용 유닛 | 도감이 이세계모드 유닛을 별도로 표시 | ORDR 조합 도우미; 실제 맵 내 해금·제작 조건은 개별 검증 필요 |
| 이세계 개인미션 | 2.320 패치에서 이세계 적용 시에만 등장하는 `유닛조합(신비)` 개인미션 추가 | ORDR 2.320 패치 기록; 현재 `OtherworldMissionRules`가 조건을 표현함 |
| 유닛도박 이세계 | 2.320 패치에서 성공 확률 15%로 변경 | 이세계 도박은 일반 도박과 구분; 2.323[C] 실기·JASS 확률 검증은 별도 |
| 항법 이세계 추가효과 | 카지노·리스크헷지·환전소 노드의 이세계 추가효과가 2.320에서 변경; 리스크헷지 도박 실패 확률 보정도 변경 | 2.320 패치 기록, 뒤 버전의 개별 변경사항은 누적 대조 필요 |
| 웨이브 몬스터 추가 HP·방어력 | 이세계 **선택 분기에서 적 플레이어의 추가 연구는 발견되지 않음** | 직접적인 몬스터 강화 부재를 증명하는 것은 아님; `tu` 트리거·다른 조건문 분석 전까지 미확정 |
| 악몽 공통 버프·51~65 웨이브 능력·오로성 | 각각 별도 난이도/생성/이벤트 경로 | 이세계모드 자체의 보너스로 잘못 집계하지 않음 |

추가 자료: [ORDR 2.320 패치노트](https://ordr.kr/patch-notes/2-320), [2.321](https://ordr.kr/patch-notes/2-321), [2.322](https://ordr.kr/patch-notes/2-322), [2.323](https://ordr.kr/patch-notes/2-323), [원본 악몽 몬스터 연구 조사](../data/original-2323C-nightmare-monster-tech-evidence.json), [웨이브 원본 코드 분석](원본-몬스터-웨이브-연결.md).

**구현 정책:** 이세계모드 ON을 캐릭터·개인미션·해당 도박/항법의 조건으로 분리하되, 연구 `R00P` 또는 `tu`가 직접 몬스터 강화에 연결된다는 추출 근거가 확보되기 전까지 **이세계 전용 몬스터 HP/방어 가산을 넣지 않습니다.** 원본 전투의 불확실한 값은 기존처럼 `safeForVerifiedMonsterWaveRuntime:false`를 유지합니다.

- 13종 공통: **10,000골드 + 목재 7 + 행운의토큰**. **고죠 사토루는 해적선도 추가로 표기**되어 있습니다. 해적선과 토큰의 실제 원본 판정/소모 방식은 미확인입니다.
- **5종**(고죠, 바쿠야, 야쿠모 유카리, 콘파쿠 요우무, 히그마)은 ‘랜덤 등급 유닛’ 추가 1기가 필요합니다. 고정 랜덤 재료와 **다른 인스턴스**가 필요하므로 도감 조합 보조 기능도 중복 선정을 막습니다.
- 기존 랜덤 등급 **14종**도 `data/characters/by-grade/RN.json`에 이름·스킬이 수집되어 있습니다. 다만 14종 모두의 모드별 생성/해금 조건은 아직 별도 검증이 필요합니다.
- `OtherworldMysticFusionCatalog`는 완전한 ID/수량/비용 목록을 읽고, `OtherworldMysticFusionPreviewPort`는 보유 유닛을 기준으로 모바일 재료 선정 미리보기를 제공합니다. 스토리 파견 중인 유닛은 제외하고 동일 인스턴스를 두 번 쓰지 않습니다.
- **원본 제작 트리거와 재료 원자적 소비의 검증 전에는 실제 합성 실행이 불가**합니다. 데이터의 `authorizedForConsumption:false` 및 `CanExecute:false` 유지. 도감 수치만으로 원본 제작이 완료된 것으로 취급하지 않습니다.
- 테스트: Python 도감 데이터 유효성 3건 + Unity EditMode 신규 항목 7건(실행 결과는 CI에서 확인).
