# 전 등급 방어력 감소 오라의 공통 런타임 연결

> **자료의 위치:** 본문은 해당 기능의 원본 근거와 작성 당시 구현 기록입니다. 현재 실행 범위는 [START_HERE](START_HERE.md), 다음 작업은 [PLAYABLE_ROADMAP](PLAYABLE_ROADMAP.md), 운영 정책은 [AGENTS](../AGENTS.md)를 우선합니다. 본문의 과거 APK/테스트 보류·사거리·다음 작업을 현재 지시로 복사하지 않습니다.

시작 main `ea041b6`. 전 유닛 감사 자료의 원본 AHad 음수 방어력 필드를 유닛 이름·등급별 하드코딩 없이 읽도록 연결했다. **정의 확보와 원작 실기 실행 승인은 별개**다. 원본 공격력·간격·쿨타임·확률·조합은 변경하지 않았고 APK는 만들지 않는다.

## 연결 범위

`Original323ArmorAuraCatalog`는 기존 `original-2323C-all-unit-aura-audit.json`에서 **54종, 레벨별 61개 방깎 정의**를 읽는다. 14개 등급에 걸친 대상이며, 특별함 두 방깎도 이 경로로 읽어 중복 등록하지 않는다. 기존 특별함 이감 3종·가드포인트 공격 버프 1종을 함께 보존하면 총 58종의 오라 정의가 같은 런타임에 들어간다. 이 수는 캐릭터의 모든 스킬 구현 완료 수가 아니다.

예: X-드레이크 A132 -5/825, 레일리(전설) A06Q -20/900, 우솝(초월) A0OS -8/99999와 A0OR -22/1085, 조로(초월) A0QE -30/-35/-42 및 반경815, 핸콕(영원) A0NR -35/-40 및 반경850. 원본 값·레벨·능력/버프 ID·대상 마스크·반경을 보존한다. 적재한 모든 레벨을 동시에 적용하거나 최고 레벨을 자동 선택하지 않는다.

- `IOriginal323AuraCatalog.FindAll` / `CharacterCombatRuntime.OriginalAurasOf`로 한 유닛의 여러 능력·레벨을 전달한다. 기존 단일 오라 조회는 호환용으로 첫 정의만 반환하므로 새 코드는 복수 조회를 사용한다.
- 실제 효과 출처는 `original-aura:<개체>:<능력>:<버프>:<레벨>`이다. 효과 객체 참조를 검증하는 기존 방어 계산기에 연결한다. 레벨이 바뀌면 이전 효과와 그 승인도 제거한다.
- 같은 능력 A132를 가진 서로 다른 카탈로그 유닛(X-드레이크/킹)도 중복 비중첩 규칙을 공유한다. 각 소환 개체의 제거 수명주기는 독립이다.
- 한 개체의 서로 다른 오라도 반경과 대상 자격을 따로 확인한다. 서로 다른 오라를 합산하거나 강한 값으로 선택하는 미확인 계산은 계속 거부한다.
- Unity 데이터 동기화 목록에 감사 JSON을 추가하고 컨트롤러에서 읽어 공통 런타임을 구성한다. 이전 6종 자료만 있는 외부 호출도 유지한다.

## 실제 적용에 필요한 독립 근거

`IOriginal323SpecialAuraTargetRules`는 이름이 남아 있는 기존 호환 인터페이스이며 이제 전 등급을 받는다. 각 정의의 **현재 실제 능력 레벨**, 전체 마스크(고대/자폭/영웅 제외 등 포함), 적/아군·면역, 원본 틱과 잔류·현재 버프 존재를 확인해야 한다. 단순히 소유 유닛의 기본 능력 목록에 있다는 이유로 true를 반환하면 안 된다. 엄격한 현재 반경 경로에서 원본 잔류를 재현할 수 없는 경우도 승인하지 않는다.

방깎에는 추가로 `IOriginal323FlatArmorAuraRules.IsVerifiedFlatArmor`의 명시적 고정 방어력 모드 근거가 필요하다. SLK의 `DataB`가 없으면 `RawArmorPercentageMode=null`로 보관한다. null을 0으로 채워 고정값 모드를 추측하지 않는다. 이 독립 근거가 없거나 false/빈 문자열이면 대상 자격이 승인되어도 방깎을 부여하지 않는다. 기존 특별함 두 방깎도 같은 조건을 적용한다.

**실제 원본 상태/모드/틱 공급자는 아직 없다.** 기본 설정에서 이를 임의 승인하지 않는다. `safeForUnconditionalLiveCombat:false`와 몬스터 최종 HP/방어 미검증 경계도 유지한다. 이번 작업은 공통 정의→수명주기→검증된 방어 계산기 연결이며, 최종 악몽 몬스터 수치나 모든 오라의 실기 검증 완료가 아니다.

## 제외·검증

E-02 객체 목록 미확인, 타시기(초월) A0JI의 0값/0반경, 거프(불멸) A0VE의 **양수** 방어력은 방깎으로 만들지 않고 제외 사유를 노출한다. W3A 오버레이 병합이 필요한 능력, 퍼센트 모드가 명시된 능력, 미확인·비지속 필드는 자동 적용하지 않는다. 음수 방깎 이외의 양수 방어·다른 공격력/속도 오라 확대는 별도 작업이다.

Unity 회귀 검사는 전체 정의 수/소유자/원시 필드, 복수 능력의 전체 마스크, 능력 레벨 변경·제거, 이전 효과 참조 거부, 모드/대상 근거 누락, 서로 다른 유닛의 동일 오라, 개별 반경, 미검증 혼합 거부, 기존 6종 유지, 전 등급 방깎의 실제 HP 감소 전달을 확인한다. 여기 쓰인 모드·대상·정수화 공급자는 **합성 테스트 정책**이며 Warcraft 원작 검증으로 승격하지 않는다. 실행 결과는 해당 main 커밋의 기존 Unity EditMode CI에서 확인한다.

후속 작업은 공유 버프의 서로 다른 능력/레벨 선택과 실제 몬스터 대상 속성·면역/현재 버프 자료를 연결하는 것이다. 원본 근거가 없는 최종 피해·이동 계산은 추가하지 않는다.
