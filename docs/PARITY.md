## 기준
- 대상: ORDR S2 2.323[C]
- 고정 모드: 악몽 난이도 + 이세계모드
- 플랫폼: Unity 모바일 오프라인 싱글플레이

1. 해당 버전의 인터넷 도감·조합표·공략을 우선 조사합니다.
2. 출처별 URL, 버전, 확인일, 확실성을 기록합니다.
3. 도감 자료가 불충분하거나 서로 충돌하고 플레이에 중요한 경우에만 원본 W3X를 분석합니다.
4. 불확실한 수치를 임의로 만들어 넣지 않습니다.
