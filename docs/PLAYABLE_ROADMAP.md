2. 보조 그래프는 연구·진화체·해독·크립·스토리·65R를 준비하지만 씬에 공개하지 않습니다. 스토리 보상 포트는 전체 소유자 복구 전에 연결하면 보류 보상을 실행할 수 있어 결합 순서를 유지해야 합니다.
3. 물품 지원은 MoneyDesk.MaterialSupport로 저장되고 **비공개 거래 복원 그래프**에도 결합했습니다. 남은 과제는 권리·항법/능력·추가 난수, 보상 유닛 소유권을 전체 월드와 안전하게 재결합하는 것입니다. 별도 중복 저장 필드는 만들지 않습니다.
4. 기존 마르코/마리아 수동 상태, TR-03/TR-06 변신, 비보유 가상 공격 효과, 모바일 난수 4종은 기존 코드에 기반하여 누락 상태만 보완합니다.

상세 계약: [저장·이어하기 구현명세](저장-이어하기-구현명세.md). 종료 중 저장·손상 슬롯·중복 보상·예약 타격·난수 순서·파견 상태의 실행 검증은 Q01/Q02/Q04에 묶습니다.

### 구현 절차 S01~S03

아래는 **앞으로 적용할 구현 설계**입니다. 제안하는 필드/단계 이름은 기존 API가 있다는 뜻이 아니며, 실제 클래스에 같은 역할이 있으면 확장해서 사용합니다.

**1단계 — 상태 소유자별 저장 누락표를 먼저 만든다.** 컨트롤러가 보유한 각 서비스마다 ‘상태 소유 클래스 / 캡처 호출 / 검증 호출 / 복원 호출 / 참조하는 다른 서비스 / 아직 거부하는 상태’를 한 행으로 기록합니다. 개별 CaptureState가 있어도 컨트롤러가 호출하지 않거나 복원된 서비스가 UI에 연결되지 않으면 미완료로 남깁니다.

**3단계 — 이미 구현된 상거래 재결합을 완성한다.** OrdrCommerceRestoreGraphBuilder와 기존 보류 추첨/물품 지원 복원 포트를 재사용합니다. 원본 권리·항법·능력·공유 지갑·개별 난수·실제 보상 유닛을 전체 월드에 연결하고 누락 상태는 거부합니다.

**4단계 — 동기 캡처 경계를 전 서비스로 확대한다.** 기존 CaptureCheckpointAtSafeBoundary가 시계/지갑/로스터/미션과 수동 일시정지 복원을 보장합니다. 다른 전투·스토리/시설·아이템 소유자의 거래 중 상태·리비전을 함께 검증해 한 시점 스냅샷만 기존 A/B 파일에 기록합니다.

**5단계 — 복원한 객체들을 묶어서 한 번에 교체한다.**

1. 형식·해시·필수 자료 검사 → 코어/지갑/로스터/난수 준비.
2. 원래 적/아군 ID와 원본 스펙 등록 → 파견 등 소유권이 필요한 대상은 정지 상태로 준비.
3. 스토리·크립·연구·해독·공유 목표·상거래 월드 구성 및 상태 로드.
4. 소유권·버프·폼·예약 효과·공격 시계 재결합 → 전역 교차 검증. 기존 빌더가 일부를 먼저 복원하면 그 순서를 검토해 외부 참조가 생기기 전 실행되지 않게 분리.
5. 새 객체 묶음에 화면/입력/이벤트 수신 대상을 연결하고 틱 경계에서 활성 세션을 교체. 이전 객체는 교체 성공 뒤 구독 해제/Dispose.
6. 실패하면 임시 객체와 임시 구독만 폐기. 현재 세션과 정상 저장은 그대로 유지.

검증 전에 `Start`, `BeginRound`, `SpawnCharacter`, 보상 지급 콜백을 호출하지 않습니다. 미처리 보상은 복원 완료 후 기존 영수증 처리기로만 이어갑니다.

**6단계 — 마지막에 이어하기 화면을 연다.** 전체 상태를 지원하고 통합 검증을 마친 뒤 저장 유무/지원 버전/손상 여부에 맞춰 진입을 연결합니다. 최신 슬롯이 손상됐을 때 이전 정상 슬롯을 찾되, 형식 미지원과 파일 손상을 구분합니다. 구형 부분 초안은 누락 상태를 0으로 채워서 실행하지 않습니다. 정확한 UI 위치·새 자동저장 정책이 기존 합의 밖이면 먼저 의견을 확인합니다.

**통합 확인 장면:** 마리아 주기 효과·파견 유닛·도박 보류 결과가 동시에 있는 저장을 복구해 유닛 ID/재화/난수 다음 값/다음 타격 시각을 비교합니다. 복원 도중 실패를 넣었을 때 기존 게임이 유지되는지, 같은 저장을 두 번 읽어도 새 보상을 받지 않는지 확인합니다. 실행은 요청 시에만 합니다.

### 화면 연결 방식

- **시트 매핑:** 기존 에셋 로더에서 원본 이미지·셀 사각형·대상 유닛/건물 ID를 연결하는 매핑을 추가합니다. 셀의 실제 캐릭터를 확인한 것만 매핑하고 이름 유사성으로 다른 등급에 자동 배정하지 않습니다. 기존 캐시를 재사용해 매 프레임 텍스처를 생성하지 않습니다.
- **전장 표시:** 논리 좌표→화면 좌표 변환을 공통으로 사용해 적·유닛·투사체·HP 표시를 맞춥니다. 표시용 이미지 크기가 실제 사거리/충돌 판정을 바꾸지 않게 합니다.
- **수동 스킬:** 현재 선택된 OwnerInstanceId의 버튼만 표시하고, 대상 선택 중에는 전장 터치를 기존 대상 시전 처리기가 먼저 받습니다. 버튼 활성/쿨타임/재료 수량은 실제 서비스 값에서 읽으며 UI 전용 가짜 타이머를 두지 않습니다.
- **스크롤/배속:** 스와이프로 인정된 입력은 같은 터치의 버튼 클릭을 소비하지 않게 기존 드래그 처리를 보완합니다. 배속은 기존 `MobileGameSpeedClock` 한 곳에서만 반영하고 효과·스토리·해독이 다시 배율을 곱하지 않게 합니다.
- **글꼴:** 기존 `ApplyBundledFonts`의 역할별 폰트를 재사용합니다. 작은 화면에서 최소 글꼴·줄바꿈·스크롤을 점검하며 폰트 교체로 가격/수량이 잘리면 실제 레이아웃을 수정합니다.

완료 확인은 실제 가로 휴대폰/태블릿 화면에서 마지막 메뉴 접근, 스킬 스와이프 후 오발동 없음, 실제 HP/수량 가독성, 배속·정지·앱 복귀 시 논리 시간 일관성으로 합니다. 새로운 화면 구성이나 장식은 추가 승인 범위로 확대하지 않습니다.

## 재구현하지 않을 기반과 완료 판정
