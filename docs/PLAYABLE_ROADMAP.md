## 3. 요청받으면 수행할 통합 확인

- 최신 검사 통과 후 기존 워크플로로 새 APK를 제작하고 소스 커밋·해시·서명을 기록합니다.
- 실제 기기에서 준비 → 위습/조합 → 65R와 스토리 → 보상·승패까지 확인합니다. 소환수 귀속, 5% 고유 보상의 중복 방지, 그린블러드 대상 선택도 포함합니다.
- 작은 가로 화면에서 유닛 개별 선택·조합 임박·파견/복귀·카메라 경계와 일시정지/앱 전환을 확인합니다.
- 60~65R 다수 적·유닛·스킬 상황의 프레임 시간·메모리·발열을 측정한 뒤 병목을 개선합니다.

실행하지 않은 항목은 미검증으로 유지합니다. APK 생성 성공과 설치/플레이 성공은 별도로 기록합니다.
