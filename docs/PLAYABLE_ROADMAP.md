# 개발 작업

이 문서는 실제로 남은 **개발 작업과 완료 조건**을 다룹니다. 각 행의 ‘코드 연결’ 표시는 작성 당시 확인된 범위이며 최신 `main`의 Unity·APK 검증을 뜻하지 않습니다. 작업 직전에는 [현재 상태](START_HERE.md)·[코드 구조](CODE_MAP.md)·[데이터 안내](../data/README.md)와 실제 최신 코드를 대조합니다.

**최종 기능의 빠짐없는 범위는 [전체 기능 구현 대장](전체-기능-구현대장.md)에 있습니다.** 이 개발 작업 문서는 *지금 손댈 미완료 연결점과 검사 항목만* 추적합니다. 기능이 완료되면 이 목록에서 지울 수 있지만 **전체 기능 대장에서는 지우지 않습니다.**

이 목록은 **구현·원본 조사 26건과 실행 검증 5건**을 구분합니다. ‘연결됨’은 코드 경로가 있다는 뜻이며 실기 통과를 의미하지 않습니다. 아래 번호는 고정 작업 ID이며 차수·예상 완성 날짜가 아닙니다.

## 먼저 할 순서

기본 우선순위는 캐릭터 고유 기능입니다. **C01·C02 원본 명세/전투 코드 연결 완료(실행 검증 전) → C03 누락 콜백 분류 진행(5개 피해 경로 연결) → C04 남은 기술 효과 일괄 구현**을 권장합니다. 돈 도박 졸업 구매 **M01/M02는 코드상 연결**되어 있고, 실제 기기·원본 초기 재고/난수 동등성 확인은 Q02로 남깁니다. 이세계 도박·카지노/리스크헷지·희귀/랜덤 리롤과 하급/중급/고급 도박·미션은 코드 연결했으며 **M03 해왕류 정산·M06 환전소 구현**, **P04~P06 연구·강화·항법 전수**, 전체 저장은 **S01 → S02 → S03**으로 진행합니다.

**조합 UI 코드 반영 · 실행 검증 대기:** 가로형 전장 오른쪽 패널의 전체/가능/임박/★ 저장·등급 필터·페이지, 결과 카드 초상화와 **유닛·돈·나무 한 줄 재료 띠(가로 스크롤)**, 고정 하단 **‘조합 확정’ 1거래 버튼**을 소스에 구현했습니다. **이름 검색·1회/3회 수량 선택·장식성 준비 문구를 제거**하고 기존 원본 거래 처리기를 그대로 재사용합니다. 거래 1건의 **원본 결과 개체 수량**은 바꾸지 않았습니다. **Unity 컴파일·Android 실행·실제 소비 및 회귀 동작은 미검증**이며, 기존 APK에는 아직 미반영입니다. [전체 UI 요구](전체-기능-구현대장.md) · [화면 조작](화면-조작-시스템.md).

원본 근거가 없는 항목은 추측해 활성화하지 않고 필요한 함수·객체·조건을 특정합니다. 그 항목이 막혀도 근거가 있는 다른 작업은 진행합니다. 테스트·Unity·APK 실행과 Actions 조회는 [작업 규칙](../AGENTS.md)에 따라 명시적 요청 시 수행합니다.

## 작업을 닫는 기준

각 작업은 **실제 연결점 + 원본 근거 + 비용/상태/생명주기 + 해당 범위 검사 결과(또는 미실행 명시)**를 남긴 뒤 닫습니다. 구현 완료와 실행 검증 완료는 따로 적습니다. C03/F02 같은 조사 과제는 ‘무엇이 빠졌는지와 다음에 고칠 위치가 확정됨’이 완료 조건이며, 조사가 끝났다고 해당 기능을 구현 완료로 표시하지 않습니다.

새 채팅은 작업 ID 하나와 관련 코드/근거부터 읽고, 공통 원인인 작업만 묶어서 진행합니다. 완료한 행은 현재 상태로 옮기거나 삭제하고 날짜별 진행 이력을 이 목록에 누적하지 않습니다.
