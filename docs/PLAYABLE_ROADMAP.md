# 개발 작업

이 문서는 실제로 남은 **개발 작업과 완료 조건**을 다룹니다. 각 행의 ‘코드 연결’ 표시는 작성 당시 확인된 범위이며 최신 `main`의 Unity·APK 검증을 뜻하지 않습니다. 작업 직전에는 [현재 상태](START_HERE.md)·[코드 구조](CODE_MAP.md)·[데이터 안내](../data/README.md)와 실제 최신 코드를 대조합니다.

**최종 기능의 빠짐없는 범위는 [전체 기능 구현 대장](전체-기능-구현대장.md)에 있습니다.** 이 개발 작업 문서는 *지금 손댈 미완료 연결점과 검사 항목만* 추적합니다. 기능이 완료되면 이 목록에서 지울 수 있지만 **전체 기능 대장에서는 지우지 않습니다.**

이 목록은 **구현·원본 조사 28건과 실행 검증 5건**을 구분합니다. ‘연결됨’은 코드 경로가 있다는 뜻이며 실기 통과를 의미하지 않습니다. 아래 번호는 고정 작업 ID이며 차수·예상 완성 날짜가 아닙니다.

## 작업을 닫는 기준

각 작업은 **실제 연결점 + 원본 근거 + 비용/상태/생명주기 + 해당 범위 검사 결과(또는 미실행 명시)**를 남긴 뒤 닫습니다. 구현 완료와 실행 검증 완료는 따로 적습니다. C03/F02 같은 조사 과제는 ‘무엇이 빠졌는지와 다음에 고칠 위치가 확정됨’이 완료 조건이며, 조사가 끝났다고 해당 기능을 구현 완료로 표시하지 않습니다.

새 채팅은 작업 ID 하나와 관련 코드/근거부터 읽고, 공통 원인인 작업만 묶어서 진행합니다. 완료한 행은 현재 상태로 옮기거나 삭제하고 날짜별 진행 이력을 이 목록에 누적하지 않습니다.
