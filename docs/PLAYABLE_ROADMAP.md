1. `RestoreActorWorldDraft`는 스토리·공유 출전·해독 중인 유닛을 아직 거부합니다. 관련 세션 복원과 실제 유닛 소유권/전장 연결을 함께 완성해야 합니다.
2. 보조 그래프는 연구·진화체·해독·크립·스토리·65R를 준비하지만 씬에 공개하지 않습니다. 스토리 보상 포트는 전체 소유자 복구 전에 연결하면 보류 보상을 실행할 수 있어 결합 순서를 유지해야 합니다.
3. 물품 지원은 자체 저장 코드와 돈 도박 서비스 연결이 존재합니다. 상위 돈 도박 상태를 포함한 전체 캡처→새 서비스 구성→복원 경로를 대조해 구매 횟수/보류 추첨이 실제 복구되는지 확인합니다. 필드가 코어에 직접 없다는 이유로 미구현이라고 단정하지 않습니다.
4. 현재 지원되는 마르코/마리아 수동 상태, TR-03 각성·TR-06 숲인간, 일부 가상 공격자 저장을 재작성하지 않습니다. 지원 밖 상태와 비원본 난수 공급자를 추가한 뒤 전체 조정자에 연결합니다.
