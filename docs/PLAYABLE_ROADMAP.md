## 2. 요청받으면 수행할 통합 확인

선행 Python 검사 불일치는 정리됐습니다. 다음 검사 환경에서는 Linux 패키징 계약과 Unity EditMode를 확인하고, C# 실행 지원을 실제로 내보내어 저장된 모델 지원 스냅샷의 최신성을 대조합니다. 로컬 JSON 일치 검사를 Unity/기기 검증으로 대신하지 않습니다.

- 최신 검사 통과 후 기존 워크플로로 새 APK를 제작하고 소스 커밋·해시·서명을 기록합니다.
- 돈 도박의 부족 재화/정지 시 무소비·무추첨, 실제 아론 격파 해금, 35000 정확/초과 졸업, 목재 기회 소모와 지갑 복원·커밋 후 예외를 확인합니다.
- 실제 기기에서 준비 → 위습/조합 → 65R와 스토리 → 보상·승패까지 확인합니다. 소환수 귀속, 5% 고유 보상의 중복 방지, 그린블러드 대상 선택도 포함합니다.
- 작은 가로 화면에서 유닛 개별 선택·조합 임박·파견/복귀·카메라 경계와 일시정지/앱 전환을 확인합니다. 스토리 공성 표시의 일렬 대형/페이지·건물 HP·실제 피격·격파 잔해·다음 건물 전환, 소환수 귀속, 복귀/판매/조합 후 제거도 포함합니다.
- 60~65R 다수 적·유닛·스킬 상황의 프레임 시간·메모리·발열을 측정한 뒤 병목을 개선합니다.

실행하지 않은 항목은 미검증으로 유지합니다. APK 생성 성공과 설치/플레이 성공은 별도로 기록합니다.
