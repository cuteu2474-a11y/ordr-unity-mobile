# 전설 조합과 20라운드 연습

`49642e3`의 희귀함 성장 묶음에서 이어 전설 제작과 더 긴 연습 전투를 연결했다. 원본 맵 파일은 읽기만 하며 변경하지 않았다.

## 추가 기능

- 전설 조합 31종을 추가했다. 실제 제작 가능한 조합은 안흔함 13 + 특별함 31 + 희귀함 41 + 전설 31 = **116종**이다.
- 검수한 전설 31종은 원본에 등록된 유닛 재료와 **목재 3개**를 요구한다. 보유 목재를 조합 목록에 표시하고 확인 시 다시 검사한다. 목재 부족·오래된 재료 선택은 소비 전에 거부한다.
- 재료 교체와 같은 거래 안에서 목재를 차감한다. 결과를 준비한 뒤 지갑 차감을 확인하고 재료 교체를 확정하며, 실패 시 지갑과 준비한 결과를 복구한다. 성공 후 같은 확인을 다시 눌러 중복 소비할 수 없다.
- 목재 잔액이 바뀌면 열려 있는 플레이/조합 메뉴의 준비 상태도 갱신한다.
- 전설도 별도 개발용 연습의 객체 기본 공격을 사용한다. 미완성 기술·오라·네이티브 광역 평타를 임의의 피해로 대체하지 않는다.
- 기본 전투 시작 버튼은 **20R 연습 전투 시작**이다. 플레이 메뉴의 준비 단계에서는 **10R / 20R**를 고를 수 있다. API 기본 인수는 기존 10R로 유지했다.
- 11~20라운드의 원본 출현 객체·수량·0.5초 출현 간격을 기존 웨이브 시스템에 연결한다. 20라운드 보스까지 처치하면 연습 완료이며, 제한시간·적 70마리 누적 패배·새 라운드 위습 2개·실제 처치 골드·라운드 기록은 같은 세션에서 처리한다.

## 원본 대조

[전설 감사 자료](../data/original-2323C-legendary-growth.json)와 [감사 도구](../tools/audit_original_legendary_growth.py)는 원본 JASS·AbilityData.slk의 고정 SHA, 결과 객체·재료·시전자 소유 능력·WOOD 비용·타깃 없는 시전 타이밍을 대조한다.

원본 `CH8`에서 추가 생성 처리가 필요한 전설 6종과 원본 객체 변형 재료가 아직 매핑되지 않은 조합 2종은 열지 않았다. 제외 능력은 A00O/A02D/A025/A0UG/A01S/A02Q/A02G/A113이다. 전체 전설 39종을 완성했다고 표시하지 않는다. 희귀함 브룩 음악가의 객체는 전설 재료 식별용으로 연결했으며, 기존 미검수 A1A0 제작을 풀거나 유닛을 무료로 주지 않는다.

몬스터 자료는 기존 **참조 엔진 기반 악몽 초기 HP/방어 모델**을 20라운드까지 읽은 것이다. 예를 들어 20라운드 보스 모델은 원본 객체 `o01W`, HP 807500이며, 이를 원작 최종 전투 수치로 승인하지 않는다. 두 미검증 플래그는 false를 유지한다. 자료 생성기는 원본 맵을 수정하지 않는다.

10R는 10에서, 20R는 20에서 끝난다. 65라운드 정식 클리어 보상이나 베리를 지급하지 않는다. 희귀함/전설 자동 위습과 전체 게임 저장은 아직 미연결이며, 원작의 모든 스킬·오라·연구·동적 몬스터 보정이 재현됐다는 의미가 아니다.

## 검사

- 고정 원본 대조: 전설 31종의 실제 재료와 목재 3개 확인.
- 로컬 Python 회귀 **152건 통과**, `git diff --check` 통과.
- Unity EditMode에 전설 31종의 실제 재료 소비/목재 차감/결과 생성, 확인 이후 목재 변경 시 재검사, 전설 기본 공격·스킬 차단, 20R의 632마리 실제 처치/라운드 위습 38개/20개 기록 합계와 중복 방지, 10R/20R 보스 시간초과, 지원하지 않는 길이 거부와 준비 상태 보존을 추가했다.
- 20R 완료 검사의 강한 전설 편대는 검사 전용이다. 실제 게임에서 유닛·재화를 무료로 지급하지 않는다.
- 로컬 Unity 실행 환경은 없어 Unity 검사·Android APK 생성은 기존 GitHub Actions에서 수행한다. Actions 실행 시작 후 결과는 별도 요청 전 조회하지 않는다. APK 빌드 성공·실기 설치·플레이 확인을 완료로 표시하지 않는다.
