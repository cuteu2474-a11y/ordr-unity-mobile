## 이번 단계

기존 도감 캐릭터 271종 중 스킬 설명 프로필이 있는 캐릭터는 200종, 없는 캐릭터는 71종이다. 이 71종에 대해 `data/original-2323C-map-base-stats.json`의 **원본 유닛 객체에 기록된 능력 rawcode와 순서**를 캐릭터 ID별로 연결했다.

| 등급 | 툴팁 상세 프로필 없는 수 | 원본 맵 유닛 및 능력 목록 연결 |
|---|---:|---:|
| 희귀함 | 24 | 24 |
| 특별함 | 25 | 25 |
| 안흔함 | 13 | 13 |
| 흔함 | 9 | 9 |
| 합계 | **71** | **71** |

해당 71종이 참조하는 능력 rawcode는 중복을 제외하면 **181종**이다. 예시:

| 캐릭터 | 원본 유닛 rawcode | 맵 객체에 저장된 능력 코드(순서대로) |
|---|---|---|
| 희귀 도플라밍고 (`R-04`) | `h01L` | `A0K2, A057, A07Y, A058, A0B9, A009, Avul` |
| 흔함 루피 (`C-01`) | `h003` | `A0JE, A09G, A00D, A012, Avul` |

위 코드가 실제로 **공격 발동 스킬인지, 패시브인지, 강화나 시스템 공통 능력인지** 아직 판정되지 않았다. 예컨대 여러 유닛에서 같은 rawcode가 보인다는 통계는 조사 우선순위의 힌트일 뿐, 그 기능을 입증하지 않는다.

원본 객체의 기본 능력치가 이미 연결된 `OriginalMapBaseStatCatalog`에 `OriginalAbilityRawcodes` 읽기 전용 접근자를 추가해 Unity 런타임에서도 원본 순서를 확인할 수 있다. **원본 효과나 데미지는 만들어 넣지 않았다.**

## 생성 파일 및 검증

- `data/original-2323C-missing-skill-profile-evidence.json`: 누락 71종, 원본 객체 이름·rawcode·원본 능력 코드 목록·공유 빈도·출처·미검증 상태.
- `tools/build_missing_character_skill_evidence.py`: 세 개의 원천 데이터에서 동일 결과 재생성.
- `tests/test_missing_character_skill_evidence.py`: 전체 71종, 버전·이름 일치, 순서 유지, 잘못된 출처 차단, 효과 미확정 검증.
- `Assets/Scripts/Data/OriginalMapBaseStatCatalog.cs`: 능력 코드 목록을 원본 순서로 노출하되, 길이 불일치/중복 코드 거부.

```bash
python3 tools/build_missing_character_skill_evidence.py --verify
python3 -m unittest discover -s tests -q
```

## 다음 작업의 정확한 의존성

1. 원본 2.323[C]의 능력 객체 데이터(특히 `war3map.w3a`)에서 181종의 능력 효과·레벨·계수·적용 범위를 확인한다.
2. `war3map.j` 스킬 트리거와 해당 유닛 rawcode를 연결하여 발동 이벤트, 확률, 쿨타임, 피해 순서를 확정한다.
3. 실제 확인된 효과만 `character-skill-profiles.json`의 스킬 정보로 승격하고, 자동 발동을 테스트한다.
4. 단순 시스템 능력/기본 공격만 보유한 유닛은 **원본 확인 후**에만 ‘스킬 없음’으로 판정한다.

원본 코드가 없거나 내용이 미확정이면 빈 프로필을 스킬 완료로 둔갑시키지 않는다. 이 단계의 **원본 스킬 공식 검증 완료는 0개**다.
