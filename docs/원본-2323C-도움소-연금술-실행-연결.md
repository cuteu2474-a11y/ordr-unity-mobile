# 도움소 h08A 연금술 A0J2 실행 연결 (S2 2.323[C])

## 검증 근거

- 사용자 원본 W3X SHA-256 `0794996c9bc73eaa3020f20ebc45fb37cfa64a6e98ffe8aa0dfa3b356e77bc5c`
- `war3map.j` SHA-256 `96201e80edec1b2764f85818760306c6b2f0becd390ba4d63f41c86f3dfaff6d`
- `CJZ`: 소유권 확인 후 `A0BA` 또는 `A0B9` 능력 레벨 양수, 혹은 원본 ID `h01C`/`h015`이면 대상 허용. 대상 제거 후 `R3` 능력 목록을 따라 `CJY` 호출
- `CJY`: 원본 BGI 조건 중 `UNIT`만 환급. 플레이어 시작 위치에 생성, `holdposition` 명령, 언데드 유닛에는 `A07Y` 추가
- `Units/AbilityData.slk`: `A0J2` 마나 100, 쿨타임 5초, 사거리 99999
- `tools/extract_original_helper_alchemy.py`: 원본 JASS와 265개 등록 대상의 UNIT 환급 순서/수량 검증

## 이번에 구현한 실행 경로

1. 사용자가 연금술 탭에서 유닛을 고르고 **실행 선택 → 최종 확정**을 누릅니다.
2. `Ordr323OriginalAlchemyCastService`가 실제 마나·스킬 보유·진행 시각·쿨타임을 검사합니다.
3. 원본 월드의 **배타적 거래**에서, 선택 인스턴스가 현재 소유한 진짜 원본 유닛인지와 실시간 `A0BA/A0B9` 레벨을 확인합니다.
4. 원본 시전 가능 상태를 확인하고, 등록된 경우에만 해당 원본 `CJY` 환급식 전달합니다.
5. 같은 거래에서 **마나 차감·유닛 제거·UNIT 재료 생성·원본 후속 효과**를 처리하고 확정합니다. 실패하거나 예외가 발생하면 미확정 거래를 전부 롤백해야 합니다.
6. 성공한 경우에만 5초 쿨타임을 시작합니다.

관련 코드: `Assets/Scripts/Combat/Ordr323OriginalAlchemyCastService.cs`,
`Assets/Scripts/Unity/OrdrCharacterCombatController.cs`,
`Assets/Scripts/Unity/OrdrMobileTouchPanel.cs`.

## 아직 연결해야 할 실제 월드 구현

**현재 기본 Unity 씬은 실행 월드를 자동으로 제공하지 않습니다.** `OriginalUnitRawcodeLabelCatalog`는 이름 기반 미리보기 데이터일 뿐 원본 객체 매핑/소비 승인이 아니기 때문입니다. 아직 실제 소비/환급 플레이가 완료됐다고 보고하면 안 됩니다.

`OrdrCharacterCombatController.ConfigureOriginal323AlchemyCasting(world)`에 연결할 월드는 다음 계약을 충족해야 합니다.

- `IOrdr323AlchemyTransactionalWorld.BeginAlchemyTransaction`에서 플레이어별 배타 잠금과 완전한 롤백 스냅샷을 확보
- `TryInspectTarget`에서 실제 원본 객체 ID/소유자/실제 능력 레벨을 반환하며 웹 도감 유닛명으로 추정 금지
- `TryVerifyOriginalNativeCast`에서 진짜 A0J2 시전 허가와 범위·대상 상태 검증
- `TryApplyOriginalAlchemy`에서 현재 마나 재검사 후 차감, 대상 소비 및 환급 재료의 원본 위치/명령/능력까지 정확하게 반영
- `Commit` 실패, 중간 생성 오류, 실제 대상 소실 시 모든 자원·유닛 상태 원복
- `R3` 환급식이 없는 유효 대상은 원본 `CJZ`처럼 대상만 소비하고 재료를 생성하지 않음

검증 범위: 원본 W3X 환급표 265개 재추출 일치; Python 회귀 95개 통과; Unity EditMode의 새 거래/롤백 테스트는 CI에서 확인해야 함. 모바일 실기 플레이와 실제 월드 어댑터는 아직 미확인.
