# 공통 전투 엔진 확장 (2026-10-21)

원랜디 S2 2.323[C] 악몽·이세계 모바일 독립 Unity 개발.

> **범위 주의:** 이번 작업은 원본 전투 수치가 주입되면 작동하도록 만드는 **공통 전투 엔진 구현**이다. 271종 캐릭터의 원작 전투 성능 검증이나 실제 게임 완성을 뜻하지 않는다.

## 비개발자용 한 줄 설명

유닛의 공격력과 스킬 설명을 집어넣을 **공통 전투 기계**를 크게 개선했다. 하지만 엔진에 넣을 정확한 캐릭터·몬스터 수치, 일부 특수 기술의 원작 규칙, Unity 장면과의 실제 연결은 아직 완성되지 않았다.

## 현재 명확한 미완료 항목

1. `data/units.json`의 **271종 캐릭터 기본 공격력·사거리·공격 주기·피해 계열**은 아직 완전 검증된 등록값이 0종. 공통 엔진의 피해 계산 **인터페이스는 구현**했지만, 검증된 2.323[C] 실제 피해 계산 규칙 공급자는 미구현.
2. `data/character-skill-profiles.json` 200종/554스킬 항목은 **부분 데이터**. 변신·소환·아이템·중첩 특수효과는 별도 핸들러만 열어둔 상태이며 실제 핸들러가 없음. 스킬 데이터 554개가 모두 발동한다는 뜻이 아님.
3. 라운드 몬스터·이동 경로·방어력·특수 보스·도전 크립·자원 보상 원본 데이터 연결 없음. 새 웨이브/경로 클래스는 **검증된 데이터를 넣어야 시작할 수 있음**.
4. Unity `MainGame.unity` 씬에서 웨이브 계획 및 검증된 피해 공급자를 연결하는 구동 서비스는 아직 없음. 기존 `OrdrCharacterCombatController.Awake()`는 카탈로그를 읽지만 전투 세션 자동 시작은 하지 않음.
5. 실제 전투 디버그, Unity 컴파일, NUnit, 모바일 실행, APK 빌드 미진행. **구문/자료형 위주 정적 점검만 수행**, 게임 정상 동작을 검증했다고 주장하지 않음.

## 다음 개발 작업

**공통 엔진의 그릇을 추가하는 것보다** 이제는 도감과 2.323[C] 규칙을 실제 주입하고 소수 캐릭터의 전투를 엔드투엔드로 완성하는 것이 우선이다.

1. 평타 피해 계산과 검증 가능한 기본 공격 스펙 수집·구현
2. 물리/마법/고정/폭발 공격과 방어/저항, 아군 버프·방깎의 원작 보정 확정
3. 쉬운 유닛부터 스킬과 원작 수치 적용. 처치·다단히트·상태이상·사거리·공속의 원작 결과 일치 확인
4. 그 다음 특수 스킬과 캐릭터 범위 확대, Unity 씬에 실제 전투 구동 연결

## 프로젝트 규칙

- `main`만 사용; 신규 브랜치/워크플로 불필요.
- 원본 W3X의 내부 rawcode를 271종 모두 매핑하는 작업은 기능 구현의 선행 조건이 아님.
- 원작 공격력/확률/딜 보정/웨이브 보상이 없는 곳에 임시 게임 수치를 사실처럼 채우지 않음.
- 기능 구현 완료와 실제 실행 검증은 명확히 구분.
