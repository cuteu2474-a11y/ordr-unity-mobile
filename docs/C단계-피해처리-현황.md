# C단계: 피해·처치·누수 연결

기준: ORDR S2 2.323[C] / 악몽 이세계모드

## 구현
- `CombatEnemy`: 적 체력, 실제 적용 피해량, 사망 판정
- `CombatResolution`: 소환 시 세션 적 수 등록, 공격 쿨타임 확인, 체력 감소, 사망 시 처치 수 갱신, 누수 시 누수 수 갱신
- 동일 적의 처치/누수 중복 집계 방지
- NUnit 테스트 3개 작성

## 의도적으로 제외
- 원작의 방어력·마법저항·공격력·스킬 계수에 따른 피해 계산 공식
- 적 처치 골드 및 보상표 (검증 데이터 필요)
- 실제 유닛의 타깃·공격 모션·투사체·광역 스킬
- Unity 장면 및 Android APK

## 자체 검증 범위
- GitHub 파일 등록과 재조회만 가능
- Unity 컴파일/NUnit 실행은 미검증
- 테스트에 등장하는 숫자는 모두 테스트용 가상 값
