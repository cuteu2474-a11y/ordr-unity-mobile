# 개인 미션: 실제 게임 진행·보상·모바일 패널 연결

기준일: 2026-10-27. 기준 main: `e4cc358a28604500146fb765effad73a7a41dfd7`.
원랜디 S2 2.323[C] 악몽·이세계, main 단일 브랜치. APK 미제작.

## 진행 상태 확인

이번 기준 소스의 유닛 카탈로그는 **272종**, 상세 프로필은 기존 200종이다.
최근 변경에는 특별함·희귀함 관측 타격/연속 시전과 공속·공격력 오라 연결이 있지만,
검증 공급자가 필요한 경로와 미구현 실제 게임 시스템이 남아 있다.
데이터 등록·공통 실행 코드·기본 씬에서 실제 동작하는 기능을 구분한다.
전체 캐릭터·65라운드·게임 기능 완성으로 보고하지 않는다.

## 이번에 함께 추가한 기능

1. `PersonalMissionGameplay`: 게임 시작 직전 원본 18종 중 3칸을 중복 없이 준비하고,
   실제 시작 성공 뒤 컨트롤러에 연결한다. 잘못된 난수 공급자는 시작 재화 소비 전에 거절된다.
2. 모바일 개인 미션 탭: 이름·목표·진행도·보상·기한 종료·달성 후 라운드 종료 대기를 표시한다.
   도박중독은 하급/중급/고급 시도 횟수를 각각 표시한다. rawcode 대신 한국어 이름을 쓴다.
3. 원본의 10라운드 전, 전체 게임 1회 교체: 미완료 한 칸을 고르고 확정/취소한다.
   완료·보상 지급 대기 칸은 교체할 수 없고 재화를 차감하지 않는다.
4. `OriginalMissionWalletRewards`: 미션 장부 전용 잔액 대신 상점·조합·위습이 읽는
   동일한 `EconomyWallet`에 목재와 위습을 지급한다. 자동 위습 처리도 기존 지갑 알림을 사용한다.
   특성포인트는 `trait-points`, 기록지침 레벨은 `mission:ability:능력ID`로 보존한다.
5. 보상 묶음의 지급 영수증·추가/설정 레벨을 원자적으로 반영한다.
   로얄로더는 +2가 아니라 원본처럼 레벨2 설정이며, 부분 지급·오버플로 실패는 잔액을 바꾸지 않는다.
6. 실제 성공한 흔함 판매와 선택위습 Merge를 집계한다. 실패·선택·미리보기는 집계하지 않는다.
7. `OriginalJassLiveCombatFusionWorld`는 실제 결과 ID·카탈로그 ID·원본 객체 ID를
   **커밋과 월드 잠금 해제 후** 알린다. 컨트롤러가 결과 소유 능력을 대조하여 미션에 전달한다.
   중복 결과 이벤트는 한 번만 반영된다. 관측자 실패가 이미 완료한 조합/판매를 실패로 바꾸지 않는다.
8. 다음 원본 라운드를 실제로 수락한 시점에 이전 라운드 종료형 미션을 판정한다.
   적이 일시적으로 0명이 되는 것만으로 보상을 지급하지 않는다. 패배는 라운드 종료 보상을 만들지 않는다.
9. 보상 지급 오류는 달성 자격을 유지하고 지급만 다시 시도한다. 원래 거래를 재실행하지 않는다.
   도박·조합의 복수 카운터를 먼저 반영하여 중간 보상 오류로 후속 카운터가 누락되지 않게 했다.
10. 직렬화 가능한 미션 슬롯·기한·카운터·교체 여부·중복 이벤트·지갑/지급 영수증·난수 상태를
    함께 캡처/복원한다. 잘못된 슬롯/중복 카운터/보상 영수증 누락/다른 라운드는 라이브 지갑 변경 전에 거절한다.

## 저장과 난수의 경계

`CapturePersonalMissionProgress`/`RestorePersonalMissionProgress`는 **컴포넌트 저장 API**다.
앱 종료 후 전체 전투·로스터를 되살리는 자동 저장 기능을 추가한 것은 아니다.
반드시 같은 게임의 전투/로스터/라운드 저장을 먼저 복원하고 이 상태를 적용해야 한다.
전체 복원 뒤 자동 위습 처리를 재개하는 순서도 전체 저장 통합에서 다룬다.

기본 `MobileMissionRandom`은 상태 저장 가능한 독립 균등 난수다.
원본 Warcraft 난수열/시드를 재현했다고 주장하지 않으며, 전투 BFh/BFi 난수열을 임의로 소비하지 않는다.
`ConfigurePersonalMissionRandom`으로 실제 원본 미션 난수 공급자를 주입할 수 있다.
외부 공급자의 상태는 해당 공급자의 저장 구현과 함께 복원해야 한다.

기록지침 레벨·특성포인트가 지갑에 기록되는 것과 해당 능력의 실제 효과/연구 소비가 연결되는 것은 별개다.
와일드카드·로얄로더 효과를 이번 변경에서 임의로 만들지 않았다.
3미션 완료의 클리어 추가 베리는 자격 표시만 유지하며, 영구 정산으로 지급하지 않는다.
