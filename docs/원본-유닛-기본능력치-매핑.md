# 원본 유닛 기본 능력치·rawcode 매핑

> **기술 근거:** ORDR S2 2.323[C] 맵에서 추출한 기본 공격 오브젝트, JASS 조합 결과, 이름 교차대조를 정리합니다. 원본 객체 수치와 실제 피해·DPS·스킬 구현은 다릅니다. 2026-10의 수치 집계는 당시 스냅샷이며 최신 구현 범위는 [현재 상태](START_HERE.md)에서 확인합니다.

## 2026-10 원본 조사 당시의 기준

> **현재 개발 지시가 아닙니다.** 당시에는 271종 DB를 기준으로 매핑을 조사했습니다. 현재 최종 범위는 기본·확장 **288항목**이며, [전체 캐릭터·기술 목록](전체-캐릭터-기술목록.md)을 따릅니다.

- 당시 조사에서는 기존 271종 이름·등급 DB를 재사용했습니다.
- **기본 능력치**: 동일한 원본 W3X의 `UnitWeapons.slk`, `UnitBalance.slk`, `UnitAbilities.slk`에서 확인한다.
- **원작 캐릭터 ID**: 맵 이름·등급의 직접 일치, 흔함 9종 직접 확인, 동일한 W3X의 JASS 조합 결과(`CWR`)와 이름 표(`BjB`) 교차 일치, 또는 원본 맵 이름·등급·rawcode를 명시적으로 검토한 별칭만 연결한다. 별칭 연결은 JASS 전투 검증보다 낮은 증거 등급으로 별도 표기한다.
- 게임 중 업그레이드, 오라, 능력·JASS 트리거, 방어 보정, 실제 첫 공격 시각은 **추가 검증 필요**다. 이 작업만으로 캐릭터를 전투 완성 상태로 표시하지 않는다.
- 원본 사거리 필드는 실제 공격 거리와 크립 공격 자격을 검토하는 근거로 유지한다.

### 흔함 9종: 맵 오브젝트 기본 평타

| 캐릭터 | rawcode | 오브젝트 기본 피해량 | 원본 공격 주기 |
|---|---|---:|---:|
| 루피 | `h003` | 29~31 | 1.02초 |
| 조로 | `h002` | 31~33 | 1.03초 |
| 나미 | `h001` | 26~30 | 0.98초 |
| 우솝 | `h007` | 25~27 | 0.84초 |
| 상디 | `h004` | 23~25 | 0.77초 |
| 쵸파 | `h008` | 22~24 | 0.57초 |
| 버기 | `h005` | 29~31 | 0.99초 |
| 해군 총병 | `h009` | 30~32 | 0.96초 |
| 해군 칼병 | `h006` | 28~30 | 0.94초 |

`minimumBaseDamage = dmgplus1 + dice1`, `maximumBaseDamage = dmgplus1 + dice1 × sides1`.
이는 오브젝트에 저장된 기본 수치이며 **피격 대상에게 실제 적용되는 데미지나 실DPS가 아니다**. 도감의 공격력과 다르면 원본 오브젝트 수치를 별도의 우선 근거로 보존한다. 기존 도감 값은 삭제·덮어쓰기하지 않고 별도 근거로 보존합니다.

## 동명이인·변신·보조 객체의 rawcode 구분

`war3map.j`의 `CWR` → `BGH`에 등록된 **조합 결과 rawcode**를 `data/original-jass-fusion-registry.json`에서 확인했다. `BjB`의 이름 연결표가 있는 4종은 해당 rawcode와 교차 검증했다. 같은 이름이라고 공격력이 가장 강한 객체를 자동 선택하지 않는다.

| 캐릭터 | 조합 결과 ID (능력 ID) | 다른 같은 이름 객체 | 스킬 설명과 대조한 사실·한계 |
|---|---|---|---|
| 마르코 제한 | `h08O` (`A011`) | `h09Q` | 인간형·불사조형 기술과 별도 능력치가 있지만 **어느 ID가 어느 형태인지는 미확정** |
| 페로나 왜곡 | `h048` (`IF02`) | `h000` | 다른 객체는 평타가 없고 `Aloc`가 있음. 정확한 보조 객체 사용처는 미확정 |
| 우타 영원 | `h067` (`ET07`) | `h0AF` | 추출된 스탯·능력 목록 동일. 복제 목적은 미확정 |
| 센고쿠 불멸 | `h04E` (`IM06`) | `h0BM` | 공격력·능력 목록 다름. 강화형 여부는 미확정 |
| 카이도 불멸 | `h07M` (`IM11`) | `h0AD`, `h0BW` | 인간형·용형 스킬 설명 존재, 능력 목록도 다름. **형태별 rawcode 할당은 미확정** |

`tools/reconcile_ambiguous_original_map_objects.py`는 원본 조합 결과로 확인된 객체만 캐릭터와 연결하고 나머지는 `alternateRawcodes`에 유지한다. `sourceJassFusionAbilityRawcodes`가 연결 근거다. 이 매핑만으로 변신·스킬 효과·전투 동일성을 선언하지 않는다.

## JASS 조합과 이름 라벨의 49종 교차 연결

기존 104종 미연결 중 **49종**은 `BjB`의 `Bi8(유닛 rawcode, 조합 능력)`·`Bi9(캐릭터 이름)` 자료와 `CWR`의 정확한 조합 결과가 일치했다. 맵의 `UnitWeapons.slk`에도 그 rawcode가 존재한다.

- 히든 5종, 초월 30종, 영원 8종, 불멸 6종을 추가로 연결했다.
- 초월 캐릭터의 맵 오브젝트 이름은 `해적왕이 될 사나이`(초월 루피)처럼 이름·등급 형식이 아니어서 기존 검색에서 누락됐다.
- 예: 초월 루피 `TR-08` → `H099` (`TR09`), 초월 조로 `TR-20` → `H09F` (`TR06`), 영원 니카 `E-01` → `H0BK` (`ET02`).
- 연결 상태는 `verified-jass-label-and-fusion-result`; `sourceJassFusionAbilityRawcodes`가 출처인 조합 능력 ID다.
- JASS/라벨/객체의 rawcode와 출처 SHA, 등급 접미사가 충돌하면 연결을 거부한다. 초월처럼 원본 이름에 등급 접미사가 없다면 **명시적 JASS 조합+이름 교차 확인만** 허용한다.
- 당시 216종의 **오브젝트 기본 수치** 연결이지, 버프·변신·전투 동일성의 인증이 아니다.

## 도감 이름과 원본 이름이 다른 54종 별칭

`CampaignUnitStrings.txt`의 이름과 웹 도감의 이름이 다른 54종에서 **원본 rawcode, 원본 객체 이름, 객체 등급**을 하나씩 고정해 대조했다. 흔한 차이점은 성/별명/변신명 생략 또는 오탈자다.

| 도감 표기 | 원본 W3X 표기 | 확인한 rawcode |
|---|---|---|
| 로빈 (안흔함) | 니코 로빈 - 안흔함 | `h00O` |
| 에이스 2번 대대장 (특별함) | 포트거스.D.에이스 - 특별 | `h01J` |
| 루피 기어써드 (희귀함) | 루피 기어서드 - 희귀 | `h01X` |
| 캡틴 키드 (희귀함) | 유스타스 키드 - 희귀 | `h02D` |
| 쿠마 폭군 (전설) | 바솔로뮤 쿠마 - 전설 | `h030` |
| 바쿠야 (신비함) | 쿠치키 뱌쿠야 - 신비 | `h08I` |

- 전체 54개의 고정 별칭 표는 `tools/reconcile_ambiguous_original_map_objects.py`의 `REVIEWED_MAP_NAME_ALIASES`에 있다. 자동 유사도 추정은 사용하지 않는다.
- 원본 맵의 해당 이름·등급·rawcode가 달라지거나 이미 사용 중인 rawcode와 충돌하면 재생성·검증이 실패한다.
- 매핑 상태 `reviewed-map-name-alias-and-grade`는 **기본 공격 오브젝트의 정체를 연결했다는 뜻만** 가진다. 스킬, 출혈/중첩, 변신, 최종 공격력과 실제 타격 속도는 검증되지 않았다.
- `E-02` 니카(스네이크)는 **당시 조사에서** 원본 객체/조합 결과를 확인하지 못해 미연결로 보존했다. 현재 해소 여부는 최신 데이터에서 확인한다. 다른 니카나 영원 캐릭터에 억지로 연결하지 않는다.
- 도감에 있는 스킬 설명과 원본 오브젝트의 `originalAbilityList`는 성격이 달라, 설명만으로 개별 능력 rawcode와 피해 공식을 연결하지 않는다.

```bash
python3 tools/reconcile_ambiguous_original_map_objects.py --verify
```


## 당시 스킬 연구 큐 (역사적 자료)

기존 수집 자료 `character-skill-profiles.json`에 200종 캐릭터의 스킬 554개와 패시브 295개가 있다. 이번에는 554개 스킬의 **기재된 트리거 / 효과 종류 / 재사용 가능한 구현 그룹**을 자동 분류해 연구 큐를 만들었다.

- 생성 결과: `data/original-2323C-skill-research-queue.json`
- 스킬 분류 그룹: 271개 (숫자가 캐릭터 수와 우연히 같을 뿐 271종 구현을 뜻하지 않음)
- 트리거 분류는 도감 데이터에 기록된 이름 기준이다. **원본 JASS 스킬 ID나 실제 동작이 확인된 것은 아니다**.
- **이 분류는 초기 연구용 묶음**입니다. 현재 스킬별 구현 여부는 [스킬 누락·중복 검토표](스킬-누락-검토표.md)을 확인합니다.


## 데이터 출처·재생성

- 원본 맵 수치: `data/original-2323C-map-base-stats.json`
- 맵 일괄 추출기: `tools/build_original_map_base_stats.py`
- 스킬 분류기: `tools/classify_character_skills.py`
- Unity 읽기 전용 로더: `Assets/Scripts/Data/OriginalMapBaseStatCatalog.cs`
- Unity 편집기 실행 시 `OrdrCharacterDataSync`가 맵 수치 JSON을 Resources에 동기화하며 `OrdrCharacterCombatController.MapBaseStats`에서 조회 가능하다.

원본 맵은 별도 보관하고 리포지토리에 128MB W3X 원본을 추가하지 않는다. `mpyq` Python 패키지가 설치된 환경에서 다음 명령으로 재생성한다.

```bash
python3 tools/build_original_map_base_stats.py --w3x /path/to/ORDR_S2_2.323[C].w3x
python3 tools/classify_character_skills.py
python3 -m unittest discover -s tests -v
```

검증 옵션 `--verify`는 생성물의 내용이 원본에서 재현되는지 비교하며 파일을 수정하지 않는다. 기존 271종 스냅샷 검증 명령 `python3 tools/validate_character_master.py`도 그대로 통과해야 한다.


## 실제 공격 연결 시 주의할 점

- `OriginalMapCommonAttackPreview`의 `AttackPreview`는 **체력을 감소시키지 않는 미리보기**이고, `OriginalMapCommonNativeAttackBinding`의 실피해는 원본 공격 경로가 별도로 승인된 유닛만 대상으로 합니다. 미리보기와 실제 타격을 동시에 실행하지 않도록 `BindVerifiedBasicAttack`에서 교체합니다.
- `OriginalMapMappedNativeAttackEvidenceCatalog`가 주사위·공속·공격 타입을 보유해도 **원본 방어/버프/HP 정수화가 검증됐다는 뜻은 아닙니다.** 적 HP 표시줄은 실제 `CombatEnemy.Health / MaxHealth`를 따릅니다.
- `MY-08`은 객체 공격 지점 **0.75초**, 공격 주기 **0.70초**여서 일반 미리보기 첫 타격을 자동 추정할 수 없습니다. 원본 첫 피격 시각은 별도 확인 대상입니다.
- `TR-08 / H099`의 **기본 공격 30,001·0.38초**를 사용한 과거 EditMode 사례는 *테스트용 실피해 승인*일 뿐 원본 실전 전투 검증이 아닙니다. `A04Q` 관련 과거 **900/899** 차이는 float32 근삿값·테스트 절삭 기준 차이이며, 실제 워크래프트 HP 반올림 규칙으로 확정하지 않습니다.
- E-03 류마는 `ET04` CWR의 결과 **`h0CJ`**(기본 평타 140,001 / 0.71초)입니다. 비전투 보조 객체 **`h0C7`**(HP 3·`Aloc`·평타 없음)를 주 공격 객체로 사용하지 않습니다. 이 교정은 2026-10-23 당시 공격 자료를 **268→269종**으로 바꿨습니다.

## 확인 우선순위

1. 기존 재생성 JSON의 원본 `rawcode`·기본 수치와 현재 Unity 바인딩이 일치하는지 점검합니다.
2. 모호한 변신/동명이인 객체 및 `E-02`의 현재 신원 증거를 확인합니다. 이름이 비슷하다고 다른 객체를 대신 연결하지 않습니다.
3. 업그레이드·오라·버프·피해 공식·피격 시각·기술 발동을 **개별 원본 증거**와 구분해 검증합니다.

현재 게임 기능·APK 상태는 [현재 상태](START_HERE.md), 남은 작업은 [개발 작업](PLAYABLE_ROADMAP.md)을 우선합니다. 이 문서의 2026-10 추출 수치는 **역사적 원본 조사 스냅샷**이며 최신 전투 연결 종수나 테스트 통과를 나타내지 않습니다.
