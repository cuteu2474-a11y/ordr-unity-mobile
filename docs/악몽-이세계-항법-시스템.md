# 악몽·이세계·항법 시스템

> **범위:** 원랜디 S2 2.323[C]의 악몽 난이도·이세계모드·오로성·항법을 다룹니다. **원본 근거**, **현재 코드에 들어간 기능**, **실전 미검증 사항**을 구분합니다. 최신 APK/실행 상태는 [현재 상태](START_HERE.md), 남은 작업은 [개발 작업](PLAYABLE_ROADMAP.md)을 우선합니다.

## 1. 우리 게임의 고정 조건

- **악몽 + 이세계모드**로 시작하며 다른 모드/난이도 선택 화면은 만들지 않습니다.
- **변질 모드 전용 밴 규칙**을 이세계모드에 적용하지 않습니다.
- `NightmareMutationRules`는 모드 식별자와 **권장 조합 수치**를, `OtherworldModeConfiguration`은 이세계 전용 유닛 분류를 담습니다. 이 클래스만으로 오로성 저주·이세계 추첨·몬스터 강화가 실제로 발생하지는 않습니다.
- 원본 JASS의 이세계 선택 경로 `CUM`은 `th[tn]`을 확인하고 연구 `R00P`, `k4=true`, `TriggerEvaluate(tu)`를 사용합니다. **`R00P`의 실제 효과와 `tu`의 모든 후속 동작은 추가 추적이 필요**합니다.
- 이세계모드를 선택했다는 사실만으로 **몬스터 HP·방어력을 일괄 증가시키지 않습니다.** 악몽 난이도 보정, 51~65라운드 특성, 오로성 효과는 별도 경로로 다뤄야 합니다.

이세계 전용 신비 조합과 재료는 [조합 시스템](조합-시스템.md), 신비 개인미션 `Q017` 및 **10라운드 이전 1회 리롤**은 [개인미션 시스템](개인미션-시스템.md)을 참고하세요.

## 2. 악몽·오로성: 도감 수치와 실제 전투는 다릅니다

도감의 **권장 방어력 감소·이동속도 감소 수치**이며, 강제 클리어 조건이 아닙니다.

| 도감 항목 | 권장 방깎 | 권장 이감 |
|---|---:|---:|
| 오로성 없음 | 211 | 102% |
| 나스쥬로 | 211 | 117% |
| 워큐리 | 221 | 102% |
| 새턴 | 211 | 102% |

`ElderCurseCatalog`에 담긴 도감 원자료는 다음과 같습니다.

| 오로성 | 도감상 효과 |
|---|---|
| 나스쥬로 | 적 이동속도 **+15%**, 아군 공격속도 **-15%**, 라인 몬스터 체력 **+1,500만** |
| 워큐리 | 적 방어력 **+15**, 마법방어력 **+15%**, 보스 체력 **+1,500만** |
| 새턴 | 아군 공격력 **-30%**, 폭발 피해 **-10%**, 적 체력 재생 **초당 +35만** |

- 위 자료는 **게임 내 오로성 선택·부여·중첩·대상별 실제 적용이 완성되었다는 뜻이 아닙니다.** 도감 계산기의 선택 버튼을 실제 게임의 저주 선택 UI로 복제하지 않습니다.
- 워큐리의 **마법방어력 +15%**를 이미 `A04Q`의 `NJ/LK -15`에 반영한 경우 **이중 가산하면 안 됩니다.** 실제 방어 공식·중첩·시점은 원본 전투 계약과 검증해야 합니다.
- 오라형 방깎·이감과 발동형 효과는 따로 집계합니다. [전투 공통 엔진](전투-공통엔진.md)을 참고하세요.

## 3. 항법: 공통 틀과 검증된 일부 선택을 구분

| 범위 | 현재 코드에 확인된 내용 | 미완료·주의점 |
|---|---|---|
| **일반 항법 노드** | `NavigationProgression`이 외부에서 받은 경로·선행 노드·획득 여부를 관리합니다. | 원본 전체 노드, 비용, 보상, 개방 라운드를 기본으로 채우지 않습니다. `Acquire`는 비용 차감/보상 지급을 하지 않습니다. 경로 재선택 금지는 현재 인터페이스 제약입니다. |
| **도움소 항법 두 가지** | `Ordr323OriginalHelperNavigation`에서 20라운드가 지난 뒤(현재 웨이브 **21 이상**), 게임 진행 중이고 도움소가 살아 있을 때 **`최고의도움 :: 연금술` 또는 `최고의도움 :: 최대출력`** 중 하나를 선택합니다. | 원본 `CKX → CKS` 경로로 확인된 **일부 항법 실행**입니다. 전체 항법 트리 완성으로 보지 않습니다. 타 항법도 하나만 선택하는 제약을 공유해야 합니다. |
| **최대출력 후 마나 포션** | `A0UY`는 시전 확정 **후** 마나 +300, 최대 3회 충전이라는 원본 `CJk` 경로가 있습니다. | 베이스 `AOsf`에서 상속된 마나 비용·쿨타임은 미검증입니다. 검증된 시전 포트가 먼저 성공해야 효과/횟수를 적용합니다. |

2.320 패치에는 **‘패왕의길’ 효과가 보스 목재 +2/이감 7%에서 전설 레오 소환으로 변경**된 기록이 있습니다. 이 기록만으로 2.323[C] 전체 항법 노드·연결 비용·해금 조건을 확정하지 않습니다. 이세계 관련 **카지노·리스크헷지·환전소** 노드 변경도 최종 버전 및 원본 동작을 별도로 대조해야 합니다.

이세계 유닛 도박은 2.320 패치 기준 성공 확률이 **15%**로 변경되었으나, 현재 `CJM`의 해금·충전·결제·보상 실행은 별도 미완료 작업입니다. [경제·도박 시스템](경제-도박-시스템.md)과 [M03~M05 작업](PLAYABLE_ROADMAP.md)을 따릅니다.

## 4. 개발 시 확인할 지점

1. **모드 분기:** `R00P`·`tu`의 실제 효과, 이세계 전용 유닛·미션·도박·항법의 연결을 원본 사건별로 분리합니다.
2. **오로성:** 발동 시점·확률·대상·중첩 순서를 원본에서 확인하기 전에는 도감 표만으로 적/아군 능력치를 바꾸지 않습니다.
3. **항법:** 선택 사건 → 실물 상태 → 비용·보상 거래 → 화면 표시 순으로 연결하며, 공통 지갑의 원자 처리와 복구를 재사용합니다. 인터페이스가 있다는 이유로 완료 처리하지 않습니다.
4. **검증:** 코드의 원본 근거, Unity 검사, Android 실기 결과는 서로 다른 상태입니다. 실 실행은 사용자 요청이 있을 때 진행합니다.
