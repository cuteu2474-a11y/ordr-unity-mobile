- **스토리 고유 아이템 추가 획득:** 원본의 **스릴러바크(5) AI03·샤봉디제도(6) AI00·마린포드(8) AI02**는 건물 격파 시 **각각 5% 추첨**합니다. **목재 4개 추가 보상은 꾸러미 선택에만 적용**하며 스토리 드롭에는 붙이지 않습니다. 결과가 당첨이어도 이미 영구 획득한 종류라면 다시 지급하지 않습니다. `Original323SoloStoryScenario.cs`의 격파 영수증은 아이템 잔액과 별개로 **영구 수령 이력**도 함께 기록합니다. 코드는 연결돼 있으나 **모든 실제 원본 네이티브 효과·통합 저장·Android 실기 검증까지 끝났다는 뜻은 아닙니다.**

AI13 보유 시 몬스터 골드 사망 증명의 `dL` 최소값 검증을 추가해 보너스 중복 가산 없이 누락을 막습니다. ## 3. 시설별 최종 기능 — 메뉴 껍데기로 끝내지 않기

현재 모바일은 **왼쪽 메뉴에서 시설로 직접 이동**하는 구조를 유지합니다. 별도 ‘시설’ 탭은 만들지 않습니다. 시설마다 버튼을 누른 다음 실제 게임 상태가 바뀌는지까지 구현 대상입니다.

| 시설·화면 | 최종 게임에서 필요한 실제 기능 |
|---|---|
