## 4. 시설별 개별 기능 누락 방지 체크리스트

각 시설·아이템·상점 버튼은 최소한 아래 항목을 충족해야 합니다.

- [ ] 원본 객체/상품/기술 식별자와 게임 속 표시 이름.
- [ ] 노출 조건: 난이도·모드·라운드·스토리·선행 연구·특성·횟수.
- [ ] 입력: 유닛 선택, 아이템/위습/재화, 구입·시전·파견 등 사용자 조작.
- [ ] 차감: 골드·목재·토큰·아이템·재고·기회·쿨타임·HP/마나를 실제로 반영.
- [ ] 결과: 유닛·아이템·연구·전투 능력·보상·시간 상태를 실제 변경.
- [ ] 예외: 실패·재료 부족·취소·중복 탭·전장 이탈·재시도에 대한 원자성/복구.
- [ ] 저장: 세션 종료 후 다시 시작해도 아이템/시설 상태·영수증·남은 시간 유지.
- [ ] 화면: 짧은 탭 행동, 길게 누르기 설명, 원본 규칙/비용 정확한 표시.
- [ ] 검증: 코드 존재 / 실제 실행 / Android 실기 / 원작 결과 일치 **각각 별도 확인**.

## 5. 항법·능력 선택의 전체 범위도 보존

- **21라운드 이후 항법 선택 및 25라운드 자동 선택**을 포함한 원본 전체 항법 계열·선택지·선행 노드·비용·효과를 원본 JASS와 대조해 끝까지 구현합니다. 현재 코드에 있는 **도박광(카지노·리스크헷지)**와 **도움소(연금술·최대출력)**만으로 전체 항법을 완료했다고 보지 않습니다.
- **패왕의길·최고의도움 및 나머지 원본 항법**의 정확한 수량·명칭·능력·중복/배타 조건은 미수집으로 표시하고 조사합니다. 역사적 기획에 등장한 *5계열·15선택지*는 **원본 전체 동등성 검증이 완료된 수치가 아니므로** 현재 정답으로 확정하지 않습니다.
- 항법 노드를 선택하면 해당 비용·상태·연구·상점·특수 능력까지 실제로 이어져야 합니다. 단지 선택 버튼과 제목이 있는 것은 완료가 아닙니다.
