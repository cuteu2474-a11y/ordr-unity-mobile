# 문서 안내

원랜디 Unity 모바일은 **최종 기능 범위**, **현재 코드·APK 상태**, **남은 작업**, **원본 기술 근거**를 구분해 기록합니다. 이미 구현한 기능도 최종 목록에서 지우지 않습니다. 각 문서는 아래 역할만 맡으며, 과거 변경 내역은 Git 이력에서 확인합니다.

**처음 읽는 순서:** [전체 기능 구현 대장](전체-기능-구현대장.md) → 필요한 [세부 전수 목록](#1-최종-apk에-반드시-넣을-기능) → [현재 상태](START_HERE.md) → [개발 작업](PLAYABLE_ROADMAP.md). 실제 코드를 고칠 때만 [코드 구조](CODE_MAP.md)를 엽니다.
