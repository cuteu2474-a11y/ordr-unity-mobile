# 원랜디 모바일 APK — 전체 기능 구현 대장

> **이 문서는 최종 완성 목표를 정의하는 최상위 목록입니다.** 지금 구현된 것과 아직 미구현인 것을 **모두** 포함합니다. 어떤 기능이 완성되더라도 이 목록에서 삭제하지 않습니다. 실제 연결·검증 상태는 [현재 상태](START_HERE.md), 다음 개발 작업은 [개발 작업](PLAYABLE_ROADMAP.md)에 기록합니다.

## 이 문서를 읽는 방법

- **기능 대장 = 최종적으로 반드시 갖춰야 할 기능.** 구현 우선순위나 현재 완료 목록이 아닙니다. 아래 ID는 기능을 추적하기 위한 고정 번호입니다.
- **구현 ≠ 검증.** 원본 데이터 수집, 코드 등록, 게임 실행, Android 실기, 원작 결과 일치는 별개입니다. 기능은 완성되더라도 대장에 남고, 상태만 갱신합니다.
- **원작 S2 2.323[C] 악몽·이세계모드**를 기준으로 합니다. 구현 방식은 모바일에 맞춰 바꿔도 원작의 실제 게임 결과·비용·확률·피해·조건은 임의로 바꾸지 않습니다. 성현 님이 확정한 모바일 조작 예외는 원작 데이터와 구분해 유지합니다.
- **세부 목록도 전체 대상에 포함됩니다.** 아래 공통 기능과 별개로 [전체 캐릭터·기술 목록](전체-캐릭터-기술목록.md)의 모든 유닛·기술·패시브, [원본 조합·획득 등록 266건 전수표](전체-조합-획득등록-목록.md), [고유 보상 추적 ID 10개·시설별 기능·9개 공통 아이템 기능](전체-아이템-시설-목록.md), [개인미션 18종](개인미션-시스템.md), [65라운드](라운드-몬스터-시스템.md), [스토리 14단계](스토리-시스템.md), [크립 접근 288항목](크립-접근조건-전체목록.md)을 모두 개발 범위로 간주합니다. 목록에 원본 세부 정보가 없으면 **조사 후 구현할 항목**이지 삭제 대상이 아닙니다.

## 13. 개발 중 이 대장을 어떻게 사용하나요?

1. **신규 기능 발견:** 이 대장에 기능을 추가하고 해당 원본 JASS/SLK/W3A·도감 근거를 연결합니다. 구현 여부와 관계없이 삭제하거나 숨기지 않습니다.
2. **개발할 차례:** [개발 작업](PLAYABLE_ROADMAP.md)에 구체적인 누락 부분과 수정 코드·완료 기준을 적습니다. 이 문서에 날짜별 작업 일지를 누적하지 않습니다.
3. **구현 후:** 기능 요구는 그대로 둡니다. [현재 상태](START_HERE.md)에 실제 코드 연결과 검사 범위를 갱신합니다. 캐릭터별 코드 스냅샷은 [유닛별 현황](캐릭터별-구현목록.md)으로 자동 집계합니다.
4. **완료 판단:** “원본 능력/등록 데이터 있음” → “코드 연결” → “Unity/Android에서 실제 실행” → “원본 결과 일치”를 분리합니다. 테스트 실행은 성현 님이 요청했을 때만 합니다.
5. **충돌 해결:** 성현 님이 확정한 모바일 정책과 현재 코드가 다르면 대장에서 불일치로 기록하고, 게임 기능이 아닌 문서 수정만으로 구현됐다고 선언하지 않습니다.
