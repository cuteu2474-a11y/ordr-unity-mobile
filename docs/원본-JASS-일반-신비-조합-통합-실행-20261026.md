# 원본 조합 실행 포트와 일반·신비 도감 통합 (2026-10-26)

## 사용자 기능

- 기존 **일반 조합·이세계 신비 조합 미리보기**를 유지하면서, 외부에서 원본 JASS 조합 거래 월드를 검증·연결했을 때 **원본 JASS 등록식 조합**도 같은 모바일 조합 목록에 표시합니다.
- 캐릭터·재료 검색과 페이지 기능은 세 종류의 조합에 공통으로 적용됩니다.
- 사용자가 조합을 확정하면 **해당 조합식을 제공한 포트**만 호출합니다. 다른 조합 포트의 재료·재화 소비로 우회하지 않습니다.
- 각 항목의 실제 제작 버튼은 **그 조합식을 소유한 포트에 원본 거래 구현이 연결된 경우**에만 활성화합니다. 한 종류의 제작 연결이 다른 종류의 제작 허가로 표시되지 않습니다.
- 원본 JASS의 `OriginalJassFusionPort` → `OriginalJassFusionAtomicCoordinator` → 검증된 독점·롤백 월드 경로는 그대로 사용하며, 비용·재료·시전 대상·특수 조건은 기존처럼 확정 시점에 재검증합니다.

## 개발 근거와 제한

- 원본 JASS 조합기가 있다는 것과 실제 맵의 **모든 CWR/CHu/CHx 조건이 구현·검증**됐다는 것은 다릅니다.
- 미검증 원본 ID, 아이템·특수조건 또는 실행 월드 부재로 차단된 레시피는 여전히 제작할 수 없습니다.
- 기존 `ConfigureOriginalJassCrafting(World/OrderedWorld)` 호출에서 신비·일반 목록이 사라지는 연결 오류만 해결했습니다. 원본 조합 확률, 재료, 재화, 피해 규칙을 바꾸지 않았습니다.
- 테스트에서 사용하는 합성 포트는 **조합 실행 분배기** 검증용이며 실제 원본 제작 성공의 근거가 아닙니다.
- Unity 테스트는 `CombinedOriginalFusionRoutingTests`에서 3종 동시 목록, 조합별 실행 버튼, 트랜잭션 분배, 오래된 목록, 중복 조합식 ID 및 거래 실패를 검사합니다.

실전 몬스터·원본 맵/APK는 변경하지 않습니다.
