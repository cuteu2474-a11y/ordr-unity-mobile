# 모바일 가로모드 — 평타 사거리 제한 제거 (2026-10-21)

## 사용자가 결정한 변경
휴대폰에서 유닛을 일일이 움직여 기본 공격 사거리를 맞추는 조작을 없앤다.

- **일반 공격**: 같은 전장에 있는 살아 있는 적은 화면의 위치와 관계없이 공격할 수 있다.
- **확률형/주기형 공격 스킬**: 기본 공격으로 시작되는 트리거에서 유닛의 사거리 때문에 발동이 막히지 않는다.
- **액티브·특수 스킬**: 기본 타깃 탐색에서 동일한 무제한 도달 정책을 사용한다. 각 스킬의 **광역 반경, 시전 조건, 쿨타임, 타깃 종류**는 그대로 유지한다.
- **보스 우선**: 같은 전장 안에서 보스 타깃을 선택한다. 캐릭터 위치 때문에 보스 선택이 막히지 않는다.
- **메인/스토리 분리**: 스토리로 파견한 유닛은 스토리 적만, 일반 유닛은 메인 웨이브/보스/강화 적만 공격한다.
- **크립·해왕류·도전**: 기존 임시 전장 제외 상태를 유지한다. 추후 별도 '출전' 승인을 구현하기 전까지 아무 유닛이나 자동으로 공격하지 않는다.
- **스킬 광역 반경과 오라 반경**: 공격 도달 거리와 다른 개념이므로 원작의 개별 수치를 계속 적용한다.
- **피해량과 공속**: 모바일 편의성 때문에 임의로 조정하지 않는다. 정확한 원작 데이터는 여전히 별도 확보가 필요하다.

## 코드 반영 위치
- `CombatAttackReachMode.UnlimitedWithinAssignedBattlefield`를 `CharacterCombatRuntime` 생성 시 켠다.
- `CombatAttackPipeline`의 기본값은 기존 범위 제한 정책(`OriginalUnitRange`)으로 남겨 일반 전투 코어나 기존 호출자의 호환성을 유지한다.
- 전장별 적 필터링(`CanAttackInThisLane`) **이후**에만 사거리 무시를 적용한다.
- 기본 공격, 주기 스킬, 특수 스킬, 보스 선호 타깃을 동일한 정책으로 평가한다.
- 모바일에서는 `basicAttack.range` 누락 또는 null을 공격 불가능 사유로 간주하지 않는다. `Range=0`은 값 미제공의 내부 표식일 수 있고 원작 사거리를 0으로 가정한 것이 아니다. `BasicAttackSpec(power, interval, school, traits)` 생성자도 이 용도를 지원한다.

## 원작 대비 의도한 게임성 변경
사거리를 무시하면 일부 근접 유닛이 기존보다 공격하기 쉬워져 실제 DPS와 난이도 및 일부 타깃/광역 스킬 발동 위치가 바뀔 수 있다. **원작과 완전히 동일한 전투 밸런스는 아니므로 모바일 편의성 변경임을 명시한다.** 이동형 특수효과·진형 제한이 필요한 캐릭터는 개별 검토한다.

## 구현/검증 상태
C# 소스 수정 및 GitHub main 반영 대상으로 작성했다. 실제 Unity 컴파일, 플레이, APK, 전투 수치 검증은 실행하지 않았다. 기존 공통 전투 엔진과 캐릭터별 데이터의 미완료 사항은 그대로 남아 있다.
