# 특별함 6종 오라·버프 전투 연결

기준 main: `d38ae8b`. 원본 S2 2.323[C] W3X SHA-256은 `0794996c9bc73eaa3020f20ebc45fb37cfa64a6e98ffe8aa0dfa3b356e77bc5c`이다. 원본 맵을 수정하지 않고 내부 자료 6개 파일의 지문을 확인한 뒤 직접 추출했다.

## 이번에 연결한 원본 효과

| 캐릭터 | 유닛 / 능력 / 버프 | 원본 효과 | 원본 반경 |
| --- | --- | --- | ---: |
| 바질호킨스 S-10 | h016 / A08N / B011 | AHad, 적 방어력 3 감소 | 800 |
| 쵸파 두뇌강화 S-26 | h01E / A0EO / B02G | AHad, 적 방어력 3 감소 | 800 |
| 스모커 S-14 | h01F / A08F / B012 | AOae, 적 이속 5% 감소 | 800 |
| 크로커다일 S-29 | h01A / A08E / B001 | AOae, 적 이속 5% 감소 | **850** |
| 키드 S-30 | h00Y / A08H / B004 | AOae, 적 이속 5% 감소 | 800 |
| 쵸파 가드포인트 S-25 | h01D / A0EM / B00V | ACac, 아군 공격력 7% 증가 | **850** |

앞의 5개는 `Units/AbilityData.slk` + `CampaignAbilityStrings.txt`에서 확인했다. 방깎은 `DataA1=-3`, 이감은 `DataA1=-0.05`, `DataB1=0`, 대상 마스크는 `air,enemies,ground`다.

**가드포인트 A0EM은 SLK 행이 아니다.** 원본 `war3map.w3a`의 `ACac → A0EM` 레코드에서 `Cac1=0.07000000029802322`(float32), `aare=850`, `Ear2=1`, `Ear3=1`, `Ear4=0`, `abuf=B00V`, `atar=air,invulnerable,organic,self,ground,vulnerable,friend`와 7% 툴팁을 확인했다. 원시 float와 표시 퍼센트를 별도로 보존한다. 이를 임의의 최종 HP 1.07배로 바꾸지 않는다.

기본 공격력·주사위·공격 간격·사거리·원본 조합 자료는 변경하지 않았다. 이번 작업은 이 6종의 오라/버프에 한정되며 다른 능력의 완전 구현을 뜻하지 않는다.

## 실제 코드 경로

- `Original323SpecialAuraCatalog`가 6종의 원본 소유 rawcode·능력 보유 여부를 맵 카탈로그와 대조한다. Unity 컨트롤러가 이 카탈로그를 생성해 전투 월드에 연결한다.
- `CharacterCombatRuntime.SpecialAuras.cs`가 소환·이동·제거 및 전투 시계 진행 시 갱신한다. 메인/스토리 전장을 분리하고, 원본 오라 반경을 유지하며, 범위 경계는 포함한다. 동일 출처를 매 프레임 누적하지 않으며 제거 시 다른 지속 스킬을 지우지 않는다.
- `IOriginal323SpecialAuraTargetRules`는 **현재 원본 능력 레벨1 보유, 마스크·소유관계·면역·해당 시각 버프 자격 및 반경/틱 동작**을 별도로 증명해야 한다. 승인이나 출처가 없으면 효과를 부여하지 않는다. 전장/보스/거리만으로 Warcraft의 적·영웅·유기체·면역을 추정하지 않는다.
- 엄격한 현재 반경 경로다. 실제 원본 오라가 범위 이탈 뒤 잔류한다면 이 경로를 그대로 승인하면 안 된다. 잔류 시간/원본 갱신 틱은 미검증이며 별도 타임라인 구현이 필요하다.
- 두 방깎은 **현재 월드가 직접 부여한 단일 효과**에 한해 원본의 방어력 -3을 기존 피해 계산에 반영한다. 같은 SourceId 문자열을 복제한 가짜 효과는 통과하지 않는다. 다중 오라, 동일 버프 복수 시전자, A04M/A04P와의 혼합은 원본 중첩 검증 전까지 계산을 보류한다.
- 3종 이감은 실제 몬스터의 `CombatStatusEngine`에 들어가 `CombatEnemyPathDriver`의 원본 이동 계산기로 전달된다. 실제 최종 이동속도·하한·연구/다중 이감 중첩 계산기는 이번에 추정해서 만들지 않았다.
- 가드포인트는 실제 아군 상태에 공격력 버프를 부여한다. `BasicDamageRequest.AttackerEffects`가 타격 시 상태 스냅샷을 피해 계산기로 전달한다. 기존 네이티브 주사위 경로에서 버프가 조용히 무시되던 문제를 막았다. `IOriginal323NativeAttackBuffRules`가 원본 계산을 승인하지 않으면 **주사위 이전**에 공격을 보류한다. 승인 정책은 원시 피해에만 관여하며 공격 타입/계열/방어 적용 여부를 바꿀 수 없다. 원본 피해식 기본값은 없다.
- 오라 출처 구성이 바뀌면 누락된 버프/방깎 계산으로 보류되었던 공격을 재검사한다. 버프 이탈 후 승인된 기본 공격은 다시 진행할 수 있다.

Unity 진입점은 전투 생성 전 `ConfigureVerifiedOriginalSpecialAuraTargets(rules)`이며, 원본 네이티브 경로 구성 시 필요하면 `ConfigureOriginalCommonNativeDamageWhenVerified(..., verifiedAttackBuffRules)`로 공격력 버프 계산기를 전달한다.

## 검증과 남은 범위

- 비 Unity 원본 자료 회귀 **108건 통과**, 원본 W3X 재추출 일치. Unity 전체 테스트는 이번 main 커밋의 기존 EditMode Actions에서 확인한다.
- EditMode 추가 범위: 6종 수치/ID, 5종 적 오라 경계·이동·제거, 출처 없는 대상 차단, 메인/스토리 분리, 아군 자신/이동/출생 순서, 개별 적/아군 승인 거부, 출처 중복 방지, 단일 방깎의 실제 HP 변화, 위조 효과 거부, 다중 방깎 보류, 공격력 버프 누락/거부 시 무난수 차단, 범위 이탈 후 공격 복구, 큰 시간 진행 중 갱신 및 3종 이감의 이동 계산기 전달.
- 테스트의 네이티브 승인·적/아군 분류·이동속도95·피해 절사·공격력1.07배는 **가상 정책**이다. 실제 Warcraft 클라이언트 재현 근거로 사용하지 않는다.
- 실제 몬스터 최종 방어·면역/타깃 데이터, 네이티브 오라 중첩·틱/잔류, 공격력 버프의 기본 공격력 범위 및 소수점/강화/크리티컬 적용 순서는 미검증이다. 원본 자료 JSON의 `safeForUnconditionalLiveCombat: false`를 유지한다. 6종의 원본 객체+수명주기+전투 전달 코드와 실기 완성 여부를 구분한다.
- APK는 제작하지 않았다. 기존 main 단일 워크플로를 사용하고 새 브랜치를 만들지 않는다.
