# 유닛 네이티브 효과의 연습 전투 연결

`1785d80`의 전설 제작·20R 연습에서 이어 기본 APK의 개발용 전투에 객체 효과를 연결했다. 원본 W3X는 읽기만 했다. 전체 유닛·전체 스킬 완료를 뜻하지 않는다.

## 이번 실행 범위

- 등급 제한을 제거해 원본 공격 객체가 확인된 270종의 기본 공격 모델을 지원한다. 획득·조합·소환 범위를 늘리거나 고등급 유닛을 무료 지급하지 않는다.
- 기존 순수 네이티브 패시브 26개를 연습 타격에도 연결했다. 원본 객체 확률과 배율로 치명타를 기본 피해 한 번에 반영하고, 기절은 살아 있는 일반 몬스터에 원본 일반 지속시간을 적용한다. 보스는 Arsk 저항 계산이 미확정이므로 기절을 적용하지 않는다.
- 안흔함 로빈은 기본 대상과 같은 전장의 추가 두 대상까지 타격한다. 연습에서는 거리·고정 ID 순서로 추가 대상을 고르고 즉시 처리한다. 원본 미사일 비행·대상 순서 동등성은 미검증이다.
- 1단계 객체의 방어력 감소·이동속도 감소·아군 기본 공격력 증가 오라를 연결했다. 같은 능력/버프/레벨/수치의 중복은 한 번 적용한다. 다른 오라 정체성이 충돌하면 해당 효과 그룹을 보류하고 플레이 화면에 개수를 표시한다. 임의로 합산하거나 최댓값을 고르지 않는다.
- 소유자 제거·스토리 파견·조합 재료 숨김 후 오라를 갱신한다. 같은 전장 내 도달 거리는 사용자 정책대로 제한하지 않는다. 기술의 광역 타격 형태를 전체 전장 공격으로 바꾸지는 않는다.
- 이동 거리를 시간 구간마다 누적해 기절 중 정지와 감속을 실제 경로에 반영한다. 효과 종료 후 이전 위치로 되돌아가지 않는다. 속도 상하한은 원본 맵의 89/490을 사용한다. 가속·충돌은 개발용 모델이다.
- 모바일 상세 화면에 실제 연결된 연습 효과를 표시하고 툴팁 목록과 실행 완료를 구분한다.

## 출처와 전체 항목 감사

원본 맵 SHA는 `0794996c9bc73eaa3020f20ebc45fb37cfa64a6e98ffe8aa0dfa3b356e77bc5c`다.
맵 SLK에서 빠진 AHAd 방어 오라의 백분율 여부는 사용자 제공 기본 MPQ의 AbilityData.slk에서 `DataB1=0`을 확인했다. 기본 SLK SHA는 `ddc360800784f808219bbc2518b16b0f12413082aada2755cc00944adcc31cec`다. [상속 자료](../data/practice-native-inherited-defaults.json)는 연습 모델 전용이며, 기존 정식 오라 증거의 미확인 필드를 덮어쓰지 않는다.

[전체 272개 항목 현황](../data/unit-runtime-status.json)은 현재 C# 실행기로 실제 내보낸 지원 범위를 원본 매핑·도감 목록과 합쳐 생성했다.

| 구분 | 수량 | 의미 |
|---|---:|---|
| 전체 카탈로그 항목 | 272 | 모든 항목에 남은 작업 기록 |
| 객체 기본 공격 모델 | 270 | 영웅 능력치·동적 강화·최종 원작 피해 검증과 별개 |

| 연결된 모델 효과 정의 | 144 | 치명타·기절·다중 타격·지원 오라의 합계 |

## 남은 구현

E-02 원본 객체 매칭, X-05의 평타 없는 지원 기능, 스킬별 원본 함수·피해·타깃·실행 순서 대응이 남았다. 액티브·변신·소환물·자원 생성·연구·영웅 능력치·추가 피해 AHbh·복합 패시브·공격속도 오라·혼합 오라 중첩·보스 저항·동적 면역도 전체 구현이 아니다. 일반 연습 몬스터는 정해진 출현 객체를 사용하며, 네이티브 대상 면역/유기체 판정과 원본 버프 시점·지속 여운은 별도 검증이 필요하다.

정식 원본 피해·웨이브 검증 플래그는 계속 false다. 좀비 재료 생성 등 미완성 보상을 이 모델에서 지급하지 않는다. 116개 제작식과 10R/20R 연습 범위도 전체 조합·정식 65라운드 완성으로 표시하지 않는다.

## 검증

- 로컬 Mono에서 Core/Combat/Data/Mobile의 C# 140개 파일을 컴파일했다.
- 실제 전투 코드를 사용하는 NUnit 통합 검사 8건 통과: 270종 공격 연결, 치명타 한 번 적용, 기절 정지·재개, 로빈 최대 3명, 동일 방깎 중복/혼합 충돌, 공격력 오라, 감속 이동 거리, 소유자 제거 후 해제.
- Python 원본 자료·회귀 검사 157건, `git diff --check` 통과.
- 로컬 검사는 Unity 실행·Android 설치 검증을 대신하지 않는다. 기존 Actions의 EditMode 후 APK 제작을 요청하며, 실행 시작 이후 결과는 별도 요청 전 조회하지 않는다. APK 생성 성공이나 실기 플레이 완료로 보고하지 않는다.
