## 실행 방식

- 원본 소유 유닛·능력·레벨·확률·배율·영웅/일반 기절 시간과 대상 마스크를 읽는다.
  원본 능력 하나의 전체 효과가 순수 기절 또는 순수 크리티컬인 경우만 실행한다.
- 승인된 기본 공격의 주사위가 나온 뒤 기존 `ICombatProcRandom`으로 발동을 직접 판정한다.
  발동 결과나 미래의 최종 피해를 공급하는 관측기는 요구하지 않는다.
- 크리티컬은 원시 공격 피해에 배율을 적용한 후 기존 방어·증폭·HP 변환을 통과한다.
  최종 HP에 배율을 다시 적용하거나 추가 피해 패킷을 만들지 않는다.
- 실제 기본 타격 커밋이 성공하면 같은 공격의 활성화 정보로 기절·스킬 이벤트를 처리한다.
  피해 공식 보류·다른 전장·사망한 대상에 기절을 적용하지 않는다.
- 기절 시간은 명시된 Warcraft 영웅 여부를 사용한다. 보스/스토리 분류로 추정하지 않는다.
  대상 분류·면역 상태가 타격 중 변경되면 준비된 기절 적용을 보류한다.
- 기존 안흔함 브룩 처리기나 육식 크리티컬 처리기가 연결되어 있으면 해당 능력의 소유권을
  기존 처리기에 남겨 확률 추첨·기절·배율을 두 번 적용하지 않는다.
- 상세 패널에 한국어 능력명과 실제 확률·배율/시간을 표시하며, 원본 코드명을 노출하지 않는다.
  같은 A07I에 연결된 육식 크리티컬과 별도 람각의 구현 상태도 구분한다.

## 대상 상태와 기본 공격 승인

`Original323NativePassiveTargetProfile`은 실제 몬스터의 원본 객체 ID,
Warcraft 영웅 여부, 각 능력의 **원본 대상 마스크와 면역 판정을 통과한 능력 목록**을 보존한다.
이 목록에 없는 능력은 발동 난수도 소비하지 않는다. 누락 상태를 일반 적·면역 없음으로 취급하지 않는다.
현재 상태 변경은 예상 리비전이 일치해야 하며, 다른 객체 ID로 바꾸거나 죽은 적을 갱신하지 않는다.

검증 웨이브에는 아래 `nativePassiveTarget` 필드를 선택적으로 전달할 수 있고,
`CombatWaveDirector`가 실제 적 생성 시 같은 상태를 연결한다.
이 필드가 없으면 기존 승인된 기본 공격은 유지하며 새 패시브는 비활성이다.
프로필 작성자는 영웅 분류·네이티브 면역·대상 마스크를 확인해야 한다.

```json
"nativePassiveTarget": {
  "warcraftHero": false,
  "eligibleAbilityRawcodes": ["확인한 4자리 능력 ID"],
  "evidence": "해당 몬스터의 실제 분류·대상 마스크·면역 검증 출처"
}
```

코드 연결점:
- `Original323NativePassiveCatalog.FromJson`: 원본 수치·소유 관계 로딩.
- `Ordr323DamageWorldBinding.Create(..., nativePassives, externallyHandledAbilities)`:
  원시 기본 공격 공급자와 직접 실행 엔진 연결.
- `CombatEnemy.TrySetNativePassiveTargetProfile(expectedRevision, profile)`:
  명시적으로 확인한 현재 대상 상태 설정/갱신.
- `ConnectedNativePassiveOf(instanceId)`: 실제 연결 능력 확인.

기본 Unity 컨트롤러에서는 **원본 주사위만 반환하는** `OriginalMapCommonNativeAttackBinding`에
이 실행기를 자동 연결한다. 이미 크리티컬을 적용했을 수 있는 임의의 외부 피해 공급자는
자동으로 다시 감싸지 않는다. 원본 공격 경로·적 방어·HP 정수화 승인 조건을 낮추지 않았다.

## 보류한 효과

추가 물리 피해, 크리티컬+추가 피해+기절 등 복합 능력,
여러 AHbh 능력을 동시에 가진 유닛의 중첩/처리 순서, 여러 능력 레벨의 현재 선택은 보류했다.
에이스·타시기·하찌의 추가 피해, 전설 조로의 복수 능력, 초월 로우/상디 및 영원 비비의
다중 레벨을 단순한 고정 레벨이나 부분 효과로 대체하지 않았다.
람각의 원본 더미 주문·충돌/비행은 기존 별도 실행 범위이며 이번 크리티컬 추가로 완료 표시하지 않는다.
