# 특별함 모바일 운용 — 사용자 확정 정책 (2026-10-23)

대상: ORDR S2 2.323[C] 악몽·이세계모드, main. 이 문서의 **사용자 확정 변경**은 과거 원작 동일성 문구보다 우선한다. 정책 결정과 실제 게임 기능 완료는 구분한다.

## 확정한 6가지 규칙

| ID / 유닛 | 확정 동작 | 보존·제약 |
| --- | --- | --- |
| SP-01 / S-02 갱 뱃지 | 분해는 자동 Q/W/R에서 제외하고 보유 유닛의 ‘분해’ 버튼으로 직접 실행 | 원본 5초 시전과 후쿠로·버기·총병 교환, 실패 복구는 실제 월드 서비스에서 처리 |
| SP-02 / S-05 로우 | **시전할 때마다** 현재 예상 DPS가 가장 높은 아군을 새로 선택 | 스토리 파견 로우는 스토리 유닛만, 메인 로우는 메인 유닛만. 다른 가속 중복 금지·7초/100%·50초 쿨타임 유지 |
| SP-03 / S-09 모리아 | 막타 대신 **실제 피해를 준 처치 참여**로 좀비 획득 | 현재 원작 대상 구분에 맞춰 라인 몬스터만. 피해0·단순 디버프·누수는 제외. 같은 적에 여러 모리아가 참여해도 싱글 플레이어 재료는1개 |
| SP-04 / S-32 파이러츠 도킹5 | 평타의 보스 우선·선두 우선 등 공통 타깃 경로로 고른 **현재 공격 대상에게 자동 시전** | 독립 스킬 타깃 AI/별도 우선순위 메뉴를 만들지 않음. 원본 피해·스턴·마방 감소·쿨타임·비용 검증은 유지 |

| SP-06 / S-17 압살롬 | 공중이동 등에 따른 **부가 전투 출전 자격 차이 유지** | 이동 조작 단순화·평타 무제한이 누구나 해왕류/크립에 출전할 수 있다는 뜻이 아님. 해당 모드·목표의 실제 접근 조건은 별도 대조 |

SP-03 참여의 세부 집계(양수 피해·적당1회)는 이번 코드에서 채택한 판정이다. 시간 만료를 새로 만들지 않고 해당 적의 사망/누수/퇴장까지 유지한다. 다른 유닛이 마지막 일격을 가해도 인정한다. 소환수는 실제 원본 소유자 연결이 확보되어야 모리아에게 귀속시킬 수 있다.

## 로우의 ‘AI’ 의미

외부 서버/LLM을 시전마다 호출하지 않고 **게임 안의 현재 상태로 예상 DPS를 비교하는 자동 판단**을 사용한다. 대상 ID는 고정/캐시하지 않는다. 현재 공격력·공속·공격에 연동되는 기술·적 방어/대상과 스킬 상태를 고려하는 추정기가 값을 공급해야 한다. 등급이나 표시 공격력만으로 가장 강한 유닛을 고르지 않는다.

후보 필터: 실제 보유·현재 전장 일치·생존/시전 적법성·가속 중복 없음·DPS 추정 가능. 동률은 인스턴스 ID 순으로 결정한다. 대상이 없어 실패하면 쿨타임을 소비하지 않는다. 실제 효과/자원 검증 서비스 없이 무료 버프를 만들지 않는다.

## 파일과 검증

- `Assets/Scripts/Mobile/SpecialGradeMobilePolicy.cs`: 확정 정책·로우 후보 선택·부가 전투 접근 조건·모리아 참여 장부.
- `CharacterCombatRuntime`: 로우 시전 조율, 공통 공격 타깃 조회, 모리아 재료 장부.
- `CombatResolution` → `CharacterSkillEffectExecutor`: 실제 평타/스킬 피해의 공격자 전달.
- `MobileCombatAutomation`: 갱 분해 제외, 로우 별도 아군 경로, 도킹5 현재 타깃으로 제한.
- `OrdrMobileTouchPanel` → `MobileManualInteraction`: 명시적인 분해 버튼/실제 월드 포트.
- `OrdrCharacterCombatController.ConfigureSpecialGradeMobileServices`: 실제 로우·분해 서비스 연결 진입점.
- `Assets/Tests/EditMode/SpecialGradeMobilePolicyTests.cs`: 전장 격리·시전별 재평가·쿨타임/실패·참여 보상·범위 중심·공통 타깃/자동 분해 금지 회귀 사양.

검증 결과는 해당 커밋의 기존 Unity EditMode CI에서 확인한다. 가상 피해/시전 서비스 테스트는 원작 실제 수치 검증이 아니다. APK 제작·실기 실행은 이 변경 범위가 아니다.

## 버프·디버프 데이터에 대한 표현

‘등록’은 공격력 증가·방어력 감소·이동속도 감소 등의 **효과 설명/수치가 자료에 저장되어 있음**을 뜻한다. 실제 전투에 효과가 적용되고 중첩/반경까지 확인됐다는 뜻이 아니다. 바질 호킨스·스모커·쵸파 가드포인트·쵸파 두뇌강화·크로커다일·키드의 기존 자료도 같은 기준으로 해석한다. 이번 사용자가 새로 바꾼 것은 위6개 정책이며, 이들의 오라를 전장 전체로 바꾸는 결정은 없었다.
