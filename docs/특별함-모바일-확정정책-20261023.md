## 로우의 ‘AI’ 의미

외부 서버/LLM을 시전마다 호출하지 않고 **게임 안의 현재 상태로 예상 DPS를 비교하는 자동 판단**을 사용한다. 대상 ID는 고정/캐시하지 않는다. 현재 공격력·공속·공격에 연동되는 기술·적 방어/대상과 스킬 상태를 고려하는 추정기가 값을 공급해야 한다. 등급이나 표시 공격력만으로 가장 강한 유닛을 고르지 않는다.

후보 필터: 실제 보유·현재 전장 일치·생존/시전 적법성·가속 중복 없음·DPS 추정 가능. 동률은 인스턴스 ID 순으로 결정한다. 대상이 없어 실패하면 쿨타임을 소비하지 않는다. 실제 효과/자원 검증 서비스 없이 무료 버프를 만들지 않는다.

## 특수함 추가 확정 — X-02 베티의 고무

사용자 결정: 고무의 자동 대상 선택은 로우와 같은 방법을 사용한다. 마나 부족 순으로 선택하자는 이전 제안은 채택하지 않는다.

- 고무를 시전할 때마다 현재 예상 DPS가 가장 높은 적법한 아군 후보를 새로 평가한다. 대상을 고정하거나 지난 시전 결과를 그대로 사용하지 않는다.
- 메인 전장의 베티는 메인 전장 유닛만, 스토리 파견 중인 베티는 스토리 유닛만 대상으로 한다.
- 외부 서버/LLM 없이 게임 내부의 현재 전투 상태로 판단한다. 등급·표시 공격력·부족 마나량만으로 순위를 대체하지 않는다.
- 로우와 공유하는 것은 예상 DPS 비교와 전장 격리 규칙이다. 베티의 실제 대상 자격·사거리·자원·회복 효과·쿨타임은 고무의 원본 규칙을 적용한다. 로우의 가속 중복 제한·7초 지속·50초 쿨타임을 베티에 복사하지 않는다.
- 시전 가능한 후보가 없으면 사용을 보류한다. 실제 시전에 성공했을 때만 고무의 자원과 쿨타임을 소비한다.
- 저장소 반영 상태: **정책 확정·작업목록 등록**. 이번 추가는 문서 반영이며, 베티 자동 시전 서비스와 실제 회복 효과를 구현 완료로 처리하지 않는다.

구현 시 U-X-02 및 D-06에 연결한다. 완료 전 같은 전장의 최고 예상 DPS 선택, 매 시전 순위 변화, 다른 전장 제외, 부적격 후보/대상 없음, 베티 고유 회복·쿨타임의 실제 적용을 검증한다.

## 특수함 추가 확정 — X-05 오타마의 경단먹이기

사용자 결정: 기존 유닛 양도 능력을 **목재 16개 획득**으로 대체한다.

- 사용에 성공하면 현재 싱글플레이 플레이어의 목재에 정확히 16개를 더한다.
- 기존 1회 사용 제한을 유지한다. 같은 오타마 개체로 반복 지급하지 않는다.
- 대상 유닛 선택, 희귀 이하 등급 검사, 다른 소유자의 동의, 소유권 이전, 주는 사람/받는 사람 보상 분기를 사용하지 않는다. 유닛을 재료로 소비하지 않는다.
- 기존 양도 보상(받는 쪽 4 또는 6목재·주는 쪽 12목재)은 새 능력과 함께 지급하지 않는다.
- 스킬 사용 뒤 오타마 자체를 삭제하는 규칙은 추가하지 않는다.
- 저장소 반영 상태: **부분 구현·검증 대기**. `CharacterCombatRuntime.TryUseOtamaDango`가 `EconomyWallet.TryGrantOnce`로 wood16을 지급하고 개체별 지급 이력을 확인한다. `MobileCombatAutomation`의 전용 자동 경로와 `ConfigureOtamaWoodRewards` 연결점이 있다. 실제 시작 지갑 공급, 유닛 ID와 지갑 이력의 전체 저장/복구, 해당 커밋 CI 및 실기 확인은 별도다.

구현 시 U-X-05, D-06(자동 시전) 및 경제/재화 작업에 연결한다. 완료 전 목재 +16, 중복 호출 시 추가 지급 없음, 유닛·소유권 변화 없음, 저장/복구 후 사용 완료 상태 유지, 지급 실패 시 사용 기회 보존을 검증한다. 원작 자료는 출처 기록으로 보존하며 이 모바일 확정 정책을 실행 동작의 기준으로 삼는다.

### 원본 맵에서 확인한 규칙

근거: [원본 탐색 조사 데이터](../data/original-2323C-treasure-research.json). 웹 도감만으로 확정하지 않고 제공된 맵의 JASS와 원본 유닛 이름을 대조했다.

- 가이몬의 실제 원본 유닛은 h0BG, 이름은 ‘가이몬 - 특수’다. 기존 7종 웹 목록에는 누락되어 있다.
- 보물은 고정 성공률로 지급되지 않는다. BeM이 영역 내 무작위 좌표에 배치하고, BeN이 탐색 사각 범위에 들어온 미획득 보물을 수집한다. 한 번의 탐색에 여러 보물이 들어올 수도 있다.
