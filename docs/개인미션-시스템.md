# 개인미션 시스템

> **현재 규칙 안내:** 원본 ORDR S2 2.323[C] 악몽·이세계의 개인미션을 한곳에서 찾는 문서입니다. 여기의 **원본 목표·보상 목록**과 실제 게임에서 사건이 들어오는지의 **코드 연결 상태**, 최신 APK에서 작동하는지의 **실행 검증**을 구분합니다. 기능별 남은 일은 [개발 작업](PLAYABLE_ROADMAP.md)에서 관리합니다.

## 1. 개인미션은 어떻게 진행하나요?

1. 게임 시작 때 원본 **18종 후보**에서 서로 다른 미션 **3개**를 받습니다. 이세계가 아닌 후보 풀은 17종이지만 이 프로젝트는 이세계 고정이므로 **신비 조합 Q017**도 포함합니다.
2. 미션의 목표가 실제 게임 사건으로 충족되면 **자동 완료·보상 정산**합니다. 별도 보상 수령 버튼을 만들지 않습니다.
3. **10라운드 이전**, 아직 완료하지 않은 미션 한 칸을 **게임당 한 번** 다시 뽑을 수 있습니다. 다른 칸과 중복되지 않아야 하며 리롤 자체의 원본 재화 비용은 없습니다.
4. **목재수집·리사이클**은 조건 숫자를 채워도 바로 완료하지 않고, 실제 **라운드 종료** 시점에 판정합니다. 적 개체 수가 잠깐 0이 되었다는 이유로 지급하지 않습니다.
5. 세 미션을 모두 완료하고 최종 클리어하면 원본 추가 **베리 1개** 자격이 있습니다. 현재 자격 표시는 영구 보상 지급 완성과 구분합니다.

모바일 미션 화면에는 **이름·현재 진행도·목표·보상·리롤 가능 여부·라운드 종료 대기 상태**를 표시합니다. 미션 보상은 조합·상점·위습과 **동일한 공유 지갑**에 지급하며 한 사건의 중복 지급을 막습니다.

### 판정 시 주의할 조건

- **초월**은 생성 유닛에 `A07O`가 있고 영웅 타입인지를 확인합니다. 불멸 `A905`, 영원 `A906`, 제한 `A907`, 왜곡 `A0QH`, 신비 `A909`를 원본 능력으로 구분합니다.
- **아이템 조합 Q013**은 결과 원본 객체 `h067`, `h08O`, `H0BK` 중 하나인지 확인합니다. 이름에 ‘아이템’이 들어간 유닛을 임의 포함하지 않습니다.
- **최상위 조합 Q014/Q015**은 원본 `Q7` 누적 조건을 반영해야 하므로, 등급 이름만 보고 카운트를 늘리면 안 됩니다.
- **도박중독 Q003**은 하급·중급·고급을 **각각 4회** 시도해야 합니다. 시도와 실패를 혼동하지 않습니다.
- **오늘만산다 Q001**의 15라운드 전 달성, **리롤**의 10라운드 전 제한은 서로 다른 조건입니다.

## 3. 실제 코드 연결과 남은 경계

| 게임 사건 | 코드 수준의 처리·남은 확인 |
|---|---|
| 시작·리롤·진행 표시 | 원본 3칸 세션과 한 번의 리롤, 화면의 진행도·라운드 종료 대기를 연결하는 구조가 있습니다. |
| 흔함 유닛 판매·선택위습 사용 | **성공한 거래만** 미션 사건으로 반영하며 실패·미리보기는 세지 않습니다. |
| 원본 실제 조합 | 커밋 뒤 결과 유닛/원본 능력을 검토해 중복 없는 사건으로 전달하는 경로가 있습니다. 초월 영웅 판정과 `Q7` 최상위 자격은 실제 공급자 확인이 필요합니다. |
| 라운드 종료 | 다음 라운드가 실제 수락되거나 클리어로 확정된 경우에만 이전 라운드의 종료형 목표를 판정합니다. |
| 목재·세 종류 도박, 유니크 획득, 스토리 MVP | **신호 수신 API와 각 사건의 실제 생산자 연결은 별도 확인 필요**. 모든 미션 사건이 연결됐다고 보고하지 않습니다. 싱글플레이에 스토리 MVP 순위 화면도 만들지 않습니다. |
| 보상 | 위습·목재는 공유 지갑, 특성포인트는 `trait-points`, 능력 보상은 `mission:ability:...`에 영수증으로 기록합니다. 실제 스킬 효과·최종 베리 영구 정산은 별도입니다. |
| 저장 | 미션 슬롯·카운터·리롤·난수/영수증을 캡처하는 **부분 저장 API**가 있습니다. 전투·유닛·라운드 전체 저장/이어하기는 미완성입니다. |

한 사건의 결과 보상 지급이 실패하더라도 **미션 완료 자격은 유지하고 지급만 재시도**합니다. 이미 끝난 판매·조합·도박을 다시 실행하지 않습니다. 재시도 때 원래 추첨 결과를 변경하지 않는 지갑 규칙을 사용합니다.

기본 미션 난수는 상태를 저장할 수 있는 균등 난수로, 워크래프트 3의 원본 난수열·호출 순서와 동일하다는 의미는 아닙니다. 앱 통합 검증과 실제 기기 확인은 별도로 필요합니다.
