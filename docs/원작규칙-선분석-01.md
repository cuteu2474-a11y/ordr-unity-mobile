# 원작 규칙 선분석 01 — 악몽 이세계모드

> **기록 해석 기준:** 이 문서는 단계별 조사·구현 기록입니다. 본문의 미완료·미실행·다음 작업과 정책은 해당 작성 시점 기준이며, 현재 운영·전체 현황은 [최신 인수인계](새채팅-인수인계.md)의 ‘현재 작업 기준’을 우선합니다. 특히 과거 테스트 보류, 사거리 유지, 프로젝트/원본 수치 미확보 설명을 현재 상태로 적용하지 않습니다. 원본 규칙의 근거와 미검증 한계는 계속 구분합니다.

기준: ORDR S2 2.323[C] / 2026-10-21

## 분석 원칙

- 원작 규칙을 확인하기 전에는 실제 플레이 수치를 임의로 구현하지 않는다.
- 2.323은 안정화 패치이므로 2.320~2.322의 누적 변경을 함께 반영한다.
- 도감 계산기의 권장 목표와 실제 게임의 강제 규칙을 구분한다.

## 확인된 사실

### 이세계모드 개인 미션

- 2.320 패치에서 이세계모드 적용 시에만 등장 가능한 개인 미션 **유닛조합(신비)**가 추가되었다.
- 개인 미션 리롤은 **10라운드 이전**에만 사용 가능하다.
- 출처: https://ordr.kr/patch-notes/2-320
- 아직 미확인: 미션 출현 확률, 수행 조건, 보상, 리롤 비용, 횟수, 이세계모드 활성화 절차.
- 구현 결론: 이세계모드 플래그는 개인 미션 후보군에 영향을 미쳐야 한다. 단, 후보군과 추첨기는 검증된 데이터 확보 전 구현하지 않는다.

### 환전소와 위습

- 2.322: 환전소 항법 선택위습 2배 확률 50%→35%, 랜덤박스 선택위습 확률 20%→10%, 골드 확률 40%→50%.
- 2.323: 환전소 노드의 선택위습 교환에서 1개 당첨 시 미지급되던 버그 수정.
- 출처: https://ordr.kr/patch-notes/2-322 , https://ordr.kr/patch-notes
- 아직 미확인: 전체 확률표, 나머지 보상, 비용 및 조건.
- 구현 결론: 확인된 일부 확률만으로 완전한 도박 보상표를 만들지 않는다.

### 전투 관련

- 오라형 방깎/이감과 발동형 방깎/이감은 별도로 관리한다.
- 발동형 효과는 도감 계산기의 합산치와 실제 적용치가 다를 수 있다.
- 스킬 특성강화 전후 효과가 달라지는 유닛이 있다.
- 출처: https://ordr.kr/guides/armor-reduction , https://ordr.kr/guides/slow , https://ordr.kr/guides/beginner
- 미확인: 실제 피해 공식, 공속·쿨타임 공식, 중첩 방식, 유닛별 발동 조건.

### 난이도 참고 목표

- 악몽 권장 방깎 211 / 이감 102%.
- 워큐리 방깎 목표 221, 나스쥬로 이감 목표 117%.
- **강제 승리 조건이 아닌 도감의 조합 목표**이다.
- 출처: https://ordr.kr/guides/gorosei

## 구현 우선순위

1. 이세계모드 미션 출현 제한과 라운드별 리롤 가능 여부
2. 개인 미션·항법·환전소의 원작 비용/보상 데이터 확인
3. 스킬 트리거와 공격 계산식 확정
4. 검증된 수치에 대해서만 게임 로직과 자동 테스트 추가

- Unity 컴파일·NUnit 실행: 미수행
