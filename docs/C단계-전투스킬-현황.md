# C단계 전투·스킬 구현 현황

> **기록 해석 기준:** 이 문서는 단계별 조사·구현 기록입니다. 본문의 미완료·미실행·다음 작업과 정책은 해당 작성 시점 기준이며, 현재 운영·전체 현황은 [최신 인수인계](새채팅-인수인계.md)의 ‘현재 작업 기준’을 우선합니다. 특히 과거 테스트 보류, 사거리 유지, 프로젝트/원본 수치 미확보 설명을 현재 상태로 적용하지 않습니다. 원본 규칙의 근거와 미검증 한계는 계속 구분합니다.

기준: ORDR S2 2.323[C] / 악몽 이세계모드

## 2.323 도감에서 확인

- 방어력 감소와 이동속도 감소는 오라형(상시)과 발동형(스킬 사용 시)을 구분한다.
- 도감 계산기는 이감 오라만 기본 합산하며 발동형의 실제 적용은 상황에 따라 달라진다.
- 스턴에는 단일·범위 및 서로 다른 지속시간이 존재한다.
- 특성강화에 따라 스킬 구성이나 효과가 바뀌는 유닛이 있다.

## 이번 구현

- `CombatStatusEngine`: 효과별 출처, 종류, 오라/발동 구분, 발동형 만료 시간
- 효과 출처 제거 및 스턴 활성 상태 조회
- NUnit 테스트: 만료, 출처별 제거, 잘못된 시간 입력 방지

## 미구현

- 실제 피해 계산식 및 방어·마법 저항 적용
- 스킬 발동 확률·쿨타임·대상·범위 판정
- 방깎/이감 중첩 공식 및 스턴 저항
- 유닛별 2.323 스킬 데이터 연결
- Unity 실행·컴파일 및 테스트 실행

**중요:** 현재 구현은 상태효과의 수명 관리용 코어다. 도감으로 확정되지 않은 중첩 계산이나 스킬 확률을 임의로 만들지 않는다.
