# 원본 오라·공속·이속 — 자료와 전투 연결

> **문서 목적:** 원랜디 S2 2.323[C]의 방어 감소·이동속도 감소·공격속도 증가·공격력 오라를 **원본 객체 수치 → 현재 상태 효과 → 실제 타격·이동 경로** 순서로 확인하는 개발 참고서입니다. 이 문서의 수치는 원본 **능력 정의/과거 코드 연결 범위**이고, 지금 설치된 APK에서 모든 오라가 실제 작동한다는 검증 결과가 아닙니다. 최신 작업 판정은 [현재 상태](START_HERE.md)와 [C 영역 작업](PLAYABLE_ROADMAP.md)을 따릅니다.

## 1. 무엇을 어디에서 확인하나요?

원본 W3X와 `war3map.w3a`·SLK를 대조한 [전체 오라 감사 데이터](../data/original-2323C-all-unit-aura-audit.json)가 1차 근거입니다. 원본 재추출은 [오라 조사 도구](../tools/audit_original_all_unit_auras.py)를 사용합니다. 기존 구현 보고의 수치와 개수를 현재 완료율로 계산하지 않습니다.

| 구분 | 원본 조사 / 당시 연결 범위 | 현재 다루는 효과 |
|---|---|---|
| 원본 전체 감사 | 카탈로그 **272종**, 오라 관련 객체 능력 **230개**, 카탈로그 내 관련 유닛 **116종** | 능력 소유·상속·버프·마스크·레벨·진영 증거 |
| `AHad` 방어 감소 | 방어 관련 원본 능력 **79개** 조사, 당시 전투 카탈로그는 **54종·61개 레벨별 정의** | 적 방어력 변화 |
| `AOae` 속도 오라 | 원본 관련 능력 **115개** 조사, 당시 런타임은 **59종 유닛·69개 정의** | 적 이속 감소 **51**, 아군 공속 증가 **18** |
| `ACac` 명령 오라 | `AOac` 뿌리 계열 **36개** 조사, 당시 런타임은 **17종·19개 레벨별 정의** | 아군/자기 공격력 증가 |
| 합성 오라 카탈로그 | 당시 `AHad/AOae/ACac` 통합 **149개 정의** | 이미 있던 `A0EM`을 중복 등록하지 않음 |

전체 감사에서는 카탈로그 밖 원본 맵 객체 **168개**, 능력/버프 ID를 공유하는 그룹 **26개**, 객체 능력 목록을 확인하지 못한 **E-02 니카(스네이크)** 1종도 별도로 기록했습니다. 이는 게임의 캐릭터 완성 수가 아닙니다. 실제 구현 책임은 [방깎 카탈로그](../Assets/Scripts/Combat/Original323ArmorAuraCatalog.cs), [이속·공속 카탈로그](../Assets/Scripts/Combat/Original323NativeSpeedAuraCatalog.cs), [공격력 오라 카탈로그](../Assets/Scripts/Combat/Original323NativeCommandAuraCatalog.cs), [맵 객체 오라 카탈로그](../Assets/Scripts/Combat/Original323MapObjectAuraCatalog.cs)를 따릅니다.

## 2. AOae — 적 이동속도 감소와 아군 공격속도 증가

`AOae`의 `DataA` 음수는 적 이동 감소, `DataB` 양수는 아군 공격속도 증가의 **원본 표시 수치**로 읽습니다. 원본 반경·버프 ID·능력 레벨·대상 마스크도 함께 보존하지만 이 수치를 곧바로 ‘최종 이동 좌표’나 ‘다음 평타 간격’으로 바꾸지는 않습니다.

| 캐릭터 | 능력 | 원본 효과 | 원본 반경 |
|---|---|---|---:|
| 스모커(특별함) | `A08F` | 적 이속 -5% | 800 |
| 크로커다일(특별함) | `A08E` | 적 이속 -5% | 850 |
| 키드(특별함) | `A08H` | 적 이속 -5% | 800 |
| 아오키지(희귀함) | `A023` | 적 이속 -10% | 800 |
| 캡틴 키드(희귀함) | `A03S` | 적 이속 -15% | 800 |
| 크로커다일 Mr.0(희귀함) | `A03W` | 적 이속 -15% | 600 |
| 페로나 홀로홀로(희귀함) | `A03R` | 적 이속 -20% | 600 |
| 브룩 음악가(희귀함) | `A0FT` | 아군 공속 +10% | 900 |

원본 `AOae`의 상태 적용은 [오라 전투 런타임](../Assets/Scripts/Combat/CharacterCombatRuntime.SpecialAuras.cs)의 `IOriginal323SpecialAuraTargetRules`가 현재 대상/진영/면역/레벨/실제 버프와 시간 경계를 확인해야 합니다. 자기에게만 적용하거나 `DataA/DataB`를 섞은 미확정 능력은 표준 공용 오라로 억지 승인하지 않습니다.

**실제 공격 예약:** [CombatAttackPipeline](../Assets/Scripts/Combat/CombatAttackPipeline.cs)이 공속 증가 상태를 본 뒤 `IOriginal323VerifiedNativeAttackCadence`의 **검증된 최종 간격**을 받아 다음 평타를 예약하는 경로가 있습니다. 원본 중첩·상한·공격 구간/반올림 공식이 미확정이면 **원본 공속을 추측하지 않으며 해당 평타 예약이 보류될 수 있습니다.** `DataB=0.1`을 곧바로 `원래 간격 / 1.1`로 계산하면 안 됩니다.

**실제 적 이동:** [검증 이동 경로](../Assets/Scripts/Combat/CharacterCombatRuntime.NativeSpeedMovement.cs)의 `TryAdvanceEnemyAlongVerifiedOriginalRoute`는 `IOriginal323VerifiedNativeEnemyMovementStep`이 확인한 감속 좌표만 사용합니다. 일반 `TryMoveEnemy`에 이미 감속된 좌표를 전달했다면 **이중 감속**하면 안 됩니다. 기절은 이동 불가이며 넉백은 별도 강제이동 경로입니다. 실전 웨이브 이동기와 원본 이동 공급자의 연결 여부는 현재 코드·호출부에서 별도 확인해야 합니다.

## 3. ACac — 공격력 오라는 최종 피해 증가와 다릅니다

`ACac`의 `Cac1` 퍼센트형은 무기의 **공격력 증가 원시값**입니다. 방어·크리티컬·주사위·증폭을 적용한 뒤의 최종 HP 피해에 그대로 곱하지 않습니다. `Ear4=1`은 **고정 수치형**(예: `A0O6` +5000)이므로 500000% 같은 값으로 오해하면 안 됩니다.

| 캐릭터 | 원본 능력 | 공격력 효과 | 원본 반경 |
|---|---|---|---:|
| 쵸파 가드포인트(특별함) | `A0EM/B00V` | 아군 +7% | 850 |
| 쵸파 혼포인트(희귀함) | `A0EN/B00V` | 아군 +25% | 850 |
| 페루(특수함) | `A0LR` | 아군 +40% | 650 |
| 네코마무시(전설) | `A0AG` | 아군 +32% | 825 |
| 드래곤(전설) | `A09M` | 아군 +25% | 850 |
| 레일리(전설) | `A0TB` | 아군 +25% | 800 |
| 니카 루피(영원한) | `A0UD` | **자신만** +25% | 자신 |
| 오뎅(영원한) | `A0Y2` | **자신 제외 아군** +50% | 850 |
| 쵸파(초월함) | `A0OK/A0OL` | 자신 포함 +40% / 자신 제외 +40%, 별개 능력 | 825 |
| 로져(불멸의) | `A0JN` | 아군 +60% | 850 |

특히 `A0EM`과 `A0EN`은 **같은 버프 `B00V`**를 공유합니다. 능력 ID가 다르다고 무조건 더하거나 ‘큰 수치 하나’를 고르는 규칙을 만들어선 안 됩니다. `Original323SpecialAura.AllowsAllyRole`는 `self/notself`를 구분하고, `IOriginal323NativeAuraRankWitness`는 스코퍼 가반 `A0IN`처럼 여러 레벨 중 **현재 레벨 하나**를 확인합니다. `IOriginal323NativeAttackBuffRules`가 검증한 원본 공격력 보정 단계가 없다면 계산식 없이 피해를 승인하지 않습니다. `Cac1=0`, 대형 수치 `10000/20000`, 음수·전역·근거 불명 상속 등은 다른 원본 규칙으로 분리합니다.

**특별함의 원본 개체·버프 예시:** 호킨스 `h016/A08N/B011`(적 방어 -3, 반경 800), 쵸파 두뇌강화 `h01E/A0EO/B02G`(적 방어 -3, 800), 스모커 `h01F/A08F/B012`(적 이속 -5%, 800), 크로커다일 `h01A/A08E/B001`(적 이속 -5%, 850), 키드 `h00Y/A08H/B004`(적 이속 -5%, 800), 쵸파 가드포인트 `h01D/A0EM/B00V`(아군 공격력 +7%, 850). 가드포인트 `A0EM`은 원본 `war3map.w3a`의 `ACac` 파생(`Cac1≈0.07`, `Ear4=0`)이며 최종 피해 +7%가 아닙니다. `DataB` 미기재·타시기 `A0JI`의 0·거프 `A0VE`의 양수 방어를 임의로 고정 방깎으로 처리하지 않습니다.

## 4. 중복·자격·반경 — 공통 엔진의 경계

1. **정확히 같은 효과만 중복 제거:** [Original323AuraCommonRules](../Assets/Scripts/Combat/Original323AuraCommonRules.cs)의 `TryResolveIdenticalAura`는 동일 효과 종류·능력·레벨·버프·값의 출처들을 계산 한 번으로 합치고, **시전자별 수명주기는 따로 유지**합니다. 호킨스/쵸파 두뇌강화의 동일 방어 -3 출처를 겹쳐도 무조건 -6으로 만들지 않습니다.
2. **다른 능력·레벨·버프는 보류:** 공유 버프 **26개 그룹**의 서로 다른 오라 선택·중첩 우선순위는 원본 확인 없이 ‘모두 합산’이나 ‘가장 강한 값’으로 단정하지 않습니다. 같은 효과의 성분인 이속/공속도 임의로 합치지 않습니다.
3. **실제 대상과 생명주기:** `PassesCommonEligibility`로 사망·숨김/투명·적대 오라 마법 면역 여부를 확인하되, 이 함수 하나로 실제 능력 소유·대상 마스크·진영·현재 레벨·오라 갱신 틱/잔류를 승인하지 않습니다. 잘못된 `SourceId`만 복사한 임의 상태도 거부해야 합니다.
4. **거리와 대상:** 원본 반경·시전 거리·효과 범위와 대상 수를 각각 근거에 따라 적용합니다. 전장 자격·면역을 유지하며 정책과 코드의 일치 여부는 [전투·스킬 공통 엔진](전투-공통엔진.md)에서 구분합니다.
5. **기본 이동속도 상수:** 원본 `war3mapMisc.txt`에 `MinUnitSpeed=89`, `MaxUnitSpeed=490`이 있지만, 최종 속도·충돌·정지·상한 적용 순서는 별도 근거가 있어야 합니다. 모든 몬스터에 상수만으로 속도를 억지 보정하지 않습니다.
6. **점수판 수치는 실제 전투가 아님:** `BH9/BIB/BIC`의 **246개 레벨 항목**, `BIH/BIE`의 우선순위 분기는 `BjL → BjK → LeaderboardAddItem` 정보창용 등록식입니다. 해당 유틸 계산을 실제 적이 받은 버프의 최종 중첩/방어 공식으로 복사하지 않습니다.

오라 대상·공격력·감속의 안전한 연결은 [전투 상태 엔진](../Assets/Scripts/Combat/CharacterCombatRuntime.SpecialAuras.cs)과 [원본 피해·방어·마저](원본-피해-방어-마법저항-근거.md), 보니 `A04P` 같은 **발동형 방깎**은 [별도 조사](원본-발동형-방어감소-기술사건.md)를 참조합니다. 발동형 방깎을 네이티브 오라와 하나의 무조건 적용 공식으로 합치지 않습니다.

## 5. 아직 ‘원작과 동일하게 플레이 가능’으로 볼 수 없는 부분

- 실전 W3 네이티브 오라의 **실제 버프 존재·우선순위·중첩/해제 시점**과 현재 레벨·대상 마스크 증거 공급자.
- `AOae` 공속의 **실제 공격 간격·상한·틱 반올림**, 웨이브별 이속·충돌·좌표 계산, 이동 경로 호출부.
- `ACac`가 적용된 **원본 공격력·주사위·방어·최종 HP 피해 적용 순서** 및 미확정 고정값/자기 전용 능력.
- 최신 Unity 통합 검사·APK 설치·실기에서의 캐릭터별 실제 적용 여부. 과거 `Original323NativeSpeedAuraCatalogTests`, `Original323NativeCommandAuraTests`, `Original323VerifiedNativeAttackCadenceTests`, `Original323VerifiedNativeEnemyMovementTests`, `Original323NativeSpeedRuntimeIntegrationTests` 등의 **시험 코드 존재는 최신 실행 통과 증거가 아닙니다.**

원본 오라 감사 JSON·수동 검증 근거가 기준이고, 자세한 변경 연혁은 Git 기록에서 확인합니다. 새로운 공급자·호출부를 구현할 때는 현재 [개발 작업](PLAYABLE_ROADMAP.md)의 C/Q 범위를 먼저 확인합니다.
