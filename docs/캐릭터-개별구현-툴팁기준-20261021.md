# 캐릭터 개별 구현 — 도감·툴팁 우선 (2026-10-21)

> **기록 해석 기준:** 이 문서는 단계별 조사·구현 기록입니다. 본문의 미완료·미실행·다음 작업과 정책은 해당 작성 시점 기준이며, 현재 운영·전체 현황은 [최신 인수인계](새채팅-인수인계.md)의 ‘현재 작업 기준’을 우선합니다. 특히 과거 테스트 보류, 사거리 유지, 프로젝트/원본 수치 미확보 설명을 현재 상태로 적용하지 않습니다. 원본 규칙의 근거와 미검증 한계는 계속 구분합니다.

## 원칙

1. 낮은 등급부터 **캐릭터 한 명씩** 데이터 → 동작 → 검증 순서로 완료한다.
2. 도감·툴팁에 공개된 공격력, 발동 조건, 확률, 피해량, 조합 재료를 기준으로 C# 구현한다.
3. 원본 W3X rawcode·JASS 추출은 완료 판정에 필요한 선행 조건이 아니다.
4. 공개된 내용이 없으면 **미확인**으로 명시한다. 모든 캐릭터에 스킬이 있다고 가정하지 않는다.
5. 다른 버전 자료의 숫자는 출처와 시점을 기록하고 최신 2.323[C] 확정값으로 올리지 않는다.
6. 최종 완료에는 Unity에서 실제 소환·전투·조합·처치 처리가 연결되고 동작이 검증되어야 한다.
