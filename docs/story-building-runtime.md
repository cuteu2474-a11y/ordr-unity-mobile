# ORDR S2 2.323[C] · 스토리 건물 14종

**기준:** Unity 모바일 악몽·이세계 오프라인 · 원본 W3X/JASS 고정 SHA 대조.

## 실제로 연결된 기능

- 게임 준비 시 로그타운 생성 → 1~12 건물의 사망 콜백 연속 생성 → 와노쿠니 파괴 후 120초 → 에그헤드 등장(240초 제한). 악몽 35R 시작 시 13스토리 와노쿠니 미격파면 패배.
- 스토리 건물은 정지 대상이며 65라운드 몬스터의 이동/개체수/처치/누수/패배 카운터와 분리.
- 원본 `CWL/CWM`에 따른 수동 입·퇴장, 기본 타격/스킬 전장 분리, 플레이어 소유 유닛 제거 시 파견 상태 정리.
- 원본 JASS 건물 생성 좌표 B1=(-6768,-5072); 모바일 하단 별도 스토리 전장에 건물 HP와 파견 수 및 카운트다운 표시.
- 14단계의 직접 확인된 **기본 골드·목재·위습** 보상은 공유 지갑에 단계별 중복 방지 영수증으로 지급. 실제 소유 유닛이 피해를 가한 경우만 싱글플레이 MVP/기여 기본 보너스.
- **연구 5종**(R01N, R01O, R01P, R01Q, R01S)과 **특성포인트 6개 기본 지급**은 `Original323StoryMobileProgression`의 실제 캠페인 진행 상태에 기록합니다. 특성 선택이 kW==ka인 경우 원작대로 각 보상에 +1하는 공급자 인터페이스도 제공합니다.
- 보상 대상이 있는 네이티브 효과는 `Original323StoryNativeRewardQueue`로 별도 추적하며, 실제 대상 월드가 확인하고 적용한 경우에만 정산 완료로 변경합니다. 가짜 재화로 실제 사용 가능한 보상을 가장하지 않습니다.

## 이번 원본 W3X 재대조 · 스토리 건물 능력치

원본은 **스토리 건물의 소유자를 Player(5)**로 만들며, 악몽 모드의 최초 연구와 단독 플레이어 보정은 서로 다른 함수에 나뉘어 있습니다.

- `CUM` 58044~58045행: Player(5) **R012 1레벨(HP +58%)**, R01A 1레벨(스토리 대상 업그레이드 목록에는 없음).
- `CN3/BeP` 52774~52776·8727~8746행: 플레이어 1명에서는 Player(5) **R02K(HP -5%), R021(HP -25%)**가 추가 적용됩니다. `R02Z`도 호출되나 현재 원본 `UpgradeData.slk`에는 데이터가 없습니다.
- `Units/UnitBalance.slk` 스토리 14종은 모두 `fort` 방어, 모델의 초기 HP 보정 합계는 **기본 HP × 1.28**. 산출은 정수 연산으로 수행하며, 네이티브 연구 적용 순서/소수점 처리는 최종 클라이언트 대조 전까지 *MODEL_ONLY*입니다.
- 9~14단계 건물의 기초 재생량은 **초당 1,000 HP**, `always`. 연습 모델에 전투 논리 시간 기준으로 적용하며 사망 후 재생·최대 HP 초과를 금지합니다.
- 모든 건물 생성 시 `A904`(AIde 타입), `A04Q`(AIdd 마법 피해 보정)가 적용됩니다. 악몽 초기 `NJ=16`의 현재 확인된 기본 마법 피해율은 **90%**이며 이후 오로성 이벤트로 NJ가 변경될 수 있습니다. **동적 NJ·추가 연구·스킬별 면역의 실전 완전 동등성은 아직 미확정**입니다.

## 스토리 보상 특수 효과: 확인 사항과 경계

- 9스토리 **어인섬**: 실제 원본 `CPv` 54392행에서 **고대의 배 `h05Y`** 유닛을 플레이어 시작 위치에 만듭니다. 도박에서 얻는 다른 배 및 10스토리의 초월위습과 **별개**입니다.
- 10스토리 **펑크해저드**: 원본 `CQB`가 초월위습 `e01A`를 만듭니다. 현재는 `practice:story:e01A` 연습 전용 지갑 권리로 기록되며, 원본 확정 쿠마 선택·실제 유닛 생성과 혼동하지 않습니다.
- 13·14스토리: `Hp[VT[player]]` 원본 영웅 그룹 구성원 각각에게 **경험치 300**. 아무 유닛이나 영웅으로 가정해 잘못 지급하지 않습니다.
- 14스토리 **에그헤드**: `RV[player]` 건물에 1회 사용 가능한 **그린블러드 `A13A`** 능력 부여. 실제 원본 주문 `CKe`는 `h032→h09Y`, `h043→h0A3`, `h030→h0A1`, `h03G→h0A0`로 변신하거나, `A912/A07N`을 지닌 다른 본인 유닛에게 `A134/A13C`를 부여합니다. 소유권/소비/보조효과까지 필요한 정확한 `Original323StoryGreenBloodRules` 계획을 작성했습니다.
- 고대의 배, 영웅 XP, 그린블러드 **실제 배우 생성·XP 레벨링·능력 사용 실행기는 아직 연결 전**입니다. 미완료 상태는 스토리 UI에서 별도 건수로 표시합니다.
