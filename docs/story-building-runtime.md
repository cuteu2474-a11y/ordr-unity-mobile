# 스토리 건물 14종 — 현재 개발 상태

## 구현

- `Original323StoryBuildingPracticeWorld`는 **연습용 MODEL_ONLY 생성**과 **원본 출현 확인을 거친 생성**을 엄격히 분리합니다. 원본 출현 인터페이스는 단계 허가, 실제 건물 ID, 최종 HP/방어력/좌표/마법저항과 별도의 관측 증거를 요구합니다. 검증 없이 객체 기본값을 악몽·이세계 실전 최종 수치로 승격하지 않습니다.
- 스토리 건물을 일반 65라운드 이동·적 수·처치·누수·패배 집계에서 분리했습니다. 모델의 라운드 이동기, 일반 이동, 강제 이동, 관측된 다중 위치 변경에서 스토리 건물 이동을 거절합니다.
- 실제 전투 피해/사망 판정은 `CharacterCombatRuntime` / `CombatResolution`을 재사용합니다. 건물의 상태는 생존·파괴·제거로 별도 기록합니다.
- `Original323StoryManualDispatch`는 **원본 조건 공급자가 승인한 경우에만** 수동 파견·복귀를 수행합니다. 이동 성공 전에 상태를 변경하지 않으며, 같은 유닛을 메인과 스토리 양쪽에서 공격시키지 않습니다.
- 컨트롤러가 원본 스토리 출현·파견·정산 증거 공급자를 받아 연결할 수 있습니다. 모바일 스토리 탭은 14단계와 전투 체력·건물 상태를 표시합니다. 출현 요청 버튼은 원본 출현 공급자를 설치한 경우에만 나타납니다.

## 보상과 해금 경계
- **스토리 건물 파괴는 그 자체로 보상 정산이 아닙니다.** 실제 출현을 확인한 건물이 파괴됐고, 독립적인 원본 완전 정산 공급자가 사건 ID 및 원본 건물을 증명할 때만 정산 완료로 기록합니다. 중복 출현 이벤트와 정산 이벤트를 거절합니다.
- 기존 `Original323SourceMaterialRewardWorld`는 JASS `CQB`의 **10,000골드/목재 4/기타 YR 2/초월위습 e01A 1** 전체 정산을 외부가 보증한 경우에 한해 초월위습 권리를 기록합니다. **이것이 모든 14단계의 개별 보상이라고 가정하지 않습니다.** 연결하지 않은 보상을 새로 지급하지 않습니다.
- 해금 순서·등장 시간·기본 건물 등장 좌표와 35라운드 실패 조건은 원본 2.323[C] JASS에서 검증했습니다. 다만 난이도 적용된 실제 HP, 건물 대상 스킬 유효성, 실제 파견·회수 조건과 각 보상의 원자적 정산은 추가 검증이 필요합니다. 현재 저장소에는 모든 14단계의 최종 런타임 사건을 확인해 공급하는 구현이 없으므로 **실제 스토리 전체 완료라고 표시하지 않습니다.**

### 스토리 출현·해금의 정확한 규칙

1. 난이도·모드 확정 시 `CUM`이 `LB`를 실행하고 첫 건물 로그타운이 등장한다(`CN3`, 52774~52781행).
2. 각 건물은 모두 `Player(5)`가 `B1` 지역 중심(-6768, -5072)에 생성한다. 원본은 등장할 때 `A904`를 부여하고 마법방어 `A04Q` 레벨을 `NJ`로 설정한다. 본문 `B1` 좌표는 14750행, 최초 생성 52715~52723행.
3. **1~12단계의 건물이 파괴되면 다음 단계가 즉시 소환**된다. 원본 `BDB` 사망 등록→`TriggerEvaluate(oT, stage+1)` 체인으로 이어진다. 13단계 **와노쿠니** 파괴 후에는 **신(5)·악몽(6)**에서 **120초 후 14단계 에그헤드**가 등장한다(`CQ0/CQz`, 55260~55283행).
4. **35라운드 시작 사건**(`CVD`, 59237~59285행)에서 난이도별 필요한 파괴 완료 단계는 어려움 9(어인섬), 지옥 11(드레스로자), 신 12(홀케이크섬), **악몽 13(와노쿠니)**. 미완료 시 패배한다. 악몽은 에그헤드의 실제 등장까지 완료할 필요는 없으며 **와노쿠니 파괴까지**다.
5. 에그헤드는 원본 `CRB` 생성 시 **240초 제한시간**이 시작되며, 신/악몽에서 살아 있으면 `CQ9`가 패배 처리한다(55433~55461행). 이는 스토리 미션 제한이지 일반 라운드 패배 카운터가 아니다.
