# 스토리 건물 시스템 현황

- 스토리 14종은 원본 객체의 고정 건물로 분류한다. 기본 HP/fort 방어력은 최종 악몽·이세계 수치가 아니다.
- 연습용 건물 생성/파괴 판정과 컨트롤러 및 스토리 탭 목록이 연결되어 있다.
- `Original323StoryManualDispatch`는 기존 수동 파견 인터페이스를 구현한다. 원본 검증 이동 공급자 `IOriginal323StoryUnitMovement`가 파견 가능 여부와 실제 이동 성공을 제공한 경우에만 파견 상태를 변경한다. 복귀 실패 시 상태를 유지하며, 원본 이동 공급자 없이 임의로 활성화하지 않는다.
- 전투 엔진의 `IsStoryDeployed`에 연결하면 파견 유닛의 메인 전장 공격이 차단되고 스토리 대상으로 분리된다.
- **미완료:** 원본 파견/복귀 조건·실제 건물 배치와 해금·모드 최종 수치·건물 대상 스킬 면역·원본 보상/중복 지급 방지·실제 모바일 검증. 스토리 완료나 보상을 임의 생성하지 않는다.
