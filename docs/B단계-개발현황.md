# B단계 개발 현황: 게임 기본 구조

기준: 원랜디 S2 2.323[C] / 악몽 변이 모드 고정

## 구현한 순수 C# 기반 코드
- `GameSession`: 게임 시작, 라운드 순차 진행, 적 출현·처치·누락 집계, 종료 상태
- `PathProgress`: 외부에서 전달한 경로를 거리 기준으로 보간
- `UnitRoster`: 유닛 인스턴스 생성·선택·이동·제거
- `BasicLoopTests`: 위 상태 전이의 단위 테스트 코드

## 아직 구현하지 않은 항목
- Unity 장면, UI, 터치 입력 및 Android 빌드
- 원작 맵의 실제 좌표·경로와 라운드별 몬스터 데이터
- 원작 유닛 데이터·소환 규칙·비용·확률
- 몬스터 자동 이동·스폰 스케줄·전투
- 악몽 변이의 정확한 효과 및 종료 조건

## 테스트 상태
코드와 NUnit 테스트를 작성했지만 이 작업 환경에는 Unity 및 C# 컴파일러가 없어 **컴파일/테스트 통과를 주장하지 않습니다**. 다음 작업 환경에서 Unity Test Runner 실행이 필요합니다.
