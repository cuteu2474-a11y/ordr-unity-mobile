## 판정 기준

MS-01~24는 이전에 발견한 24개 기술의 **추적 ID**입니다. 후속 코드가 반영됐으므로 ‘24개 전부 미구현’ 또는 ‘힘/민첩 공급 함수 호출0건’으로 해석하지 않습니다. 최신 핵심 실행기·능력치 월드·컨트롤러와 현재 문서를 재대조했습니다. 이번에 모든 기술/효과를 다시 실행하거나 전수 검증한 것은 아닙니다.

- **현재 추가 구현/입력이 필요한 것:** 원본 표식/A11S, 시저 피해, 전체 능력치 보너스/위성 성장·실제 폼 거래·저장 등.
- **계산/모델 코드가 추가된 것:** 검은수염·나미·타시기 능력치 식, 카이도 명중 비례 성분, 히바리 독립 도시락과 점수 자격.
- **검증이 필요한 것:** 원본 피해/타이밍 의미와 현재 모델의 동등성, Unity/Android 실행, 전체 복원.
- E절의 98개는 이전 ID/이름 검색 후보입니다. 최신 미구현 총수나 구현 완료율이 아닙니다.

### 능력치 공급의 정확한 상태

`Original323HeroAttributeWorld`와 컨트롤러의 `ConfigureSourceModelOriginalHeroAttributes` 연결은 존재합니다. 초기값/레벨 성장/SET 보정으로 보너스 제외(false) 값을 모델 계산하고, true 값은 원본 보너스의 실제 입력이 필요합니다. 현재 관측 인터페이스 존재만으로 실제 입력이 있는 것은 아닙니다. 원본 자료가 확보된 효과는 독립 모바일 상태로 재현하고 관측값과 모델 계산값을 구분합니다.

H영웅70행은 명시4행과 숫자 생략66행으로 나뉩니다. 생략의0은 OpenRealm 파서 규칙을 따른 모델이며 Blizzard 실측 검증 완료를 뜻하지 않습니다. 실제 미등록/미확정 입력은 null로 유지합니다. UnitPointValue·표시 공격력·등급점수를 힘/민첩/지능으로 대입하지 않습니다.

### 카이도의 별도 콜백4개

B_5/B_1은 명중 피해30%, CBE는25%, CBI는10% 후속 모델이 연결됐습니다. 원본 EventDamage 의미와 CBI 두 타격 지연/타입은 남아 있습니다. 이4개를 별도 프로필 기술4개로 합산하지 않습니다. 실제 공격 사건의 ID·대상·폼·전장에 매칭하고 후속 피해가 자신을 재발동하지 않게 해야 합니다.

## D. 다시 미구현으로 만들지 않을 것

- 히바리 제작/소비/판매 및 독립 사용 명령, 핸콕 피해타입, 비비/핸콕 간격, 쿠마10% 기절 등 기존 코드.
