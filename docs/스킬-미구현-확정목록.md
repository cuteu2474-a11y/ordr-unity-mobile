## 구현 순서와 닫는 기준

1. **능력치 공급 묶음:** MS-02~07. 검은수염 현재 폼과 위성 원본 스탯의 출처를 각각 확인하고 공통 스탯 읽기/저장 구조에 연결. 검은수염 힘과 위성 힘을 같은 값으로 가정하지 않음.
2. **원본 자격 묶음:** MS-01과 히바리 대상 자격. 객체/능력 레벨·적 분류 조건을 확보해 기존 타격/사용 함수에 연결.

4. **UI/예약 상태 묶음:** C절의 도시락 독립 조작과 기존 저장 작업을 함께 연결.

각 행을 완료로 바꿀 때 ‘기술 ID·원본 근거·실제 호출 위치·빠진 성분 적용·비용/난수/종료·검증 결과’를 기록합니다. 단순 필드 추가나 이벤트 메시지 출력으로 완료 처리하지 않습니다. 실제 실행은 별도 요청 시 묶어서 검증합니다.

**이번 수행:** 소스/등록 프로필/최근 변경 정적 대조와 문서 작성. 코드·데이터·자동 생성 감사표는 수정하지 않았고 Python/NUnit/Unity/APK/Actions를 실행·조회하지 않았습니다.
