# 공격 유형과 피해 유형 분리 — 현재 구현 상태

범위: 원랜디 S2 2.323[C] 독립형 Unity 전투의 **공격 선언 스킬** 공통 계산 경로.
원본 W3X JASS·SLK의 공격 상성, 피해 유형과 A04Q 마법 저항은 서로 다른 축입니다.

## 현재 연결

- **공격 유형**: 원본 `DamageBonus*` 8개 방어 유형 상성표. 평타 경로는 기존대로 유지.
- **피해 유형**: `SourceScriptDamageType`에서 물리(수치 방어력 적용), 마법(수치 방어력 무시·출처가 있는 A04Q 마법 저항), Universal(양쪽 무시)을 명시적으로 분리.
- `ModelDefault`는 피해 유형이 원본에서 확정되지 않은 기존 스킬의 구형 물리 계산을 유지. **모든 Spells 공격 유형을 마법 피해로 가정하지 않음**.
- `SourceModelScriptDamageTypeRules.TryPrepare`에서 피해 난수 소모 **전** 대상의 방어 유형, 필요한 수치 방어력과 A04Q 레벨을 검사. 미확정 마저는 0%로 바꾸지 않고 `EffectDeferred`로 보류.
- 현재 마저/증폭의 원본 중첩 공식이 불명확한 상태에서는 다른 버프와 임의로 합치지 않고 보류.
- 원본 네이티브 주문에 근거가 있는 `S-12` 봉쿠레 폭격백조(`A08O/Apxf`), `U-04/U-13` 람각(`A0VS/AUcs`), `S-18` 갈래 번개(`A086/ANfl`), `S-19` 캐리언 스웜(`A0ES/AUcs`)을 Magical로 명시. `S-03` 나미의 명시적 JASS Universal은 유지.

## 모델과 원본의 경계

- 봉쿠레 `Bn4` 확률 12%, `h0C5` 수명 1.2초, `A08O` 피해 250·주기 0.2초·탐지 800은 원본 객체 근거. 모바일은 5회 재표적 직격으로 근사하며 **첫 발사 시각, 실제 네이티브 대상/투사체 선택, 면역은 미검증**.
- 독립형 65R 연습 월드는 악몽 초기 A04Q 16레벨(원본 Def5 피해 수령 계수 약 0.9)을 출처 포함해 보유하며, 해당 레벨의 마법 주문은 수치 방어력 대신 이 계수를 적용.
- `IOriginal323MonsterNativeAbilitiesWitness` 등은 원본 현재 마법 면역/무적 상태를 별도로 관측하기 위한 인터페이스로 존재하지만 **이 공통 스킬 모델에는 아직 연결되지 않았음**. 마법 면역 결과를 원본과 동일하다고 인증하지 않습니다.
- `A04Q`가 **각 네이티브 주문의 실제 타격에 적용되는 조건**, 마법 저항 증감·증폭 중첩 순서, 최종 float32 HP 양자화와 네이티브 대상 타이밍은 원본 실행 대조 전입니다.
- 다른 액티브·후속 효과 계산기는 각각 별도 경로를 쓰므로 이번 변경이 **모든 스킬의 마저 적용 완료를 뜻하지 않습니다**.

## 검증

`SourceModelScriptDamageTypeRulesTests`: 마법/물리/Universal 계산 분기, 원본 방어 유형 배율 보존, 16/41레벨 A04Q, 근거 없는 마저 차단, 미검증 중첩 보류, 네이티브 주문 타입 매핑.
`SourceModelScriptAttackSkillTests`: 마저가 없는 20R 레거시 전장에서는 스킬을 근거 없이 실제 피해로 처리하지 않도록 회귀 조건 변경.
테스트 코드는 추가했으나 **Unity·Android 원본 실기 일치 검증은 별도**입니다.
