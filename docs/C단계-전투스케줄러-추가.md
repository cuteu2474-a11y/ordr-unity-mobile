# C단계 후속: 공격 주기 및 타깃 판정

> **자료의 위치:** 본문은 해당 기능의 원본 근거와 작성 당시 구현 기록입니다. 현재 실행 범위는 [START_HERE](START_HERE.md), 다음 작업은 [PLAYABLE_ROADMAP](PLAYABLE_ROADMAP.md), 운영 정책은 [AGENTS](../AGENTS.md)를 우선합니다. 본문의 과거 APK/테스트 보류·사거리·다음 작업을 현재 지시로 복사하지 않습니다.

> **기록 해석 기준:** 이 문서는 단계별 조사·구현 기록입니다. 본문의 미완료·미실행·다음 작업과 정책은 해당 작성 시점 기준이며, 현재 운영·전체 현황은 [최신 인수인계](새채팅-인수인계.md)의 ‘현재 작업 기준’을 우선합니다. 특히 과거 테스트 보류, 사거리 유지, 프로젝트/원본 수치 미확보 설명을 현재 상태로 적용하지 않습니다. 원본 규칙의 근거와 미검증 한계는 계속 구분합니다.

기준: 원랜디 S2 2.323[C] / 악몽 이세계모드

## 실제 구현

- `CombatScheduler`: 시간 진행, 유닛별 첫 공격 지연, 공격 가능 여부, 공격 후 쿨타임, 유닛 제거
- `CombatTargeting`: 사망한 대상과 사거리 밖 대상을 제외하고 후보를 선정
- 최근접/경로 진행도가 높은 적 우선은 **외부에서 명시적으로 지정하는 임시 정책**이다. 원작의 실제 타깃 우선순위라고 주장하지 않는다.
- 동일 우선순위의 대상은 ID 오름차순으로 결정해 재현성을 높인다.
- NUnit 테스트 4개 작성

## 확인 필요

- 원작의 공격속도/공격 주기 공식, 선딜 및 투사체
- 유닛별 공격 사거리, 타깃 정책, 스킬 발동 조건
- 물리/마법/고정 피해와 방어력 계산식
- 타격 시점 및 상태효과 적용 순서

## 검증 상태

GitHub 파일 등록/재조회와 Unity 컴파일·테스트 실행은 구분한다. 테스트 코드는 작성했으나 Unity 환경에서 아직 실행하지 못했다.
