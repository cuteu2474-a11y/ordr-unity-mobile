## 사용 방법

1. 아래 ‘다음 실행 묶음’에서 선행 조건이 충족된 작업부터 진행한다. A 전체 조사를 마칠 때까지 구현을 멈추지 않는다.
2. 작업 ID는 유지한다. 추가 항목은 새 번호를 부여하고 기존 번호를 재사용하지 않는다.
3. 체크박스는 **해당 항목의 완료 조건과 필요한 검증 결과를 충족했을 때만** 체크한다. 코드 작성만 끝났거나 자료가 없으면 미완료로 둔다.
4. 부분 완료·진행 중·자료 대기는 아래 진행 기록에 적는다. 막힌 이유, 필요한 원본/관측값, 다음 실행 가능한 작업을 함께 남긴다.
5. 완료한 ID·커밋·검증 결과·다음 ID를 같은 변경에서 갱신한다. 구현과 검증을 별도로 보고하고 테스트 파일 존재를 통과 증거로 쓰지 않는다.
6. 캐릭터별 작업은 공통 코드가 만들어져도 자동 완료하지 않는다. 해당 캐릭터의 모든 대상 기술·강화·조합·파견 예외까지 별도로 확인한다.
7. 현 모드에서 사용하지 않는 콘텐츠는 출처와 제외 이유를 기록한다. 미구현을 임의로 제외 처리하지 않는다.
8. 작업량은 같지 않다. 시간·완성률을 체크 개수로 추정하지 않는다. 현재 빈 체크는 ‘아무 코드도 없음’이 아니라 **통합 완료 기준을 아직 충족하지 않음**이다.
