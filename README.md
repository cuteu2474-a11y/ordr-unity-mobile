# 원랜디 Unity 모바일

ORDR S2 2.323[C] · 악몽 + 이세계모드 · 오프라인 싱글플레이 리메이크입니다. **현재는 10R/20R 개발용 연습이며, 전체 유닛 스킬·원작 동등성·정식 65라운드는 미완성입니다.**

## 개발을 이어받는 순서

1. [AGENTS.md](AGENTS.md) — 작업 규칙·GitHub/검사 운영
2. [여기서 시작](docs/START_HERE.md) — 최신 구현 범위·실행 방법·원본 입력
3. [코드 구조](docs/CODE_MAP.md) — 구성 흐름·기존 구현·수정 지점
4. [다음 작업](docs/PLAYABLE_ROADMAP.md) — 우선순위·대상 파일·완료 기준

이 네 문서가 현재 개발 진입점입니다. 이전 대화나 임시 로컬 파일이 없어도 먼저 저장소의 코드·JSON·검사를 확인할 수 있도록 정리했습니다.

## 현재 플레이 경로

Unity 기본 씬 `Assets/Scenes/MainGame.unity`에서 **유닛 준비 → 위습 소환·조합 → 20R 연습 전투**로 진행합니다. 플레이 메뉴에서 10R도 고를 수 있습니다.

- 원본 객체 기본 공격 모델, 순수 치명타·기절, 로빈 다중 타격과 일부 오라
- 실제 재료를 소비하는 116개 제작식, 지원 유닛 판매, 갱 뱃지·버기 마기탄 분해
- 일반 돈 도박의 수동 확인·실제 10골드 거래·원본 보상 분기와 연습 재고 모델
- 몬스터 출현·순환 이동·처치 골드·라운드 위습·보스 시간초과·승패·기록
- 가로 UI, 전장 수동 이동/확대, 일시정지·앱 전환 시 논리 시간 정지

파일·코드 연결, 로컬 검사, Unity 실행, APK 생성, 실기 플레이 검증은 각각 구분합니다. 상세 범위와 알려진 문제는 [현재 상태](docs/START_HERE.md)에 있습니다.

요청 APK는 기존 Actions에서 Unity 검사 후 ARM64·ARMv7 단일 개발용 APK로 제작합니다. 서명·필수 데이터 검사 후 APK와 체크섬을 함께 첨부합니다. 제작 경로가 연결됐다는 사실은 APK 생성·설치·정식 게임 완성을 뜻하지 않습니다. [제작·다운로드 방법](docs/unity-editmode-test.md)을 참고하세요.
