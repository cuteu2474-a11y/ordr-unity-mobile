# 원랜디 Unity 모바일 프로젝트

원랜디 **S2 2.323[C] 악몽 난이도 이세계모드**의 플레이 경험을 Unity 기반 모바일 독립 앱으로 재현하는 프로젝트입니다.

## 확정 개발 범위
- **악몽 난이도 + 이세계모드 고정**: 다른 난이도 및 일반 모드 구현은 범위에서 제외합니다.
- **오프라인 싱글플레이**: 난이도·모드 선택 화면 없이 해당 모드로 바로 시작합니다.
- **인터넷 도감 우선**: 유닛, 스킬, 조합, 특성강화, 경제, 라운드 규칙은 버전이 확인된 도감·공략을 우선 참조합니다.
- **원본 W3X는 예외적 검증**: 도감에 없는 필수 규칙, 출처 간 충돌, 실제 동작 검증이 필요한 경우에만 분석합니다.
- **게임성 최우선**: 전투·스킬·조합·상점·도박·위습·스토리·보스·항법 등 실제 플레이 기능을 먼저 구현합니다.
- **그래픽은 신규 최소형**: 시각 효과와 애니메이션은 후순위입니다.

## 현재 상태
전투 코어와 개인 미션 규칙 분석을 진행 중입니다. 원본 S2 2.323[C] JASS에서 개인 미션 **18종의 목표·보상·3칸 추첨·리롤 조건**을 추출하여 독립 C# 세션 엔진과 테스트를 작성했습니다. 다만 **실제 게임 이벤트 연결, Unity 프로젝트 구성·컴파일·테스트 실행·APK 빌드**는 아직 완료되지 않았습니다. 자세한 내용은 [개인 미션 구현 현황](docs/개인미션-구현현황.md)을 참고하세요.

## 전투·스킬 공통 엔진 (2026-10-21)
- 물리·마법·스크립트 정의 피해와 폭발형 속성을 독립 모델로 분리했습니다.
- 공격형/적중형/주기형/조건형 스킬 트리거, 인스턴스별 쿨타임, 기본 공격의 타깃·피해 계산 주입·처치 연동 C# 코드를 추가했습니다.
- 원본 전투 공식 및 유닛별 세부 수치는 아직 검증 중이며, 실제 스킬 효과의 범위 피해·오라 갱신은 미구현입니다.
- [C단계 전투·스킬 공통 규격](docs/C단계-전투피해스킬-공통규격.md)

## 프로젝트 구조
- `Assets/Scripts/Core`: 화면과 독립된 게임 로직 기반

- `docs`: 원작 대조 기준 및 개발 기록

## 개발 규칙
1. 인터넷 도감의 버전·URL·확인일을 기록합니다.
2. 도감에 없는 수치·확률·스킬 효과를 추측해 넣지 않습니다.
3. 원본 W3X 분석은 필요한 예외 상황에 한정합니다.
4. 검증하지 않은 기능은 '미검증'으로 표시합니다.
5. 문서·커밋·테스트 보고서는 한국어로 작성하고 불필요한 브랜치와 워크플로는 만들지 않습니다.
6. APK는 핵심 기능 완성 및 검증 후 제작합니다.

## 배포 권리
원작의 이름·설정·데이터 등 보호되는 요소는 공개 배포 전에 이용 권한을 확인해야 합니다.
