# 원랜디 Unity 모바일 프로젝트

원랜디 S2 2.323[C]를 참고하여 개발 중인 **Unity 모바일 독립 게임**입니다. 현재는 개발·검증 단계이며 완성본이나 배포용 APK가 아닙니다.

## 2026-10-27 개인 미션 게임 연동

게임 시작 시 미션 3개 배정, 모바일 진행도·기한·보상 표시, 10라운드 전 1회 교체,
성공한 판매·선택위습·원본 실제 조합 집계와 공유 지갑 보상을 한 묶음으로 추가했습니다.
중복 이벤트·보상 재시도·미션/지갑 저장 복원도 포함합니다.
**전체 게임 저장·기록지침의 전투 효과·모든 미션 이벤트 연결이 완료된 것은 아닙니다.**
[실제 연결 범위와 검증 기록](docs/개인미션-게임연동-20261027.md).

## 현재 상태

- **캐릭터**: 웹 도감 기준 271종 목록, 상세 스킬 프로필 200종 등록. 실제 전투 동작까지 완성되었다는 뜻은 아닙니다.
- **평타 데이터**: 원본 유닛 270종 매핑, 그중 269종 공격 1 오브젝트 필드 확보. 실제 HP 피해 적용에는 유닛별 검증된 피해 공급자가 필요합니다.
- **전투·조합·경제 시스템**: 원작 대조와 단계별 구현이 진행 중입니다. 미확인 수치나 재료 비용은 임의로 가정하지 않습니다.
- **평타 시각 연출**: 유닛·적 마커, 베기/발사체/마법 공통 타격 효과를 전투 이벤트로 표시합니다. 마법 연출은 별도 검증된 마법 공격 스펙에서만 사용합니다. 피해 미검증 유닛의 파란색 공격 미리보기는 적 체력을 감소시키지 않습니다.
- **실제 체력 반영 경로**: 외부에서 해당 유닛의 공격 경로·적 방어값·HP 정수화 방식을 검증해 공급하면 원본 기본 공격 주사위/주기에 따라 실제 적 체력이 감소하고, 적 체력 바가 이를 표시합니다. 검증되지 않은 적의 방어력을 0으로 취급하거나 검증된 다른 적까지 공격 중단시키지 않습니다. 현재 전체 맵의 실제 피해 공식이 승인된 상태는 아닙니다.
- **테스트**: `main` 변경 시 Unity 6 EditMode와 비 Unity 회귀 테스트가 자동 실행됩니다. 통과하더라도 모바일 실기 플레이·원작 전투 완성을 뜻하지 않습니다.
- **GitHub 운영**: `main` 단일 브랜치, Unity 테스트 워크플로 1개를 자동 및 수동 실행에 사용합니다.

현재 운영·수치가 과거 기록과 다르면 [최신 인수인계의 현재 작업 기준](docs/새채팅-인수인계.md)을 참고합니다.

## 2026-10-21 개발 방향 변경: 도감·툴팁 기준 캐릭터 한 명씩 구현

워크래프트 rawcode·JASS 오브젝트 추출은 이제 **필수 개발 조건이 아닙니다**.
모바일 독립 게임에서 도감에 기재된 플레이 규칙·수치·효과를 직접 구현합니다.
설명에 없는 값이나 다른 버전의 값은 추측하지 않고 근거·버전을 명시합니다.

- **첫 대상 C-01 흔함 루피**: ORDR 도감의 기본 조합 재료/공개 스킬 설명 없음과,
  사용자가 제공한 ordsearch.net 캡처의 공격력 표시 **50~52**를 기록했습니다.
- 그 수치는 게시물 수정일 **2021-02-02**의 자료이므로 **S2 2.323[C] 확정 수치가 아닙니다**.
  공격 주기·피해 분류가 공개되지 않아 실제 평타 활성화는 아직 보류합니다.
- 루피를 재료로 쓰는 베포·에이스·프랑키 조합 3건을 도감에서 확인하여
  조합 **미리보기**에 추가했습니다. 추가 재화가 명시되지 않은 이 3건은
  무료라고 가정하지 않고 최종 제작을 차단합니다.
- 전체 캐릭터 목록은 271종, 상세 스킬 프로필은 기존 200종 그대로입니다.
  루피를 '스킬 미수집'과 구분해 '공개된 스킬 설명 없음'으로 표시합니다.
- **완성 판정은 보류**: 소환·조합 데이터 준비와 전투 실행/검증은 구분합니다.
  [첫 캐릭터 진행 기록](docs/캐릭터-개별구현-툴팁기준-20261021.md)

## 2026-10-21 보니 A04P 방깎 별도 연동

원본 JASS `B4C/B4D/B39/B4B`의 A04P 방어 감소를 A04M과 별도 관리하도록 처리하고, 공격 선언(+10)·조건부 +20/+2 및 반경320 검증 진입점을 추가. **검증된 폼 공급자와 원본 RNG/마나 상태를 전부 연결한 것은 아니며, A04M+A04P·오라의 중첩 수식은 미확인**. [연구·구현 범위](docs/원본-2323C-보니A04P-오라조사.md).
