# 적·공격 이펙트 v1

일반 적 1장·보스 1장·공격 이펙트 4장을 최소 공통 이미지로 재사용합니다. **이미지 보관용 시안이며 게임 코드에는 아직 연결하지 않았습니다.** 각 PNG는 정적 이미지 한 장이고, 애니메이션 프레임 시트가 아닙니다. 이동·회전·확대·투명도 변화는 게임에서 처리합니다.

## 파일과 사용법

| 파일 | 역할 | 표시 방법 |
|---|---|---|
| [enemy-grunt-v1.png](enemy-grunt-v1.png) | 일반 적 공통 | 현재 적 좌표를 따라 이동. 작은 화면에서 실루엣이 보이도록 크기 조정. 이동 방향 반전은 그래픽에만 적용 |
| [enemy-boss-v1.png](enemy-boss-v1.png) | 보스 공통 | 일반 적보다 크게 표시하고 기존 보스 테두리·실제 HP바 유지. 크기는 표시용이며 충돌/대상 판정은 유지 |
| [fx-physical-impact-v1.png](fx-physical-impact-v1.png) | 물리 명중 섬광 | 실제 피해가 확정된 대상 위치에서 짧게 확대 후 페이드. 공격 예고·빗나감·면역을 실제 명중처럼 표시하지 않음 |
| [fx-sword-slash-v1.png](fx-sword-slash-v1.png) | 근접 참격 | 기본 그림은 왼쪽 아래 → 오른쪽 위로 휘두르는 궤적. 공격 방향에 맞춰 회전 오프셋을 보정하고 짧게 확대/페이드 |
| [fx-magic-projectile-v1.png](fx-magic-projectile-v1.png) | 마법탄 | 기본 진행 방향은 화면 오른쪽(+X). 시전자→대상 벡터의 각도로 회전하고 해당 표시 궤적을 따라 이동. 원본 가로세로 비율 유지 |
| [fx-area-shockwave-v1.png](fx-area-shockwave-v1.png) | 광역 충격파 | 중앙이 빈 링. 실제 광역 효과의 중심에서 확대/페이드. 사각·선형·단일 대상 기술에 원형 범위를 임의로 붙이지 않음 |

일반 적과 보스는 원작의 개별 캐릭터를 재현한 그림이 아닌 공통 표시 후보입니다. 이동 애니메이션 프레임이 없으므로 한 장을 이동시키는 방식으로 먼저 사용합니다. 몸 흔들기 등 추가 연출은 선택 사항입니다.

## 최소 이미지로 재사용하기

- 일반/보스는 같은 원본을 여러 적이 공유합니다. HP·이름·선택·상태 표시는 이미지에 굽지 않고 별도로 그립니다.
- 공격 종류별로 4개 효과를 공유하고 회전·크기·색/알파만 조절합니다. 이미 색이 있는 원본이므로 강한 틴트는 색을 탁하게 만들 수 있습니다.
- 메인/스토리 전장은 같은 텍스처를 공유하되 좌표 변환·클리핑·개별 효과 상태를 분리합니다.
- 이동 궤적이나 섬광을 본 것을 피해 계산 근거로 쓰지 않습니다. 이미지 교체로 원본 비용·확률·공격 주기·사거리·광역 반경을 바꾸지 않습니다.

## Unity에 적용할 때

이 폴더는 원본 보관 위치이므로 현재 APK에 자동 포함되지 않습니다. 적용 작업에서 필요한 PNG를 프로젝트의 아트 로딩 경로로 가져오고 Unity 메타 파일을 함께 관리합니다. 파일을 `Assets/`에 넣기만 해서는 기존 코드가 자동으로 사용하는 것이 아니므로 아래 연결점도 수정해야 합니다.

다음은 **적용 시 조정할 초기 설정 제안**이며, 설정 파일을 생성하거나 게임에서 검증한 값은 아닙니다.

| 항목 | 시작 설정 |
|---|---|
| Texture Type / Sprite Mode | Sprite (2D and UI) / Single |
| 투명도 | 원본 알파 사용, Alpha Is Transparency 활성화. 투명 영역을 검은 사각형으로 굽지 않음 |
| 필터·반복 | Bilinear / Clamp |
| Read/Write·Mip Maps | 별도 픽셀 접근/원근 축소가 없다면 비활성으로 시작 |
| 최대 크기 | 적 512, 이펙트 256~512로 시작해 실제 휴대폰에서 가독성/메모리를 보고 조정 |
| Pivot·화면 배치 | 적은 발 위치를 기준으로 시각 오프셋을 조정. 효과는 중심 기준. 원본 투명 여백도 크기에 포함되므로 실제 보이는 경계를 확인 |
| Pixels Per Unit | 기존 전장의 월드 단위와 스프라이트의 보이는 폭에 맞춤. 새 값으로 런타임 좌표/피격 범위를 바꾸지 않음 |
| Material | 투명 알파 혼합으로 시작. 발광용 가산 혼합은 번짐·배경 가독성을 비교한 뒤 선택 |
| Atlas·압축 | 화면에서 확인한 뒤 묶음/플랫폼 압축 적용. 원본 PNG는 그대로 보존 |

마법탄은 1774×887이고 나머지 5장은 1254×1254입니다. 원본 파일은 모바일에 그대로 쓰기에는 크므로 임포트 설정에서 줄인 뒤 확인합니다. 메타데이터의 `Bytes`는 디스크 파일 크기이며 런타임 텍스처 메모리 사용량이 아닙니다.

현재 공격 표시 코드에는 예고용 `preview`와 비행 진행률로 표시하는 섬광이 있습니다. 이 PNG로 교체했다고 실제 명중 이벤트 연결까지 끝난 것으로 표시하지 않습니다. **예고/시전/이동 연출과 실제 피해 확인 연출을 분리**하고 기존 이벤트 생산자를 먼저 확인합니다.

## 연결 후 확인할 것

1. 공격/피해 이벤트를 중복 구독하거나 이펙트의 이동 완료 시 피해를 다시 계산하지 않습니다.
2. 연출만을 위해 새 대상 선정이나 난수 호출을 추가하지 않습니다. 실제 대상이 사라진 경우 남은 궤적을 정리하고 새 대상을 임의로 때리지 않습니다.
3. 다수 공격에서는 기존 풀과 표시 개수 제한을 재사용합니다. 화면 표시를 줄이더라도 실제 공격·스킬·보상 사건은 생략하지 않습니다.
4. 세션 교체·적 제거·스토리 대상 교체·화면 비활성화 때 이전 이펙트를 정리합니다. 일시정지/앱 전환 때는 해당 전장 정지 정책에 맞춥니다.
5. 작은 가로 화면에서 일반/보스 구분, HP바 겹침, 참격 방향, 마법탄 비율, 투명 배경, 광역 표시의 실제 중심/반경을 확인합니다.
6. 알파를 서서히 줄여 소멸시키고 전장·메뉴 위로 효과가 새지 않도록 렌더 순서/클리핑을 확인합니다.

## 생성·확인 기록

- 내장 ImageGen으로 생성했으며 CLI/API 별도 생성은 사용하지 않았습니다. 생성 원본을 변경하지 않고 보관했습니다.
- 최종 프롬프트 6개: [prompts.json](prompts.json).
- 크기·알파 확인 기록: [image-metadata.json](image-metadata.json). 6개 모두 RGBA PNG이며 모서리 알파 0, 충격파 중앙 알파 0을 확인했습니다.
- 원본 무결성: [checksums.json](checksums.json)의 SHA-256과 Git blob SHA로 식별합니다.
- 이번 작업은 파일 보관·사용법 작성과 업로드 내용 일치 확인입니다. Unity·Python·NUnit·APK 실행이나 Actions 조회는 수행하지 않았습니다.

다른 chat에서는 **“`art/combat-v1/README.md`를 읽고 이 폴더의 적·이펙트 원본을 사용해줘”**라고 전달하시면 됩니다.
