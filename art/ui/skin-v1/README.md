# UI 바탕 이미지 v1

말풍선·작은 공통 버튼·팝업 패널을 글자 없이 재사용하는 이미지 3종입니다. **생성 원본 보관용이며 게임 UI에 자동 적용되는 파일은 아닙니다.**

## 파일과 재사용

| 파일 | 용도 | 재사용 방법 |
|---|---|---|
| [speech-bubble-v1.png](speech-bubble-v1.png) | 대사·길게 누르기 설명·짧은 도움말 | 글자와 줄바꿈을 별도로 표시. 꼬리 끝이 설명 대상 쪽을 향하도록 위치를 조절 |
| [button-square-v1.png](button-square-v1.png) | 닫기·일시정지·페이지·작은 행동 버튼 | 아이콘/기호는 게임에서 따로 표시. 같은 PNG에 색과 밝기를 곱해 선택·눌림·사용 불가 상태 표현 |
| [popup-panel-v1.png](popup-panel-v1.png) | 구매 확인·유닛 정보·보상·설정 창 | 모서리와 테두리는 고정하고 가운데만 늘리는 9분할 방식으로 크기 변경 |

기존 [가로 공통 버튼](../button-v1/README.md)과 함께 사용하는 회색 계열입니다. 제목·가격·확률·수량·버튼 문구를 이미지에 넣지 않았으므로 같은 원본을 여러 메뉴에 사용할 수 있습니다. 새 기능이나 버튼 동작을 추가하는 자료는 아닙니다.

## 적용할 때

- 원본 알파를 유지합니다. 흰색·검은색 사각 배경을 추가하지 않습니다.
- 텍스트와 아이콘은 별도 레이어로 올리고, 실제 모바일 크기에서 글자 대비와 여백을 확인합니다.
- 버튼 상태마다 별도 PNG를 만들지 않습니다. 회색 원본의 색/밝기를 바꾸되, 텍스트 색과 비활성 이유도 함께 표시합니다.
- 패널과 버튼은 테두리를 고정하는 9분할로 시작합니다. 투명 여백을 포함한 분할 경계는 이미지 크기·불투명 경계를 보고 수동으로 맞춥니다. 자동 임포트 프리셋은 포함하지 않습니다.
- 말풍선은 꼬리가 늘어나지 않도록 꼬리가 들어 있는 왼쪽·아래 구간을 고정합니다. 작은 크기에서 분할이 어색하면 원래 비율로 먼저 표시합니다. 글자 영역에는 꼬리 부분을 포함하지 않습니다.
- 연결 후보는 `Assets/Scripts/Unity/OrdrMobileUiTheme.cs`와 `OrdrMobileTouchPanel.cs`의 기존 버튼·패널·도움말 표시입니다. 기존 단일 탭/확인 정책·비용·재고·보상 처리에는 영향을 주지 않습니다.
- 현재 보관 위치는 `art/ui/skin-v1/`입니다. 실제 적용 시 프로젝트 아트 로딩 경로·Unity 메타·공통 테마 연결을 함께 처리해야 하며, APK에 들어갔다고 표시하지 않습니다.

## 생성·확인

내장 이미지 생성 도구를 사용했습니다. 전체 프롬프트는 [prompts.json](prompts.json), 원본 크기·파일 해시·PNG 정보는 [image-metadata.json](image-metadata.json)에 보관합니다. 원본 PNG를 수정하거나 기존 버튼 이미지를 덮어쓰지 않았습니다.

확인 범위는 이미지 시각 확인·PNG 크기/알파 정보·파일 해시·문서 연결입니다. Unity·Python·NUnit·APK 실행과 Actions 조회는 하지 않았습니다.
