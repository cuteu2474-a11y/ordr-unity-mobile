# 게임 이미지 원본

**2026-11-16 ImportedArt 5종 화면 연결(코드 반영·Unity/실기 검증 전):** 업로드된 PNG와 저장소의 5개 파일은 바이트 크기·해상도가 일치합니다. `Assets/Resources/ImportedArt`의 해적 적 이미지, 건물 14칸 시트, 파란 금테 UI 배경, 캐릭터 10칸 시트, 푸른 돌바닥을 실제 게임 표시 경로에 연결했습니다. 해적 이미지는 일반·광폭화·보스의 공통 몸체(보스 외곽선/크기 별도), 건물 14칸은 스토리 1~14단계별 표시, UI 패널은 오른쪽 메뉴/대기 패널, 돌바닥은 메인·스토리 전장에 적용됩니다. 캐릭터 시트는 명확히 대응되는 7종(LI-06, C-02, X-01, C-07, S-27, U-12, S-16)에만 사용하며 나머지 그림을 엉뚱한 유닛에 붙이지 않습니다. 게임 데이터·피해·사거리·이동 경로는 변경하지 않습니다. 각 자산 로드 실패 시 기존 대체 표현을 유지합니다. 테스트 5건은 추가했지만 Unity/Android 실기 검증 결과가 아닙니다.

게임 UI·전장에 재사용할 생성 이미지와 적용 안내입니다. **전장 바닥·수량 버튼·스토리 요새와 카툰풍 기본 버튼/확인창/도움말 배경 4종을 게임 리소스·테마 코드에 연결했습니다. 실제 Unity·Android 실행과 화면 가독성은 아직 검증 전입니다.**
