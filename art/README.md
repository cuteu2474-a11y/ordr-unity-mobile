# 게임 이미지 원본

게임 UI·전장에 재사용할 생성 이미지와 적용 안내입니다. **공통 바닥·수량 버튼·스토리 요새는 게임 코드의 오프라인 리소스에 연결했습니다. 나머지 원본 보관과 구분하며 실제 Unity/기기 적용 품질은 각 README와 검사 상태를 확인합니다.**

| 묶음 | 포함 | 사용법 |
|---|---|---|
| [공통 버튼 v1](ui/button-v1/) | 글자 없는 회색 공통 버튼 배경 1장 | [크기·색상 상태·9분할](ui/button-v1/README.md) |
| [UI 바탕 v1](ui/skin-v1/) | 말풍선·작은 버튼·팝업 패널 3장 | [글자 분리·색상 상태·늘림/꼬리 처리](ui/skin-v1/README.md) |
| [카툰풍 해적 UI v1](ui/cartoon-v1/) | 청록·금빛 버튼 3장, 양피지 패널 1장, 레퍼런스 보드 2장 | [원본 파일과 적용 구분](ui/cartoon-v1/README.md) |\n| [전장·수량 버튼 v1](battlefield-ui-v1/) | 공통 바닥·글자 없는 수량 버튼 2장 | [게임 연결·테두리 없는 메뉴·바닥/요새 공유](battlefield-ui-v1/README.md) |
| [적·이펙트 v1](combat-v1/) | 일반 적·보스 2장, 타격·참격·마법탄·광역 링 4장 | [파일별 용도·Unity 연결 위치·주의점](combat-v1/README.md) |

전체 게임 화면의 배치·버튼 동작·최종 사용 여부는 [모바일 UI 설계·조작 기준](../docs/화면-조작-시스템.md)에서 확인합니다. 이미지 보관 여부와 게임 코드 반영 여부는 각각 구분합니다.

원본은 버전 폴더에 보존하고 수정본은 별도 버전으로 관리합니다. 글자·가격·HP·확률 같은 동적 정보는 이미지에 포함하지 않습니다. 실제 적용 코드와 임포트 설정이 연결되기 전에는 APK 반영 완료로 표시하지 않습니다.
